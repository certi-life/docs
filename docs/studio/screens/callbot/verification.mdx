# 조직 인증 - 번호 구매를 위한 사업자 인증 받기

전화번호를 구매하려면 먼저 조직 인증을 받아야 합니다. 실제 사업자가 전화번호를 쓰는지 확인하는 절차입니다. **승인 전에는 번호 구매가 막혀 있고 심사에는 시간이 걸릴 수 있으므로, 에이전트를 만들기 시작할 때 미리 신청해 두는 것이 좋습니다.**

**위치:** 콜봇 > 조직 인증

## 인증 신청하기

**위치:** 콜봇 > 조직 인증 > 인증 신청

1. `인증 유형`에서 `개인사업자` 또는 `법인`을 고릅니다.
2. `신청자 구분`에서 `대표자 본인` 또는 `임직원`을 고릅니다.
3. `사업자등록증`을 첨부합니다.
4. `임직원`으로 신청한다면 `재직증명서`도 첨부합니다. 대표자가 아닌 임직원 명의로 신청할 때 필요합니다.
5. `인증 신청`을 누릅니다.

서류는 JPEG, PNG, WebP, PDF 형식의 10MB 이하 파일만 올릴 수 있으며, 제출된 서류는 심사 용도로만 사용됩니다. "아직 콜봇 조직이 연결되지 않았습니다"가 보이면 에이전트 화면 위쪽 배너의 `조직 생성`을 먼저 해야 합니다.

## 심사 상태 읽는 법

| 상태 | 뜻 | 할 일 |
| --- | --- | --- |
| `미신청` | 아직 인증을 신청하지 않았습니다 | 서류를 제출해 신청합니다 |
| `자동 확인 중` | 제출한 서류를 자동으로 확인하고 있습니다 | 기다립니다 |
| `심사 중` | 수동 심사가 진행 중입니다. 시간이 걸릴 수 있습니다 | 기다립니다. 끝나면 이 화면에 자동으로 반영됩니다 |
| `승인됨` | 인증이 승인되었습니다 | [번호 관리](./phone-numbers)에서 번호를 구매합니다 |
| `반려됨` | 인증이 반려되었습니다 | `반려 사유`를 확인하고 `인증 재신청`을 합니다 |
| `철회됨` | 인증이 철회되었습니다 | 필요하면 다시 신청합니다 |

상태 카드에는 `인증 유형`, `상호/법인명`, `신청일`, `승인일`이 함께 표시됩니다.

## 알아 둘 점

- 인증 등급에 따라 보유할 수 있는 번호 수가 다릅니다. 화면에는 개인 1개, 개인사업자 3개, 법인 5개로 안내됩니다.
- [발신표기번호](./phone-numbers#고객-화면에-보일-번호-등록하기)를 등록할 때 제출하는 통신가입증명원의 명의는 조직 인증 명의와 같아야 합니다.
- 반려되었다면 다시 신청하기 전에 상태 카드의 `반려 사유`를 먼저 읽고, 그 사유에 맞게 서류나 신청자 구분을 고쳐 제출하세요.
- 서류에는 사업자 정보가 들어 있습니다. 조직에서 서류 제출 권한이 있는 담당자가 진행하세요.
