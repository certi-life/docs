# 시술동의서와 근로계약서 - 전자 서명으로 받고 관리하기

`병원 관리`에는 **종이 대신 전자 서명으로 받는 문서** 두 가지가 있습니다. `시술동의서`는 환자에게, `근로계약서`는 직원에게 받습니다. 두 메뉴 모두 작성한 뒤 알림톡으로 보내고, 서명이 끝나면 상태가 자동으로 바뀝니다.

**위치:** 병원 관리 > 시술동의서

왼쪽 메뉴 이름은 `시술동의서`와 `근로계약서`이고, 열린 화면의 제목은 `시술동의서 관리`와 `근로계약서 관리`입니다. 두 메뉴는 각각 권한이 있는 계정에만 보입니다.

## 이럴 때 사용하세요

| 하려는 일 | 가는 곳 |
| --- | --- |
| 시술 전에 환자 동의를 받기 | [시술동의서 받기](#시술동의서-받기) |
| 환자가 알림톡을 못 받았다고 할 때 | [서명 확인하고 다시 보내기](#서명-확인하고-다시-보내기) |
| 새 직원과 근로계약서 쓰기 | [근로계약서 쓰기](#근로계약서-쓰기) |
| 직원 연락처나 계약 상세 보기 | [민감정보 확인하기](#민감정보-확인하기) |
| 직원이 퇴사했을 때 | [퇴사 처리하기](#퇴사-처리하기) |

## 시술동의서 받기

**위치:** 병원 관리 > 시술동의서 > 신규 작성

1. `신규 작성`을 누릅니다.
2. 진료과목 탭에서 동의서 양식을 고릅니다. 현재는 임플란트 시술동의서를 쓸 수 있고, 다른 양식은 누르면 "준비 중인 서비스입니다."가 표시됩니다.
3. `기본 정보`에 `환자명`, `환자 연락처`, `병원 연락처`를 입력하고 동의서 내용을 채웁니다. `병원 연락처`는 알림톡을 받을 병원 쪽 연락처입니다.
4. `미리보기`로 내용을 확인한 뒤 `동의서 작성완료`를 누릅니다.
5. `시술동의서 발송` 창에서 받을 대상(`병원`, `환자`)을 고르고 `발송`을 누릅니다. 대상은 하나 이상 골라야 합니다.

작성을 마치면 상태가 `서명 대기 중`이 되고, 환자가 서명하면 `서명 완료`로 자동 변경됩니다.

## 서명 확인하고 다시 보내기

**위치:** 병원 관리 > 시술동의서

목록에서 `환자명`, `동의서상태`, `시술일자`로 찾습니다.

- **`알림톡 재발송`의 `재발송`:** 환자가 알림톡을 받지 못했을 때 다시 보냅니다. 먼저 연락처가 맞는지 확인하세요.
- **`PDF 다운로드`:** 동의서를 파일로 받습니다.
- **`동의서 삭제`:** 삭제할 동의서를 고른 뒤 `삭제 완료`를 누릅니다. 그만두려면 `돌아가기`를 누릅니다.

:::caution[삭제한 동의서는 복구할 수 없습니다]
삭제 확인 창에도 "삭제한 동의서는 복구할 수 없습니다."라고 나옵니다. 서명이 끝난 동의서는 병원의 보관 기준을 확인한 뒤에 지우세요.
:::

## 근로계약서 쓰기

**위치:** 병원 관리 > 근로계약서 > 신규 작성

1. `신규 작성`을 누릅니다. 비슷한 계약이 있으면 `최근 계약 불러오기`로 시작할 수 있습니다.
2. `기본 정보`에 고용처, 대표자, 피고용인, 연락처, 계약일을 입력합니다.
3. `주요 계약 사항`을 채웁니다. `계약기간`(근무시작일, 수습 여부), `근무장소`, `근로시간`, `휴게시간`, `임금`, `기타사항` 순서입니다.
4. `미리보기`로 확인하고 `계약서 생성`을 누릅니다. `계약 내용 확인` 창에서 `작성완료`를 누르면 서명 요청이 나갑니다.

`임금`에서는 계약형태(`연봉제`, `실수령제`), 식대와 기타급여의 `포함` 여부, 지급방법, 산정방식(`포괄임금제`, `비포괄임금제`), 급여일을 정합니다. 식대가 급여에 포함되면 `포함`, 급여 외에 따로 지급하면 `미포함`을 고릅니다.

작성하다 멈춰야 하면 `임시저장`을 씁니다. 임시저장은 이전 임시저장 데이터를 덮어쓰고, 계약서를 생성하면 초기화됩니다.

:::info
계약서 양식에 어떤 조건을 넣어야 하는지는 이 문서에서 다루지 않습니다. 근로 조건의 법적 검토는 병원의 노무 담당자와 확인하세요.
:::

### 계약 상태 읽기

| 구분 | 값 | 바뀌는 시점 |
| --- | --- | --- |
| 계약 상태 | `계약 생성됨` → `서명 진행 중` → `서명 완료` | 작성 완료, 한 명 서명, 모두 서명 |
| 근무상태 | `입사 예정` → `재직 중` | 계약 생성, 모든 서명 완료 |

근무상태에는 이 밖에 `수습 중`, `휴직 중`, `퇴사`, `계약 해지`가 있습니다. 목록은 `재직자`와 `퇴사자` 탭으로 나뉩니다. 직원이 서명 요청을 받지 못했으면 행의 `재발송`을 누릅니다.

## 민감정보 확인하기

**위치:** 병원 관리 > 근로계약서 > 연락처 보기

직원 연락처와 계약 상세에는 급여 같은 민감정보가 있어 바로 보이지 않습니다. `연락처 보기`나 `상세`를 누르면 본인 인증 창이 열립니다.

1. `관리자 전화번호`를 입력하고 `인증요청`을 누릅니다.
2. 받은 `인증번호`를 입력하고 `확인`을 누릅니다.

인증에는 **책임자 연락처**가 쓰입니다. 등록되어 있지 않으면 "민감정보 확인을 위해 책임자 연락처 등록이 필요합니다."라는 안내와 함께 [병원 정보 관리](./hospital-info#책임자-연락처-등록하기)로 이동할지 묻습니다.

## 퇴사 처리하기

**위치:** 병원 관리 > 근로계약서 > 퇴사

1. 직원 행에서 `퇴사`를 누릅니다.
2. `퇴사 처리` 창에서 `퇴사일자`를 고르고 `확인`을 누릅니다.

처리된 직원은 `퇴사자` 탭으로 옮겨집니다. 퇴사한 직원이 Hospital 서브계정을 쓰고 있었다면 [계정 관리](./accounts#계정-고치고-정리하기)에서 계정도 함께 정리하세요.
