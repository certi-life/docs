# CRM 메시징

CertiLife CRM 메시징은 고객에게 필요한 안내를 전달하고 **병원과 고객의 관계를 이어가는 마케팅 활동**을 지원합니다.

## 활용 예시

- 시술 이후 필요한 안내 전달
- 고객에게 도움이 되는 정보 제공
- 적절한 시점의 재방문 안내
- 고객 특성에 맞는 메시지 구성

## 좋은 메시지의 기준

1. **목적이 분명합니다.** 고객이 무엇을 확인하거나 행동해야 하는지 드러납니다.
2. **필요한 정보만 담습니다.** 짧고 읽기 쉽게 작성합니다.
3. **수신 동의를 존중합니다.** 관련 법령과 병원의 운영 정책을 따릅니다.
4. **확인 가능한 내용만 안내합니다.** 가격, 혜택, 기간을 정확하게 표시합니다.
