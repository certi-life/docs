# AI - AI와 함께 문서 작성하고 챗봇에 반영하기

`AI` 메뉴는 AI와 대화하면서 **문서 일을 같이 하는 작업 공간**입니다. 문서에 대해 질문하고, 요약을 받고, 안내문 초안을 쓰게 하고, 고친 문서를 챗봇 학습자료로 반영하는 데까지 한 화면에서 이어집니다. 처음 들어오면 가운데에 "무엇을 도와드릴까요?"가 보이고, 아래 입력창(`AI에게 메시지 보내기`)에 하고 싶은 일을 적으면 됩니다.

**위치:** AI

## 화면 구성

| 영역 | 있는 것 | 하는 일 |
| --- | --- | --- |
| 왼쪽 | `세션`, `검토` 탭 | 지난 대화를 다시 열고, 용어 통일 같은 검토 작업을 봅니다 |
| 가운데 | 대화창 | AI에게 질문하고 작업을 요청합니다 |
| 오른쪽 캔버스 | `문서함`, `지식` 탭 | 문서를 작성·편집하고, 문서와 챗봇 학습자료의 연결을 관리합니다 |

오른쪽 캔버스를 닫았다면 `캔버스` 버튼으로 다시 엽니다. 무엇을 시킬 수 있는지 모르겠다면 처음 화면의 추천 질문 `어떤 일을 도와줄 수 있나요?`를 눌러 보세요. 문서 질문·요약, 자료 조사, 글 작성·편집, 웹 검색을 도와줍니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 안내문 초안을 AI에게 쓰게 하고 싶어요 | 대화창에 요청하고, 결과를 `문서함`에서 다듬습니다 |
| 가지고 있는 파일을 문서로 등록하고 싶어요 | [문서 만들고 올리기](#문서-만들고-올리기) |
| 고친 문서를 챗봇이 쓰게 하고 싶어요 | [고친 문서를 챗봇에 반영하기](#고친-문서를-챗봇에-반영하기) |
| 예전 내용으로 되돌리고 싶어요 | [버전 비교하고 되돌리기](#버전-비교하고-되돌리기) |
| 여러 문서에서 제각각인 표기를 맞추고 싶어요 | [여러 문서의 용어 통일하기](#여러-문서의-용어-통일하기) |

## 문서 만들고 올리기

**위치:** AI > 문서함 > 추가

1. 오른쪽 캔버스의 `문서함` 탭에서 `추가`를 누릅니다.
2. `새 문서 작성`, `파일 업로드`, `새 폴더 만들기` 중에서 고릅니다. 파일은 끌어다 놓아도 되며 PDF, Markdown, JSON, TXT를 가져올 수 있습니다.
3. 문서 제목을 적고 내용을 작성한 뒤 `저장`합니다. 제목이 없으면 저장할 수 없습니다.

문서를 정리하려면 `폴더 이동`으로 폴더를 옮깁니다. 문서가 [백과사전](./encyclopedia)의 어느 주제에 속하는지는 `카탈로그 태그 할당`으로 정합니다. 문서를 선택한 뒤 `카탈로그 태그 할당` 창에서 태그를 찾아 고르고 `변경 적용`을 누르세요. 문서 하나의 태그는 `상세정보`(`문서 상세정보` 창)의 `카탈로그 태그`에서도 바꿀 수 있고, 여기서는 선택하거나 해제하면 바로 저장됩니다.

## 고친 문서를 챗봇에 반영하기

**위치:** AI > 문서함 > 챗봇에 반영

문서를 저장하면 "저장됨. 챗봇에 반영하세요."라는 안내가 나옵니다. **저장만으로는 챗봇 답변이 바뀌지 않습니다.**

1. `챗봇에 반영`을 누릅니다.
2. 특정 버전을 반영하려면 `버전 선택`을 눌러 `챗봇 적용 버전 선택` 창에서 `적용할 버전`을 고르고 `선택 버전 반영`을 누릅니다.

어느 챗봇이 이 문서를 쓰고 있는지는 `문서 상세정보` 창의 `사용 중인 챗봇`에서 확인합니다. 문서와 챗봇 학습자료의 연결 전체는 캔버스의 `지식` 탭에서 관리합니다.

## 버전 비교하고 되돌리기

**위치:** AI > 문서함 > 버전

문서를 저장할 때마다 버전이 남습니다. `버전`에서 `비교하기`를 누르고 `왼쪽`과 `오른쪽` 버전을 고르면 `버전 비교`에서 달라진 부분을 볼 수 있습니다. 예전 내용으로 돌아가려면 그 버전에서 `복원`을 누르고 메모를 남긴 뒤 다시 `복원`을 누릅니다.

## 여러 문서의 용어 통일하기

**위치:** AI > 검토 > 용어 통일

같은 시술을 문서마다 다르게 적어 두면 챗봇 답변도 제각각이 됩니다. 왼쪽 `검토` 탭의 `용어 통일`은 여러 문서에서 표기가 다른 곳을 찾아 한 번에 맞추도록 돕습니다. 찾을 표기는 `표기 직접 추가`로 넣을 수 있고, 목록을 확정한 뒤 `이 목록으로 찾기`를 누릅니다.

:::caution[결과는 직접 확인하세요]
문서가 많으면 일부만 훑고 "못 찾은 표기가 있을 수 있어요"라고 안내합니다. 자동 분류에 실패하면 후보가 검증되지 않았다는 안내가 나오니, 그때는 후보를 직접 확인하고 고르세요. 캔버스에 저장하지 않은 편집이 있으면 미리보기가 되지 않으므로 먼저 저장하거나 편집을 되돌립니다.
:::

## 알아 둘 점

- 세션을 삭제하면 저장된 대화 기록이 목록에서 사라집니다.
- `지식` 탭은 현재 내 문서 폴더 기준으로 제공되며, 챗봇 문서는 아직 포함되지 않는다고 화면에 안내됩니다.
- AI가 쓴 초안에는 사실과 다른 내용이 섞일 수 있습니다. 운영시간, 가격, 의료 관련 설명은 반드시 사람이 확인한 뒤 저장하고 반영하세요.
