# 상담 - 채팅 상담을 직접 응대하기

`상담`은 상담원이 고객과 직접 채팅하는 화면입니다. 챗봇이 넘긴 상담과 고객이 바로 요청한 상담이 모두 여기로 들어옵니다. 화면은 세 부분으로 나뉩니다. 왼쪽에서 상담을 고르고, 가운데 `상담 백과사전`에서 답변에 쓸 내용을 찾고, 오른쪽에서 고객과 대화하며 고객 정보를 확인합니다.

**위치:** 상담

## 이럴 때 사용하세요

| 하고 싶은 일 | 섹션 |
| --- | --- |
| 기다리는 고객의 상담을 시작하고 싶어요 | [상담 시작하고 끝내기](#상담-시작하고-끝내기) |
| 다른 상담원에게 넘기고 싶어요 | [다른 상담원에게 넘기기](#다른-상담원에게-넘기기) |
| 외국어로 문의한 고객과 대화하고 싶어요 | [외국어 고객과 대화하기](#외국어-고객과-대화하기) |
| 특정 고객이나 내 상담만 보고 싶어요 | [원하는 상담 찾기](#원하는-상담-찾기) |
| 오래 방치된 상담을 한 번에 정리하고 싶어요 | [여러 상담을 한 번에 종료하기](#여러-상담을-한-번에-종료하기) |

## 원하는 상담 찾기

**위치:** 상담 > 상담 목록

목록 위쪽 탭은 상담의 상태입니다. `대기`는 챗봇이 응대 중이거나 상담원을 기다리는 상담, `진행중`은 상담원이 응대 중인 상담, `완료`와 `종료`는 끝난 상담입니다. 상담원은 주로 `대기`와 `진행중`을 오가며 일합니다.

탭 아래 필터로 목록을 좁힙니다.

- **기간:** `오늘`, `1주일`, `1개월`, `6개월` 또는 `직접설정`
- **채널:** `카카오`, `웹챗`, `네이버`, `인스타그램`
- **챗봇·태그:** `챗봇 전체`, `태그 전체`에서 선택
- **토글:** `활성 유저만`, `내 상담만`, `안읽음만`
- **검색:** `고객 이름`, `고객 연락처`, `상담사`, `상담내용` 중 기준을 고르고 검색합니다. 연락처는 전체 번호로, 상담내용은 2자 이상으로 찾습니다.

:::tip[활성 유저만이 뭔가요?]
'활성 유저'는 챗봇에게 한 번이라도 말을 건 사람입니다. 켜면 실제로 메시지를 보낸 고객만 보이고, 끄면 인사 메시지만 받고 아무 말도 하지 않은 방까지 모두 보입니다. 목록이 너무 길다면 켜 두세요.
:::

매번 같은 필터로 시작하고 싶다면 필터 옆 톱니(`검색 필터 설정`)에서 필터의 순서, 노출 여부, 시작 상태를 정할 수 있습니다. 이 설정은 조직 전체에 적용됩니다.

## 상담 시작하고 끝내기

**위치:** 상담 > (상담 선택) > 대화창

1. `대기` 탭에서 상담을 누릅니다.
2. 대화창의 `바로 상담 시작`(상황에 따라 `상담 진행하기`, `추가 상담 시작`)을 눌러 상담을 시작합니다. `대기` 탭에서는 `챗봇만`, `상담원 대기만` 토글로 상담원을 기다리는 고객만 골라 볼 수 있습니다. 다른 상담원의 상담에 함께 들어갈 때는 `상담 참여하기`를 누릅니다.
3. 고객과 대화합니다. 답변에 필요한 내용은 가운데 `상담 백과사전`에서 찾고, 기억해 둘 내용은 메모 아이콘을 눌러 남깁니다.
4. 상담이 끝나면 대화창 위쪽의 `상담완료` 또는 `상담종료`를 누릅니다.
5. `상담 완료 — 내용 정리` 창에서 `상담사 정리`에 상담 내용을 정리하고 `저장하고 완료`를 누릅니다. **저장해야 상담이 완료됩니다.**

`AI 초안`은 상담이 완료·종료된 뒤에 만들어지는 참고용 초안입니다. 상담사가 확정한 정리 기록과는 구분되므로, 초안을 그대로 믿지 말고 확인한 뒤 활용하세요. 상담 중간에 정리만 해 두려면 `정리하기`를 누릅니다.

## 다른 상담원에게 넘기기

**위치:** 상담 > 대화창 > 이관

1. 대화창 위쪽의 `이관`을 누릅니다.
2. `상담 이관` 창에서 상담원을 이름으로 검색해 고릅니다. `담당 적은순`으로 정렬하면 여유 있는 상담원을 찾기 쉽습니다.
3. `이관 사유`를 적습니다. 필수 항목이며, 넘겨받는 사람이 상황을 바로 파악할 수 있게 적으세요.
4. `이관하기`를 누릅니다.

상담에서 그냥 빠지려면 `상담 나가기`를 누릅니다.

## 외국어 고객과 대화하기

**위치:** 상담 > 대화창 > 번역

입력창 위의 언어 바에서 `고객`과 `상담사`의 언어를 정합니다. 고객 언어는 `자동 감지`로 둘 수 있습니다. 메시지를 쓰고 `번역`을 누르면 `원문`과 `실제 발송` 문구가 나란히 보이고, 확인한 뒤 `전송`합니다. 번역 없이 보내려면 `바로 전송`을 고릅니다.

고유명사나 시술명은 번역이 어색할 수 있으니 `실제 발송` 문구를 꼭 확인하세요. 번역 설정과 확인 절차는 [상담 메시지 번역](../../products/ai-chatbot/message-translation)에 자세히 있습니다. 번역을 켜고 끄는 조직 설정은 [설정(조직 설정)](./org-settings#상담-운영-기준-정하기)의 `번역`에 있습니다.

## 고객 정보 확인하고 활용하기

**위치:** 상담 > 대화창 > 고객정보

대화창 오른쪽 패널의 `고객정보` 탭에는 고객 카드와 `상담 히스토리`가 있어, 이 고객이 전에 무엇을 문의했는지 보고 응대할 수 있습니다. 고객 카드에서 `고객 상세`, `일정 잡기`, `메시지 발송` 같은 작업으로 바로 이어갈 수 있습니다. `서티 AI` 탭에서는 상담 중 궁금한 내용을 질문하면 AI가 지식 문서에서 관련 정보를 찾아 줍니다.

대화창 위쪽에서 고객 태그를 붙여 두면 나중에 `태그 전체` 필터로 같은 유형의 고객을 모아 볼 수 있습니다. 태그 목록은 [백과사전](./encyclopedia)에서 관리합니다.

## 여러 상담을 한 번에 종료하기

**위치:** 상담 > 상담 목록 > 일괄 종료

목록에서 상담을 선택(또는 `전체 선택`)하고 `일괄 종료`를 누른 뒤, `일괄 종료` 창에서 `종료 사유 (선택)`를 적고 `종료 실행`을 누릅니다.

:::caution[일괄 종료는 취소할 수 없습니다]
현재 필터 조건에 해당하는 상담방 전체가 종료 처리되며 되돌릴 수 없습니다. 검색어는 종료 대상에 적용되지 않으므로, 실행 전에 필터 조건과 건수를 꼭 확인하세요.
:::
