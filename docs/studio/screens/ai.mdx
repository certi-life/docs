# AI - AI와 함께 문서 작성하고 챗봇에 반영하기

`AI` 메뉴는 AI와 대화하면서 **문서 일을 같이 하는 작업 공간**입니다. 문서에 대해 질문하고, 요약을 받고, 안내문 초안을 쓰게 하고, 고친 문서를 챗봇 학습자료로 반영하는 데까지 한 화면에서 이어집니다. 처음 들어오면 가운데에 "무엇을 도와드릴까요?"가 보이고, 아래 입력창(`AI에게 메시지 보내기`)에 하고 싶은 일을 적으면 됩니다.

**위치:** AI

## 화면 구성

| 영역 | 있는 것 | 하는 일 |
| --- | --- | --- |
| 왼쪽 | `세션`, `검토` 탭 | 지난 대화를 다시 열고, 용어 통일 같은 검토 작업을 봅니다 |
| 가운데 | 대화창 | AI에게 질문하고 작업을 요청합니다 |
| 오른쪽 캔버스 | `문서함`, `지식` 탭 | 문서를 작성·편집하고, 문서와 챗봇 학습자료의 연결을 관리합니다 |

오른쪽 캔버스를 닫았다면 `캔버스` 버튼으로 다시 엽니다. 무엇을 시킬 수 있는지 모르겠다면 처음 화면의 추천 질문 `어떤 일을 도와줄 수 있나요?`를 눌러 보세요. 문서 질문·요약, 자료 조사, 글 작성·편집, 웹 검색을 도와줍니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 안내문 초안을 AI에게 쓰게 하고 싶어요 | 대화창에 요청하고, 결과를 `문서함`에서 다듬습니다 |
| AI가 어디에서 찾아 답할지 정하고 싶어요 | [AI가 찾아볼 곳 고르기](#ai가-찾아볼-곳-고르기) |
| AI가 제안한 수정을 골라서 받아들이고 싶어요 | [AI의 편집 제안 적용하기](#ai의-편집-제안-적용하기) |
| 가지고 있는 파일을 문서로 등록하고 싶어요 | [문서 만들고 올리기](#문서-만들고-올리기) |
| 고친 문서를 챗봇이 쓰게 하고 싶어요 | [고친 문서를 챗봇에 반영하기](#고친-문서를-챗봇에-반영하기) |
| 예전 내용으로 되돌리고 싶어요 | [버전 비교하고 되돌리기](#버전-비교하고-되돌리기) |
| 여러 문서에서 제각각인 표기를 맞추고 싶어요 | [여러 문서의 용어 통일하기](#여러-문서의-용어-통일하기) |

## AI가 찾아볼 곳 고르기

**위치:** AI > 대화창 > 입력창 아래 도구

입력창 아래의 도구 버튼으로 AI가 답을 찾을 곳을 정합니다.

| 도구 | AI가 찾아보는 곳 | 쓰는 경우 |
| --- | --- | --- |
| `웹 검색` | 인터넷 | 최신 정보나 외부 자료가 필요할 때 |
| `문서 검색` | 문서함의 문서 | 우리 조직의 자료를 근거로 답을 받고 싶을 때 |
| `상담 검색` | 상담 내역 | "지난달 임플란트 문의가 어땠지?"처럼 과거 상담을 찾을 때 |

`상담 검색`을 켜면 `웹 검색`과 `문서 검색`은 함께 쓸 수 없습니다. 모델 선택은 기본값 `Auto`로 두면 질문에 맞는 모델이 자동으로 쓰입니다.

답변에 붙은 근거 표시를 누르면 근거가 된 문서가 열립니다. 답변이 마음에 들지 않으면 `다시 시도`를 누르고, 답변 아래의 `좋아요`와 `싫어요`로 평가를 남길 수 있습니다. 응답을 기다리는 중에는 전송 버튼이 중단 버튼으로 바뀝니다. 대화창에는 파일을 첨부하는 버튼이 없으며, 파일은 오른쪽 `문서함`에 올립니다.

## AI의 편집 제안 적용하기

**위치:** AI > 대화창 > 편집 제안

문서를 열어 둔 채 "이 문단을 더 쉽게 고쳐 줘"처럼 요청하면 AI가 문서를 바로 바꾸지 않고 **편집 제안**을 카드로 보여 줍니다. 제안의 종류는 `삽입`, `수정`, `초안`(문서 전체를 채우는 초안)입니다. 카드에 마우스를 올리면 문서의 어느 부분이 바뀌는지 볼 수 있습니다.

1. 제안마다 `적용` 또는 `제외`를 누릅니다. 한꺼번에 처리하려면 `현재 문서 모두 적용`이나 `현재 문서 모두 제외`를 누릅니다.
2. 적용한 제안을 취소하려면 그 카드의 `되돌리기`를 누릅니다. 제안을 받기 전 상태로 모두 되돌리려면 `편집 전으로`를 누릅니다.
3. 결과가 마음에 들면 문서를 `저장`합니다.

적용할 수 없는 제안에는 사유가 표시됩니다.

| 표시되는 사유 | 뜻과 할 일 |
| --- | --- |
| "문서가 변경됨: 제안이 만들어진 기준 버전과 현재 문서가 달라 다시 제안해야 합니다." | 제안을 받은 뒤에 문서를 고쳤습니다. AI에게 다시 요청합니다 |
| "앵커를 현재 문서에서 찾지 못해 적용할 수 없습니다." | 고칠 위치를 문서에서 찾지 못했습니다. 고칠 부분을 더 분명히 알려 주고 다시 요청합니다 |
| "표/목록/제목 구조가 손상될 수 있어 적용할 수 없습니다." | 표나 목록이 깨질 수 있는 수정입니다. 해당 부분은 직접 고칩니다 |
| "예상보다 큰 삭제가 감지되어 적용할 수 없습니다." | 제안이 내용을 너무 많이 지웁니다. 범위를 좁혀 다시 요청합니다 |

챗봇의 커스텀 프롬프트에 대한 제안은 여기에서 적용되지 않습니다. 내용을 참고해 챗봇의 [AI 설정](./chatbot/settings/ai-settings)에서 직접 고칩니다.

## 문서 만들고 올리기

**위치:** AI > 문서함 > 추가

1. 오른쪽 캔버스의 `문서함` 탭에서 `추가`를 누릅니다.
2. `새 문서 작성`, `파일 업로드`, `새 폴더 만들기` 중에서 고릅니다. 파일은 끌어다 놓아도 되며 PDF, Markdown, JSON, TXT를 가져올 수 있습니다.
3. 문서 제목을 적고 내용을 작성한 뒤 `저장`합니다. 제목이 없으면 저장할 수 없습니다.

열어 둔 문서를 저장하지 않은 채 다른 문서나 폴더를 열거나, 새 문서를 만들거나, 버전을 복원하려 하면 `저장되지 않은 변경` 창("현재 문서의 변경사항이 저장되지 않았습니다. 저장하지 않고 이동하면 변경사항이 사라집니다.")이 뜹니다. `계속 편집`을 누르면 편집이 남고, `저장하지 않고 나가기`를 누르면 고친 내용이 사라집니다.

문서를 정리하려면 `폴더 이동`으로 폴더를 옮깁니다. 문서가 [백과사전](./encyclopedia)의 어느 주제에 속하는지는 `카탈로그 태그 할당`으로 정합니다. 문서를 선택한 뒤 `카탈로그 태그 할당` 창에서 태그를 찾아 고르고 `변경 적용`을 누르세요. 문서 하나의 태그는 `상세정보`(`문서 상세정보` 창)의 `카탈로그 태그`에서도 바꿀 수 있고, 여기서는 선택하거나 해제하면 바로 저장됩니다.

## 고친 문서를 챗봇에 반영하기

**위치:** AI > 문서함 > 챗봇에 반영

문서를 저장하면 "저장됨. 챗봇에 반영하세요."라는 안내가 나옵니다. **저장만으로는 챗봇 답변이 바뀌지 않습니다.**

1. `챗봇에 반영`을 누릅니다.
2. 특정 버전을 반영하려면 `버전 선택`을 눌러 `챗봇 적용 버전 선택` 창에서 `적용할 버전`을 고르고 `선택 버전 반영`을 누릅니다.

어느 챗봇이 이 문서를 쓰고 있는지는 `문서 상세정보` 창의 `사용 중인 챗봇`에서 확인합니다. 문서와 챗봇 학습자료의 연결 전체는 캔버스의 `지식` 탭에서 관리합니다.

## 버전 비교하고 되돌리기

**위치:** AI > 문서함 > 버전

문서를 저장할 때마다 버전이 남습니다. `버전`에서 `비교하기`를 누르고 `왼쪽`과 `오른쪽` 버전을 고르면 `버전 비교`에서 달라진 부분을 볼 수 있습니다. 예전 내용으로 돌아가려면 그 버전에서 `복원`을 누르고 메모를 남긴 뒤 다시 `복원`을 누릅니다.

## 여러 문서의 용어 통일하기

**위치:** AI > 검토 > 용어 통일

같은 시술을 문서마다 다르게 적어 두면 챗봇 답변도 제각각이 됩니다. 왼쪽 `검토` 탭의 `용어 통일`은 여러 문서에서 표기가 다른 곳을 찾아 한 번에 맞추도록 돕습니다. 찾을 표기는 `표기 직접 추가`로 넣을 수 있고, 목록을 확정한 뒤 `이 목록으로 찾기`를 누릅니다.

:::caution[결과는 직접 확인하세요]
문서가 많으면 일부만 훑고 "못 찾은 표기가 있을 수 있어요"라고 안내합니다. 자동 분류에 실패하면 후보가 검증되지 않았다는 안내가 나오니, 그때는 후보를 직접 확인하고 고르세요. 캔버스에 저장하지 않은 편집이 있으면 미리보기가 되지 않으므로 먼저 저장하거나 편집을 되돌립니다.
:::

## AI가 정리한 지식 보기

**위치:** AI > 지식

`지식` 탭의 `생성된 지식`은 AI가 문서를 읽고 자동으로 정리한 내용입니다. 폴더의 문서를 열람하면 정리가 시작되며, 직접 만들 필요가 없습니다.

- **`목록`:** `문서 요약`, `엔티티`, `개념`으로 나뉩니다. 항목을 누르면 정리된 페이지가 열리고, 아래의 `근거 문서`에서 원본 문서로, `관련 페이지`에서 이어지는 내용으로 갈 수 있습니다.
- **`그래프`:** 문서에 나온 대상들이 어떻게 이어져 있는지 그림으로 봅니다. 문서가 분석되기 전에는 "그래프가 아직 비어 있어요"가 표시됩니다.
- **묶음:** 자주 보는 페이지에 별표를 하거나 `새 묶음`으로 묶어 둡니다.

`갱신 대기` 표시는 그 페이지가 아직 최신 내용으로 갱신되지 않았다는 뜻입니다. `지식 새로고침`으로 최신 상태를 불러옵니다. 지식은 현재 내 문서 폴더 기준으로 제공되며, 챗봇 문서는 아직 포함되지 않는다고 화면에 안내됩니다.

## 지난 대화 정리하기

**위치:** AI > 세션

왼쪽 `세션` 탭에는 지난 대화가 쌓입니다. 행의 메뉴에서 `이름 변경`과 `삭제`를 할 수 있고, 자주 여는 대화는 `상위 고정`으로 위에 둡니다. 세션을 삭제하면 저장된 대화 기록이 목록에서 사라집니다. 세션을 검색하는 기능은 없으므로 나중에 다시 볼 대화에는 알아보기 쉬운 이름을 붙여 두세요.

## 알아 둘 점

- `문서 상세정보` 창의 `고급`을 펼치면 나오는 값은 문의할 때 문서를 특정하는 용도입니다. 평소에는 볼 필요가 없습니다.
- AI가 쓴 초안에는 사실과 다른 내용이 섞일 수 있습니다. 운영시간, 가격, 의료 관련 설명은 반드시 사람이 확인한 뒤 저장하고 반영하세요.
