# 상담 메시지 번역

> 상담방 언어를 자동으로 판단하고 수신 메시지를 번역하며, 발신 전 번역 여부를 선택하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/products/ai-chatbot/message-translation)

상담 메시지 번역은 고객과 상담사가 서로 다른 언어를 사용할 때 수신 메시지를 자동으로 번역하고, 상담사가 답변을 보내기 전에 번역 여부를 선택할 수 있는 기능입니다. 언어 설정은 상담방별로 관리되며 모든 상담 채널에서 같은 방식으로 동작합니다.

## 지원 언어

고객 언어와 상담사 언어에서 다음 언어를 선택할 수 있습니다.

- 한국어
- 영어
- 일본어
- 중국어(간체)
- 중국어(번체)
- 태국어
- 스페인어(멕시코)
- 베트남어

고객 언어에는 `자동 감지`를 사용할 수 있고, 상담사 언어에는 조직의 기본 언어를 따르는 `회사 설정`을 사용할 수 있습니다.

## 고객 언어가 결정되는 방식

자동 감지를 사용하면 고객의 첫 3턴을 확인한 뒤 가장 많이 사용된 언어를 상담방의 고객 언어로 정합니다. 자동으로 판단된 언어가 실제 대화 언어와 다르거나 대화 중 언어가 바뀌면 상담사가 고객 언어를 직접 변경할 수 있습니다.

언어 변경은 현재 상담방에만 적용됩니다. 다른 상담방이나 다른 상담사의 언어 설정을 함께 바꾸지 않습니다.

## 수신 메시지 확인하기

1. `상담`에서 확인할 상담방을 선택합니다.
2. 메시지 작성 영역 위의 언어 표시에서 고객 언어와 상담사 언어를 확인합니다.
3. 고객이 보낸 메시지는 수신될 때 자동으로 번역됩니다.
4. 원문 아래의 `번역` 또는 `번역 · 언어` 표시에서 번역문을 확인합니다.

필요한 경우 메시지별 `메시지 번역` 동작으로 번역을 다시 확인할 수 있습니다. 번역문만 보고 의미가 불분명하면 원문과 함께 확인하고, 의료진의 판단이 필요한 내용은 담당자에게 연결하세요.

## 답변 보내기

상담사는 두 가지 방식으로 답변을 보낼 수 있습니다.

- **번역해서 보내기:** 상담사가 작성한 답변을 고객 언어로 번역한 뒤 발송합니다.
- **번역하지 않고 보내기:** 입력한 원문을 그대로 발송합니다.

번역해 보낸 메시지에는 상담사가 작성한 내용과 고객에게 전달된 내용을 구분할 수 있도록 `실제 발송` 표기가 나타날 수 있습니다. 전송 전에 고객 언어가 맞는지, 이름·브랜드·시술명 같은 고유명사가 의도대로 표현됐는지 확인하세요.

## 고유명사 확인

번역 기능은 내부 용어집을 이용해 병원명, 브랜드명, 시술명 같은 고유명사가 일관되게 표현되도록 돕습니다.

문맥에 따라 번역이 달라질 수 있으므로 고유명사와 중요한 안내 문구는 실제 발송 전에 확인하세요.

## 상담 전 점검

- [ ] 고객 언어와 상담사 언어가 올바르게 표시됩니다.
- [ ] 자동 감지 결과가 실제 고객 언어와 일치합니다.
- [ ] 번역해서 보낼지 원문 그대로 보낼지 확인했습니다.
- [ ] 이름·브랜드·시술명 등 고유명사가 올바르게 표현됩니다.
- [ ] 날짜, 시간, 금액과 연락 방법이 원문과 일치합니다.
- [ ] 의학적 판단이 필요한 문의를 번역문만으로 확정하지 않습니다.

> **번역은 의료적 판단을 대신하지 않습니다**
>
> 번역 결과는 상담을 돕기 위한 내용입니다. 증상, 치료 결과, 시술 적합성처럼 의료진의 판단이 필요한 내용은 번역문만으로 결론 내리지 말고 병원이 정한 의료진 또는 책임자에게 연결하세요.
