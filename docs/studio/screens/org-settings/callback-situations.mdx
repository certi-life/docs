# 상황별 콜백 - 자주 보내는 알림톡을 묶음으로 만들어 두기

상담사가 "예약 안내", "검사 결과 안내" 같은 알림톡을 보낼 때마다 채널을 고르고 템플릿을 찾고 본문을 쓰는 것은 번거롭고 실수하기 쉽습니다. `상황별 콜백`은 **채널, 템플릿, 기본 본문을 하나의 "발송 상황"으로 묶어 두는 기능**입니다. 상담사는 상황만 고르면 나머지가 함께 채워집니다.

**위치:** 설정 > 운영 설정 > 상황별 콜백

:::info[자동으로 나가는 알림톡은 다른 곳입니다]
여기서 만드는 것은 **상담사가 직접 보낼 때** 고르는 묶음입니다. 콜봇 통화가 끝나면 상담사 조작 없이 자동으로 나가는 알림톡은 [자동메시지의 `AI 전화 콜백`](./auto-messages#콜봇-통화-뒤-알림톡-자동으로-보내기)에서 설정합니다.
:::

## 발송 상황 만들기

**위치:** 설정 > 운영 설정 > 상황별 콜백 > 발송 상황 추가

1. `발송 상황 추가`를 누릅니다. 버튼이 비활성이라면 연동된 알림톡 채널이 없는 것이니 [채널 연동](./channels#카카오-알림톡-채널-연동하기)부터 하세요.
2. `상황 이름`을 적습니다. 상담사 화면의 버튼에 그대로 표시되므로 "예약 안내"처럼 짧고 분명하게 짓습니다.
3. `노출 화면`에서 이 상황을 보여 줄 화면을 고릅니다. `채팅 상담`, `AI 전화 상담` 중 하나 또는 둘 다입니다.
4. `알림톡 채널`과 `알림톡 템플릿`을 고릅니다. 카카오 심사를 통과한 템플릿만 고를 수 있습니다.
5. `기본 본문 (선택)`을 적습니다. 비워 두면 상담사가 발송할 때 직접 작성합니다. 템플릿에 변수가 있다면 `템플릿 변수`에 보낼 내용을 입력합니다.
6. `발송 예시`에서 결과를 확인하고 `확인`을 누른 뒤, 화면 아래 `저장`을 누릅니다.

목록에서 `위로`, `아래로`로 순서를 바꾸면 상담사 화면의 버튼 순서도 바뀝니다. 자주 쓰는 상황을 위에 두세요.

## 알아 둘 점

- **템플릿의 머리말과 맺음말은 바꿀 수 없습니다.** 카카오 심사로 고정되어 있고, `기본 본문`에 쓴 내용만 본문 자리에 들어갑니다. 고칠 수 있는 본문이 없는 템플릿은 심사 통과한 문구가 그대로 발송됩니다.
- 채팅 상담과 전화 상담에서 문구가 달라야 한다면 상황을 하나로 같이 쓰지 말고 따로 만드세요.
- 새 템플릿이 필요하면 [채널 연동](./channels)의 `알림톡 채널`에서 템플릿을 등록해 심사를 받아야 합니다.
- 알림톡은 정보성 메시지입니다. 광고성 내용을 넣지 않도록 [CRM 메시지 발송 전 체크리스트](../../../products/crm-messaging/message-checklist)를 확인하세요.
