# 이벤트 마케팅

이벤트 마케팅은 고객별 경험을 연결하고 **병원과 브랜드의 접점을 확장**하는 데 활용할 수 있습니다.

## 준비 순서

1. 이벤트의 목적과 대상 고객을 정합니다.
2. 고객이 이해하기 쉬운 혜택과 참여 방법을 작성합니다.
3. 기간, 대상, 유의사항을 검토합니다.
4. 공개 전에 담당자가 표현과 조건을 최종 확인합니다.
5. 종료 후에는 노출 중인 안내를 최신 상태로 정리합니다.

## 공개 전 체크리스트

- [ ] 실제 제공 가능한 혜택인가요?
- [ ] 시작일과 종료일이 명확한가요?
- [ ] 대상과 제외 조건이 명확한가요?
- [ ] 고객 개인정보를 불필요하게 수집하지 않나요?
- [ ] 병원과 브랜드의 승인된 표현을 사용했나요?
