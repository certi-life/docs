# 자동메시지 - 상담 중 자동으로 나가는 안내 정하기

> Studio 설정의 자동메시지에서 고객 정보 수집, 상담 시작·완료 메시지, 상담원 배정 메시지, 운영 시간 외 메시지, AI 전화 콜백 문자를 설정하고 변수와 이미지를 넣는 방법, 카카오 상담톡에서 달라지는 점을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/org-settings/auto-messages)

고객이 상담을 요청하면 "상담원을 연결하고 있습니다", 시간 외에는 "내일 오전에 답변드리겠습니다" 같은 안내가 자동으로 나가야 고객이 기다릴 수 있습니다. `자동메시지`에서는 **상담의 각 시점에 자동으로 나가는 문구**를 정합니다. 문구는 조직의 말투로 바꾸고, 고객이 언제 어떻게 답을 받을지 구체적으로 적는 것이 핵심입니다.

**위치:** 설정 > 자동메시지

## 어떤 메시지를 바꿀 수 있나요?

| 탭          | 메시지            | 언제 나가나요                                                                                                   |
| ---------- | -------------- | --------------------------------------------------------------------------------------------------------- |
| `고객 정보 수집` | 정보 입력 화면       | 상담 전에 고객에게 이름·연락처 등을 받을 때                                                                                 |
| `상담 시작/완료` | `상담 시작 메시지`    | 고객이 상담을 시작할 때                                                                                             |
|            | `상담 완료 메시지`    | 상담원이 상담을 완료할 때. 상태가 '완료'가 되는 경우와 '종료'가 되는 경우 모두 나갑니다                                                      |
| `상담원 배정`   | `상담원 배정 메시지`   | 상담원이 배정되었을 때                                                                                              |
|            | `상담원 비활성화 메시지` | 모든 상담원이 비활성화 상태일 때                                                                                        |
| `운영 시간 외`  | `운영 시간 외 메시지`  | 설정된 [상담 시간](https://docs.certi.life/guide/studio/screens/org-settings/hours#채팅-상담-가능-시간-정하기) 외에 고객이 문의할 때 |
| `AI 전화 콜백` | `콜백 문자`        | 콜봇 통화가 끝났을 때                                                                                              |

## 메시지 문구 바꾸기

**위치:** 설정 > 자동메시지 > 상담 시작/완료

1. 바꿀 메시지의 탭을 엽니다.
2. `메시지 내용`을 고칩니다. 오른쪽 `메시지 예시`에서 고객에게 보일 모습을 확인합니다.
3. 고객 이름처럼 그때그때 달라지는 값은 `변수 안내`를 눌러 `삽입` 버튼으로 넣습니다. 발송 시점의 값으로 바뀌어 나갑니다.
4. 필요하면 `이미지 첨부`로 이미지를 넣습니다. JPG, PNG, 최대 5MB이며 `2:1` 또는 `3:4` 비율로 잘립니다.
5. 화면 아래 "변경사항이 있습니다" 저장 바의 `저장`을 누릅니다.

`메시지 내용 *`의 `*`는 필수라는 뜻입니다. 내용을 비운 채 `저장`하면 저장되지 않고 "Request failed with status code 400"이 나옵니다. 어떤 메시지를 보내지 않으려면 내용을 지우지 말고, 그 메시지 제목 오른쪽의 스위치를 끈 뒤 `저장`합니다. 해결 순서는 [문제가 생기면](https://docs.certi.life/guide/studio/screens/org-settings/auto-messages#문제가-생기면)에 있습니다.

> **변수는 직접 치지 말고 삽입 버튼을 쓰세요**
>
> 변수를 손으로 입력하다 오타가 나면 바뀌지 않은 채 그대로 고객에게 나갑니다. `변수 안내` 창의 `삽입` 버튼을 쓰는 것이 안전합니다.

`운영 시간 외 메시지`에는 "지금은 상담 시간이 아닙니다"로 끝내지 말고, 상담 가능 시간과 답변 받을 시점을 함께 적어 주세요.

## 상담 전에 고객 정보 받기

**위치:** 설정 > 자동메시지 > 고객 정보 수집

상담원이 연결되기 전에 고객에게 이름과 연락처를 받아 두면, 고객이 채팅창을 떠나도 연락할 수 있습니다.

1. `안내 문구`의 `제목`과 `부가 설명`을 적습니다.
2. `수집 항목`에서 `고정 항목`(`이름`, `연락처`, `이메일`, `생년월일`) 중 받을 것을 고릅니다. 최소 1개는 필요합니다.
3. 더 필요한 정보는 `커스텀 항목`으로 추가합니다. 최대 3개이며 `항목명`, 입력 형태(`한 줄` / `여러 줄`), `필수` 여부를 정합니다.
4. 오른쪽 `미리보기`에서 고객에게 표시되는 정보 수집 화면을 확인하고 `저장`합니다.

함께 정할 수 있는 알림이 두 가지 있습니다.

- **`정보 수집 완료 알림`:** 켜면 고객이 정보를 입력한 뒤에 상담 인입 알림이 갑니다. 입력 전에는 알림이 가지 않습니다.
- **`이탈 고객 답변 알림`:** 웹채팅을 떠난 고객에게 상담원의 답변을 SMS로 알립니다. 연락처를 수집한 고객에게만 해당하며, 채팅창에서 5분 이상 활동이 없거나 채팅창을 떠났을 때 발송됩니다. 발송 후 3분 안에 다시 방문하면 중복 발송되지 않습니다.

> **꼭 필요한 항목만 받으세요**
>
> 항목이 많을수록 고객이 입력을 포기합니다. 연락에 필요한 최소한만 받고, 주민등록번호나 상세한 증상 같은 민감한 정보는 받지 마세요. 기준은 [개인정보 및 보안](https://docs.certi.life/guide/help/privacy-security)을 참고하세요.

상담 중에 추가로 정보를 요청하려면 상담원이 [상담 화면에서 `정보 수집 메시지 발송`](https://docs.certi.life/guide/studio/screens/counsel/customer#대화-중에-고객-정보-요청하기)을 씁니다.

## 콜봇 통화 뒤 알림톡 자동으로 보내기

**위치:** 설정 > 자동메시지 > AI 전화 콜백

콜봇 통화가 끝나면 상담사가 누르지 않아도 고객에게 알림톡을 자동으로 보낼 수 있습니다. 어느 설정으로 나갈지는 **통화가 끝난 시각이 상담 시간 안인지 밖인지**로 정해집니다.

| 블록        | 적용되는 때                                         | 기본     |
| --------- | ---------------------------------------------- | ------ |
| `상담 외 시간` | 상담 시간이 아닐 때 통화가 끝난 경우. 상담사가 바로 응대할 수 없는 시간대입니다 | 발송     |
| `상담 시간`   | 상담 시간 안에 통화가 끝난 경우. 상담사가 직접 응대하는 시간대입니다        | 발송 안 함 |

위쪽 토글을 `사용 안함`으로 두면 두 블록의 설정과 관계없이 통화 후 알림톡을 보내지 않습니다. 이 탭은 화면 안의 `저장` 버튼으로 따로 저장합니다. AI 콜봇이 연동되어 있지 않으면 설정해도 발송되지 않습니다.

## 카카오 상담톡에서는 다르게 동작할 수 있습니다

화면 위쪽에 "카카오 상담톡 유료 메시지가 꺼져 있습니다"라는 안내가 보인다면, 카카오 채널에서는 다음과 같이 동작합니다.

- 상담 시작과 운영 시간 외 문구가 카카오의 기본 문구로 대체되고 변수도 바뀌지 않습니다.
- 상담원 배정과 고객 정보 수집 메시지는 발송되지 않습니다.
- 상담 완료와 상담원 비활성화 메시지는 그대로 발송됩니다.

여기에 적은 문구를 카카오 채널에서도 그대로 쓰려면 `채널 설정에서 변경하기`를 눌러 [`카카오 상담톡 유료 메시지`](https://docs.certi.life/guide/studio/screens/org-settings/channels#카카오-상담톡-유료-메시지)를 켭니다.

## 문제가 생기면

### `Request failed with status code 400`

`저장`을 눌렀지만 자동메시지가 저장되지 않았다는 뜻입니다. 이 화면에서는 이번에 고친 메시지 가운데 `메시지 내용 *`이 빈 메시지가 있을 때 이 문구가 나옵니다. 스위치만 끈 메시지도 고친 메시지에 들어가므로, 내용이 비어 있으면 저장되지 않습니다. 빈 칸에도 기본 문구가 흐리게 보이지만, 이 글자는 예시일 뿐 내용으로 저장되지 않습니다.

1. `상담 시작/완료`, `상담원 배정`, `운영 시간 외` 탭을 차례로 열고, 이번에 고친 메시지 가운데 `메시지 내용`이 비어 있는 메시지를 찾습니다.
2. 빈 칸에 문구를 적습니다. 그 메시지를 보내지 않으려면 문구는 채워 두고 메시지 제목 오른쪽의 스위치를 끕니다.
3. 화면 아래 저장 바의 `저장`을 누릅니다. "설정이 저장되었습니다"가 나오면 저장된 것입니다.

저장하지 않고 다른 메뉴로 이동하면 고친 내용이 반영되지 않으므로, 저장이 끝날 때까지 이 화면에 머뭅니다. 모든 메시지에 내용이 있는데도 같은 문구가 나오면 연 탭 이름과 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.
