# 백과사전 - 조직의 상담 지식 문서 관리하기

> Studio 백과사전(화면 제목 상담 백과사전)에서 태그와 폴더로 상담 지식을 정리하고, 태그 추가로 새 문서를 작성하거나 파일을 업로드하고, 파일로 문서를 덮어쓰고, 버전 기록에서 예전 버전으로 복원하고, 봇 칩과 챗봇 시점으로 문서를 쓰는 챗봇을 확인·연결하고, 태그 이름을 바꾸고, 인용문으로 상담원용 빠른 입력 문구를 만들고, 고객 태그를 관리하는 방법을 목적별로 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/encyclopedia)

`백과사전`은 조직의 상담 지식을 한곳에 모아 두는 문서 보관소입니다. 여기 등록한 문서는 세 군데에서 함께 쓰입니다. v2 챗봇의 학습자료로 연결되고, 콜봇의 지식 베이스에 담기고, 상담원이 [상담](https://docs.certi.life/guide/studio/screens/counsel/reply-tools#상담-백과사전에서-찾아-넣기) 화면의 `상담 백과사전`에서 찾아봅니다. **문서를 한 번만 잘 관리하면 챗봇, 콜봇, 상담원의 안내가 같은 내용으로 맞춰집니다.**

**위치:** 백과사전 (화면 제목은 `상담 백과사전`으로 표시됩니다)

문서를 만드는 방법은 두 가지입니다. `태그 추가`로 빈 문서를 만들어 직접 쓰거나, `파일 업로드`로 가지고 있는 파일을 문서로 바꿉니다. 이미 있는 문서를 파일로 통째 바꾸려면 그 문서를 연 뒤 위쪽 `업로드`를 씁니다.

## 구조 이해하기: 폴더, 태그, 문서

백과사전은 **태그**가 중심입니다. 태그 하나가 주제 하나(예: "주차 안내", "보톡스")이고, 그 태그에 문서가 연결됩니다. 태그가 많아지면 **폴더**로 묶습니다. 왼쪽 목록은 세 부분입니다.

| 영역      | 내용                        |
| ------- | ------------------------- |
| `즐겨찾기`  | 자주 쓰는 폴더와 태그. ★를 눌러 추가합니다 |
| `폴더`    | 폴더와 그 안의 태그               |
| `폴더 없음` | 어느 폴더에도 속하지 않은 태그         |

위쪽 `태그 키워드 검색`으로 태그를 찾고, `모두 접기` / `모두 열기`로 목록을 정리합니다.

## 새 문서 직접 작성하기

**위치:** 백과사전 > 추가 > 태그 추가

1. 왼쪽 아래 `추가`를 누르고 `태그 추가`를 고릅니다.
2. 태그가 만들어지면서 빈 문서가 함께 생기고, 바로 이름을 입력할 수 있습니다. 주제가 드러나게 짓습니다.
3. 오른쪽 편집기에 내용을 씁니다. 보이는 모습 그대로 편집하는 방식이며, 위쪽 서식 도구로 굵게, 밑줄, 제목, `목록`, `번호 목록`, `인용`을 넣습니다.
4. 오른쪽 위 `저장`을 누릅니다. 키보드의 Ctrl+S(Mac은 ⌘S)로도 저장합니다. "저장되었습니다"가 나오면 끝입니다.

> **저장하지 않고 이동하면 사라집니다**
>
> 이 화면에는 저장하지 않은 내용을 지켜 주는 확인 창이 없습니다. 다른 태그를 누르거나, 다른 메뉴로 이동하거나, 새로고침하거나, 브라우저 탭을 닫아도 묻지 않고 편집이 사라집니다. 그 전에 반드시 `저장`을 누르세요. 저장할 때마다 새 버전이 기록되므로, 저장한 내용은 [예전 버전으로 되돌리기](https://docs.certi.life/guide/studio/screens/encyclopedia#예전-버전으로-되돌리기)에서 되살릴 수 있습니다. 저장하지 않은 편집은 버전에 남지 않습니다.

## 파일을 올려 문서 등록하기

**위치:** 백과사전 > 추가 > 파일 업로드

1. `추가` > `파일 업로드`를 고릅니다. 여러 파일을 한 번에 올릴 수 있고 파일마다 태그와 문서가 새로 생깁니다. 문서를 열지 않은 상태라면 위쪽 `업로드`도 같은 창을 엽니다.
2. `문서 업로드` 창에 파일을 끌어다 놓거나 눌러서 선택합니다. Office, PDF, CSV 파일을 올릴 수 있고, 형식·개수·크기 한도는 창에 표시됩니다.
3. Excel 파일이라면 `Excel 시트 처리`를 고릅니다. `한 문서로 합치기`는 파일 전체를 문서 하나로, `시트마다 문서로 분리`는 시트마다 「파일명\_시트명」 태그를 만듭니다.
4. `업로드`를 누릅니다.

올린 파일은 문서로 변환되는 데 시간이 걸립니다. 진행 상황은 오른쪽 아래 업로드 트레이에서 봅니다.

| 트레이의 상태      | 뜻                                       |
| ------------ | --------------------------------------- |
| `대기`, `변환 중` | 처리하고 있습니다                               |
| `준비됨`        | 끝났습니다. `문서 열기`로 바로 확인합니다                |
| `재시도 예정`     | 일시적인 문제로 자동으로 다시 시도합니다. 따로 누를 것은 없습니다   |
| `실패`         | 변환하지 못했습니다. 표시된 사유를 확인하고 파일을 고쳐 다시 올립니다 |

변환된 문서는 원본과 모양이 다를 수 있습니다. 표나 이미지가 많은 파일은 올린 뒤 내용이 제대로 들어왔는지 꼭 열어 보세요.

## 문서 내용 고치기

**위치:** 백과사전 > (태그 선택) > 본문 편집

1. 왼쪽에서 태그를 누르면 오른쪽에 연결된 문서가 열립니다. 문서가 둘 이상이면 `문서 선택`에서 고릅니다.
2. 본문을 고치고 `저장`을 누릅니다.

올렸던 원본 파일이 필요하면 `원본 다운로드`를 누릅니다. 직접 작성한 문서처럼 업로드 원본이 없는 문서는 내려받을 수 없습니다. 일부 문장이 아니라 파일 전체로 바꾸려면 [파일로 문서 덮어쓰기](https://docs.certi.life/guide/studio/screens/encyclopedia#파일로-문서-덮어쓰기)를 보세요.

> **고치면 어디에 반영되나요?**
>
> v2 챗봇은 연결이 "최신 내용 자동 반영"으로 되어 있으면 검색 준비가 끝난 뒤 고친 내용을 자동으로 씁니다. 특정 버전에 고정된 연결은 [AI 학습자료 설정](https://docs.certi.life/guide/studio/screens/chatbot/settings/training-materials#v2-백과사전-문서를-연결하기)에 `수정 내용 미반영`으로 표시되니 거기서 `최신 내용 자동 반영`을 눌러 주세요.

## 파일로 문서 덮어쓰기

**위치:** 백과사전 > (태그 선택) > 업로드

고쳐 쓴 파일이 있고 문서의 태그와 이름은 그대로 두고 싶을 때 씁니다. 새 문서를 추가하지 않고 열려 있는 문서의 내용만 파일 내용으로 바뀝니다.

1. 왼쪽에서 태그를 눌러 바꿀 문서를 엽니다.
2. 위쪽 `업로드`를 누릅니다. 마우스를 올리면 `파일로 이 문서 덮어쓰기`라고 표시됩니다.
3. `이 문서를 덮어쓰게 돼요` 창에서 `이어서 진행`을 누릅니다.
4. `문서 덮어쓰기` 창에서 파일 1개를 고르고 `덮어쓰기`를 누릅니다. 이 창에서는 파일을 하나만 올릴 수 있고 Excel 시트 분리도 없습니다.

변환이 끝나면 문서가 새 내용으로 다시 열립니다. 진행 상황은 업로드 트레이에서 봅니다. 이전 내용은 버전 기록에 남습니다.

> **저장하지 않은 편집은 사라집니다**
>
> 본문을 고치던 중이라면 먼저 `저장`을 누르세요. 확인 창에도 같은 경고가 표시됩니다.

> **추가와 덮어쓰기를 헷갈리지 마세요**
>
> 문서를 하나 더 만들려면 왼쪽 아래 `추가` > `파일 업로드`를 씁니다. 위쪽 `업로드`는 문서가 열려 있을 때만 덮어쓰기로 동작합니다. 챗봇 연결에는 [문서 내용 고치기](https://docs.certi.life/guide/studio/screens/encyclopedia#문서-내용-고치기)와 같은 반영 규칙이 적용됩니다.

## 예전 버전으로 되돌리기

**위치:** 백과사전 > (태그 선택) > 버전 N

문서를 `저장`하거나 [파일로 덮어쓸](https://docs.certi.life/guide/studio/screens/encyclopedia#파일로-문서-덮어쓰기) 때마다 새 버전이 기록됩니다. 문서 위쪽 버튼 줄의 `버전 N`에서 N은 쌓인 버전 수이고, 마우스를 올리면 `이 문서의 버전 기록`이라고 표시됩니다.

1. 왼쪽에서 태그를 눌러 문서를 엽니다.
2. 위쪽의 `버전 N`을 누릅니다. `버전` 창이 열리고 버전이 최신순으로 보입니다. 지금 쓰는 버전에는 `현재`가 붙어 있습니다.
3. 내용을 확인하려면 버전의 `보기`를 누릅니다. 두 버전을 나란히 보려면 `비교하기`를 누르고 두 버전을 차례로 체크한 뒤 `비교`를 누릅니다.
4. 되돌릴 버전의 `이 버전으로 복원`을 누르고, 확인 창에서 `이 버전으로 복원`을 한 번 더 누릅니다.

복원은 기록을 지우지 않습니다. 고른 버전의 내용으로 새 버전이 하나 더 만들어지고, "v2로 복원했습니다. 새 버전 v5이 만들어졌습니다."처럼 표시됩니다. 그래서 복원한 뒤에도 복원 전 내용으로 다시 돌아갈 수 있습니다.

> **저장하지 않은 편집은 버전에 없습니다**
>
> 본문을 고치던 중에 복원하면 확인 창에 "저장하지 않은 편집 내용은 사라져요."가 함께 표시됩니다. 남겨야 할 편집이라면 먼저 `저장`한 뒤 복원하세요.

## 이 문서를 쓰는 챗봇 확인하고 연결하기

**위치:** 백과사전 > (태그 선택) > 봇 N

백과사전 문서는 v2 챗봇의 학습자료로 연결해야 챗봇이 답변에 씁니다. 연결 상태는 이 화면에서 두 가지 방법으로 보고 바꿉니다. 문서 하나씩은 문서 제목 옆의 봇 칩으로, 여러 태그를 한꺼번에는 왼쪽 위의 `챗봇 시점`으로 합니다. 두 방법 모두 응답 버전이 v2인 챗봇만 대상입니다.

### 문서 하나를 챗봇에 연결하기

문서를 열면 제목 옆에 `봇 N` 칩이 보입니다. N은 이 문서를 학습자료로 쓰는 v2 챗봇 수입니다. 아무 챗봇도 쓰지 않으면 `연결된 봇 없음`으로 표시됩니다.

1. `봇 N`(또는 `연결된 봇 없음`) 칩을 누릅니다. v2 챗봇 목록이 열립니다. 챗봇이 많으면 `봇 이름 검색`으로 찾습니다.
2. 연결할 챗봇의 스위치를 켭니다. 켜는 즉시 등록되고 "‘챗봇 이름’에 학습자료로 등록했습니다."가 나옵니다.
3. 연결을 빼려면 스위치를 끄고, `학습자료 등록을 해제할까요?` 창에서 `등록 해제`를 누릅니다. 백과사전 문서와 다른 챗봇의 등록은 그대로 남습니다.

등록된 챗봇 이름 아래에는 `최신 내용 자동 반영`, `버전 N에 고정`, `이전 버전에 고정` 중 하나가 표시됩니다. 이 표시를 누르면 `이 봇에 적용할 버전` 창이 열리고, 그 챗봇이 쓸 버전을 `최신 내용 자동 반영` 또는 특정 버전으로 바꿀 수 있습니다.

### 여러 태그를 한 챗봇에 한꺼번에 연결하기

1. 왼쪽 위 `챗봇 시점`에서 챗봇을 고릅니다. 왼쪽 목록이 이렇게 바뀝니다.
   - 그 챗봇에 학습자료로 등록되지 않은 **태그 줄**이 흐려집니다. 태그 줄은 그 태그에 연결된 문서를 뜻하므로, 목록 위의 안내 "흐린 문서는 이 챗봇에 등록되지 않은 문서입니다"도 이 흐린 태그 줄을 가리킵니다. 흐린 태그도 숨겨지지 않으며 눌러서 열 수 있습니다.
   - **폴더 줄**은 흐려지지 않습니다. 대신 폴더 옆 숫자가 `2/5 등록`처럼 그 챗봇에 등록된 태그 수와 전체 태그 수로 바뀝니다.
   - 오른쪽에 열린 문서 본문은 흐려지지 않습니다. 이 문서가 등록되었는지는 제목 옆 봇 칩으로 확인합니다.
   - 태그와 폴더 앞에 체크박스가 생깁니다.
2. 등록할 태그나 폴더를 체크합니다. 처음 체크한 태그가 등록되지 않은 태그면 등록할 태그만, 등록된 태그면 해제할 태그만 고를 수 있습니다.
3. 아래쪽 막대에서 `학습자료로 등록`(또는 `등록 해제`)을 누릅니다. 고르던 것을 모두 풀려면 `선택 해제`를 누릅니다.
4. 챗봇 시점을 끝내려면 `챗봇 시점` 선택란의 ×를 누릅니다.

문서가 없는 태그는 등록되지 않고 결과에 "건너뜀(문서 없음)"으로 셉니다. 연결 상태와 챗봇이 실제로 쓰는 버전은 챗봇의 [AI 학습자료 설정](https://docs.certi.life/guide/studio/screens/chatbot/settings/training-materials#v2-백과사전-문서를-연결하기)에서도 확인할 수 있습니다.

## 상담원용 빠른 입력 문구 만들기

**위치:** 백과사전 > (태그 선택) > 본문 편집 > 인용

편집기 위쪽에 "인용(>) 기능 사용시 빠른복사 및 빠른기입 기능을 사용하실 수 있어요"라는 안내가 있습니다. 문서에서 **인용으로 적은 문단**은 상담 화면에서 특별하게 동작합니다. 상담원이 그 문단에 마우스를 올리면 `채팅 입력창에 넣기`와 `복사` 버튼이 나타나, 버튼 하나로 고객에게 보낼 문구를 입력창에 넣을 수 있습니다.

그래서 문서는 이렇게 나누어 쓰는 것이 좋습니다.

- **일반 문단:** 상담원이 읽고 이해할 배경 설명, 주의사항
- **인용 문단:** 고객에게 그대로 보내도 되는 완성된 안내 문구

예를 들어 "주차 안내" 문서라면 주차장 위치와 예외 상황은 일반 문단으로, "건물 지하 2층에 2시간 무료 주차가 가능합니다."는 인용으로 적습니다.

## 폴더와 태그로 정리하기

**위치:** 백과사전 > 추가

- **만들기:** `추가`에서 `폴더 추가` 또는 `태그 추가`를 고릅니다.
- **고치기:** 태그 옆의 `태그 수정`을 누르고 `폴더`, `태그명`, `태그색`을 바꾼 뒤 `적용`합니다. 폴더는 `폴더 수정`에서 `폴더명`을 바꿉니다.
- **옮기기:** 태그를 끌어서 순서를 바꾸거나 다른 폴더로 옮깁니다.
- **즐겨찾기:** ★를 누르면 `즐겨찾기`에 모입니다. 상담 화면의 `상담 백과사전`에서도 `즐겨찾기` 탭으로 빠르게 찾을 수 있습니다.
- **잠시 끄기:** 태그의 `활성`을 끕니다. 상위 폴더가 비활성이면 그 안의 태그도 함께 꺼진 것으로 취급되며, 태그 각각의 설정은 유지됩니다.

> **삭제와 이름 변경**
>
> 위쪽의 `삭제`는 문서가 아니라 **태그를 삭제**합니다. 폴더를 삭제하면 안에 있던 태그는 `폴더 없음`으로 이동합니다.
>
> 태그 이름은 `태그 수정`의 `태그명`에서 바꾸고 `적용`을 누릅니다. 문서를 연 상태에서 위쪽의 태그 이름을 눌러 바로 고칠 수도 있습니다. 태그에 연결된 문서가 하나뿐이면 문서 제목도 새 이름으로 바뀝니다. 같은 이름의 태그가 이미 있으면 "중복된 이름은 사용하실 수 없습니다"가 나옵니다.

## 고객 태그 만들기

**위치:** 백과사전 > 추가 > 태그 추가

상담 화면과 CRM에서 고객에게 붙이는 **고객 태그도 백과사전의 태그입니다.** 따로 "고객 태그" 메뉴가 있는 것이 아니라, 여기서 `태그 추가`로 만든 태그가 고객 태그 목록에 나타납니다. 설정(조직 설정)의 `고객 태그` 화면은 목록을 보기만 하는 곳이고, 거기서 `태그 추가`를 누르면 이 화면으로 이동합니다.

고객 분류용 태그(예: "VIP", "재방문")는 폴더를 하나 만들어 모아 두면 지식 문서용 태그와 섞이지 않습니다.

## 어떤 문서를 넣어야 하나요?

백과사전의 문서는 챗봇과 콜봇이 고객에게 그대로 안내할 수 있는 내용입니다. 고객에게 공개해도 되는 승인된 자료만 넣고, 고객 기록이나 내부 메모, 직원 연락처는 넣지 마세요. 같은 내용이 여러 문서에 다르게 적혀 있으면 답변이 흔들리므로 주제당 기준 문서를 하나로 정리하는 것이 좋습니다. 선별과 갱신 기준은 [상담 지식 관리](https://docs.certi.life/guide/studio/knowledge-management)에 있습니다.

## 문제가 생기면

### `중복된 이름은 사용하실 수 없습니다`

바꾸려는 태그 이름을 다른 태그가 이미 쓰고 있다는 뜻입니다. 폴더 이름이 겹치면 "중복된 폴더 이름은 사용하실 수 없습니다"가 나옵니다.

1. `태그 키워드 검색`에 같은 이름을 넣어 이미 있는 태그를 찾습니다.
2. 같은 주제라면 새 이름을 쓰지 말고 이미 있는 태그의 문서를 고칩니다.
3. 다른 주제라면 `태그명`에 구분되는 이름을 넣고 `적용`을 다시 누릅니다.

### `태그를 삭제할 수 없습니다`

지우려는 태그가 고객, 시나리오, 캠페인, 세그먼트 같은 곳에서 아직 쓰이고 있어 삭제하지 않았다는 뜻입니다. 창에는 "(태그 이름) 태그가 아직 쓰이고 있어 삭제하지 않았습니다. 아래에서 떼어낸 뒤 다시 삭제해 주세요."라는 안내와 사용처 목록이 나옵니다.

1. 목록의 사용처마다 `보러 가기`를 눌러 그 화면으로 이동합니다.
2. 그 화면에서 이 태그를 뗍니다.
3. 백과사전으로 돌아와 태그를 다시 삭제합니다.

사용처에 "사용 여부를 확인하지 못해 삭제하지 않았습니다"가 보이면 잠시 뒤 다시 삭제해 봅니다. 그래도 안 되면 태그 이름과 화면의 문구를 적어 조직의 CertiLife 담당자에게 알립니다.

### `저장에 실패했습니다`

본문을 저장하지 못했다는 뜻입니다. 고친 내용은 아직 화면에만 있습니다.

1. 다른 태그나 메뉴로 이동하지 말고 `저장`을 한 번 더 누릅니다.
2. 계속 실패하면 고친 본문을 전부 복사해 메모장 같은 곳에 보관합니다.
3. 화면을 새로고침한 뒤 문서를 다시 열고, 보관한 내용을 붙여 넣어 `저장`합니다.

그래도 안 되면 태그 이름과 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.

### `문서 버전 복원에 실패했습니다`

`이 버전으로 복원`을 눌렀지만 복원되지 않았다는 뜻입니다. `버전` 창을 닫고 문서를 다시 연 뒤 한 번 더 복원합니다. 버전 목록이 비어 있고 `버전 N` 버튼에 마우스를 올렸을 때 "버전 목록을 불러오지 못했습니다"가 보이면 화면을 새로고침합니다. 그래도 안 되면 화면의 문구와 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.
