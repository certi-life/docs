# 상담 - 채팅 상담 화면 한눈에 보기

`상담`은 상담원이 고객과 직접 채팅하는 화면입니다. 챗봇이 넘긴 상담과 고객이 바로 요청한 상담이 모두 여기로 들어옵니다. 상담원의 일은 크게 네 가지입니다. **기다리는 상담을 찾고, 상담을 시작해 답하고, 필요하면 넘기고, 끝나면 정리합니다.** 이 화면은 그 네 가지를 한자리에서 하도록 만들어져 있습니다.

**위치:** 상담

## 화면 구성

| 영역 | 있는 것 | 하는 일 |
| --- | --- | --- |
| 왼쪽 | 상태 탭(`대기`, `진행중`, `완료`, `종료`), 필터, 검색, 상담 목록 | 응대할 상담을 찾습니다 |
| 가운데 | `상담 백과사전` | 답변에 쓸 내용을 찾아 입력창에 넣습니다 |
| 오른쪽 | 대화창, 언어 바(고객·상담사 언어가 표시되는 줄), 입력창 | 고객과 대화하고 번역합니다 |
| 오른쪽 끝 | `고객 정보`, `서티 AI`, `페르소나` 탭 | 고객이 누구인지 확인하고 AI에게 묻습니다 |

모바일에서는 `상담 백과사전`이 보이지 않고, 가로모드는 지원하지 않습니다.

## 상담원의 하루

1. **출근하면** `대기` 탭에서 밤사이 들어온 상담을 확인합니다. → [응대할 상담 찾기](./inbox)
2. **상담을 열고** `바로 상담 시작`을 눌러 응대를 시작합니다. → [상담 시작하고 마무리하기](./handle)
3. **답변할 때** `상담 백과사전`에서 안내 문구를 찾아 넣고, 외국어 고객이면 번역해 보냅니다. → [빠르고 정확하게 답하기](./reply-tools), [외국어 고객과 대화하기](./translation)
4. **고객이 누구인지** 오른쪽 `고객 정보`에서 지난 상담을 확인합니다. → [고객 정보 확인하고 활용하기](./customer)
5. **내가 답하기 어려우면** `이관`으로 다른 상담원에게 넘깁니다. → [다른 상담원에게 넘기기](./handle#다른-상담원에게-넘기기)
6. **끝나면** `상담완료`를 누르고 내용을 정리해 저장합니다. → [상담 마무리하기](./handle#상담-마무리하기)

## 하고 싶은 일로 찾기

| 하고 싶은 일 | 안내 |
| --- | --- |
| 내 상담만, 안 읽은 상담만 보고 싶어요 | [응대할 상담 찾기](./inbox#필터로-좁히기) |
| 특정 고객의 상담을 찾고 싶어요 | [응대할 상담 찾기](./inbox#고객이나-내용으로-검색하기) |
| 외국어로 온 메시지를 읽고 답하고 싶어요 | [외국어 고객과 대화하기](./translation) |
| 자주 하는 안내를 빨리 보내고 싶어요 | [빠르고 정확하게 답하기](./reply-tools#자주-쓰는-답변-빠르게-넣기) |
| 사진이나 파일을 보내고 싶어요 | [빠르고 정확하게 답하기](./reply-tools#파일과-이미지-보내기) |
| 고객 이름과 연락처를 받고 싶어요 | [고객 정보 확인하고 활용하기](./customer#대화-중에-고객-정보-요청하기) |
| 상담 중에 알림톡을 보내고 싶어요 | [고객 정보 확인하고 활용하기](./customer#상담-중에-알림톡-보내기) |
| 오래된 상담을 한꺼번에 닫고 싶어요 | [상담 시작하고 마무리하기](./handle#여러-상담을-한-번에-종료하기) |
| 끝난 상담을 다시 찾아보고 싶어요 | [상담 내역](../conversation-history) |

## 알아 둘 점

- 상담 가능 시간, 알림, 자동으로 나가는 안내 문구, 번역 사용 여부는 이 화면이 아니라 [설정(조직 설정)](../org-settings/overview)에서 정합니다.
- 어떤 문의를 챗봇이 받고 어떤 문의를 사람이 받을지는 [상담원 연결 정책](../../../products/ai-chatbot/handoff-policy)에서 기준을 세웁니다.
- 상담 화면에는 고객의 개인정보와 상담 내용이 표시됩니다. 화면을 공유하거나 캡처할 때는 [개인정보 및 보안](../../../help/privacy-security) 기준을 따르세요.
