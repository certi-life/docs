# 더 신뢰받는 병원 경험을 만듭니다

CertiLife는 **메디컬 인증서를 기반으로 병원과 고객의 관계를 이어주는 고객관리 플랫폼**입니다. 인증서 발행, AI 상담, CRM 메시징과 이벤트 마케팅을 하나의 흐름으로 연결합니다.

## 무엇을 할 수 있나요?

| 서비스 | 해결하는 일 |
| --- | --- |
| **인증서** | 시술과 제품 정보를 고객이 확인하기 쉬운 형태로 전달합니다. |
| **AI 상담** | 반복되는 채팅 상담을 줄이고 중요한 상담에 집중하도록 돕습니다. |
| **CRM 메시징** | 고객에게 필요한 메시지를 적절한 시점에 전달합니다. |
| **이벤트 마케팅** | 고객 경험과 병원 브랜드의 접점을 넓힙니다. |

## 역할에 맞게 시작하세요

CertiLife의 화면은 세 가지입니다. **Hospital**은 병원 관리자가 인증서를 발행하고 환자·계정·알림톡을 관리하는 병원용 화면입니다. **Studio**는 등록한 자료를 기반으로 AI 챗봇 상담을 준비하고 운영하는 서비스이며, 챗봇·상담·CRM·콜봇 화면이 여기에 있습니다. Hospital의 `상담/챗봇 관리` 메뉴를 누르면 Studio가 새 탭으로 열립니다. **Manufacturer**는 제조사 사용자용 화면입니다.

- **병원 원무·데스크·실장**(인증서 발행, 계정, 결제 담당)이라면 [Hospital 계정 접속](./hospital/account-access)에서 시작하세요.
- **병원 소속이지만 AI 상담·CRM·번역을 맡은 담당자**(상담실장, 코디네이터, 콜센터 상담사, 외국인 환자 코디, 마케팅)라면 [Studio 운영 가이드](./studio/overview)에서 시작하세요. 인증서 발행은 Hospital에서, 챗봇·상담·CRM은 Studio에서 합니다.
- **제조사 사용자**라면 [Manufacturer 안내](./manufacturer/overview)에서 공식 접속과 안전한 계정 이용 방법을 확인하세요.
- **Studio 계정을 받은 운영자**라면 [상담 지식 관리](./studio/knowledge-management)를 확인하세요.
- 서비스 구성이 궁금하다면 [빠른 둘러보기](./getting-started/quick-tour)를 먼저 읽어보세요.

:::tip[가장 빠른 시작]
처음 방문했다면 **빠른 둘러보기 → 서비스 소개 → 역할별 안내** 순서로 확인하는 것을 권장합니다.
:::
