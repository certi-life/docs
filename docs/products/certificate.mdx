# 인증서

CertiLife 인증서는 **시술과 제품 정보를 고객에게 안전하고 간편하게 전달**하는 서비스입니다.

## 이런 경우에 유용합니다

- 고객이 받은 시술이나 제품 정보를 쉽게 확인하도록 안내할 때
- 시술 이후에도 고객과 신뢰 기반의 접점을 이어갈 때
- 병원과 제조사의 브랜드 경험을 일관되게 전달할 때

## 기본 흐름

1. 병원에서 인증서 발행에 필요한 정보를 확인합니다.
2. 고객에게 인증서를 전달합니다.
3. 고객은 전달받은 인증서에서 관련 정보를 확인합니다.

:::info[공개 가이드 범위]
구체적인 메뉴명과 발행 단계는 실제 제품 화면과 공개 가능 범위를 검증한 뒤 Hospital 가이드에 추가합니다.
:::
