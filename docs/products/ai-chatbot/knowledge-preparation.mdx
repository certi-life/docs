# AI 상담 지식 준비

AI 상담은 조직이 등록한 자료를 바탕으로 답변합니다. 따라서 많은 문서를 한꺼번에 넣는 것보다, 고객에게 공개할 수 있고 현재 운영과 일치하는 정보를 명확하게 정리하는 것이 먼저입니다. 준비 단계에서는 실제 고객 대화에 포함된 개인정보를 제거하고, 서로 다른 문서의 내용이 충돌하지 않는지 확인해야 합니다.

## 목적

- 자주 묻는 질문에 일관된 근거로 답할 수 있는 자료를 만듭니다.
- 오래된 운영시간, 혜택, 연락처가 답변에 사용되는 일을 줄입니다.
- AI 답변 대상과 담당자 확인 대상을 구분합니다.
- 카카오톡·네이버 톡톡·웹챗봇에서 사용할 공통 정보와 채널별 안내를 정리합니다.

## 준비할 내용

1. 승인된 서비스 소개, 운영시간, 위치, 연락처, 이용 절차
2. 실제로 자주 접수되는 질문 목록에서 개인정보를 제거한 자료
3. 문서별 소유자와 마지막 확인일
4. 답변하지 않을 항목 및 담당자 전달 기준
5. 카카오톡·네이버 톡톡·웹챗봇별 문장 길이와 고객 안내 원칙

## 절차

1. **질문을 모읍니다.** 반복되는 문의를 주제별로 분류하되 이름, 전화번호, 상태를 식별할 수 있는 내용은 제거합니다.
2. **근거를 확인합니다.** 각 질문에 사용할 승인 자료를 연결하고 출처가 없거나 오래된 답변은 제외합니다.
3. **한 질문에 한 결론으로 정리합니다.** 운영시간처럼 분명한 정보는 조건과 예외를 함께 적어 모호함을 줄입니다.
4. **충돌을 해결합니다.** 같은 항목이 문서마다 다르면 담당자가 최신 내용을 확정할 때까지 등록하지 않습니다.
5. **답변 경계를 표시합니다.** 개별 판단, 공개되지 않은 가격이나 정책, 담당자 확인이 필요한 문의를 별도로 분류합니다.
6. **가상 질문으로 시험합니다.** 정상 질문, 표현이 다른 질문, 자료에 없는 질문을 넣어 답변과 전달 기준을 확인합니다.
7. **갱신 일정을 정합니다.** 운영시간이나 행사처럼 자주 바뀌는 항목은 변경 시 즉시 검토하고, 나머지 자료도 정기적으로 확인합니다.

### 가상 예시

“평일 상담 가능 시간은 언제인가요?”라는 질문에는 승인된 운영시간 자료가 있어야 합니다. “제 상황에는 어떤 선택이 맞나요?”처럼 개별 판단이 필요한 질문은 일반 정보만으로 단정하지 않고 담당자 확인 대상으로 구분합니다. 이 예시는 지식 구조를 설명하기 위한 가상 사례입니다.

:::caution[주의]
고객 대화 원문, 연락처, 민감한 개인 정보, 내부 전용 지침을 공개 상담 지식에 그대로 등록하지 마세요. AI가 등록 자료만으로 확인할 수 없는 내용은 자연스럽게 들리더라도 추정해서 답하도록 설계하지 않아야 합니다. 실제 화면의 등록 메뉴와 클릭 경로는 확인된 운영 안내를 따르세요.
:::
