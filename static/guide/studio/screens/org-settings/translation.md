# 번역 설정 - 외국어 채팅 상담 준비하기

> Studio 설정의 운영 설정 > 번역(채팅 번역)에서 번역 사용, 번역 방향(고객이 쓰는 언어·상담사가 읽을 언어), 자동 메시지 번역, 번역·전송 버튼 합치기, 번역 없이 발송할 때 확인을 정하는 방법과 각 옵션이 상담 화면을 어떻게 바꾸는지 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/org-settings/translation)

외국인 고객과 채팅으로 상담하려면 먼저 여기서 `번역 사용`을 켜야 합니다. 켜면 [상담](https://docs.certi.life/guide/studio/screens/counsel/translation) 화면에 언어 바와 번역 버튼이 나타나고, 고객의 메시지는 상담사 언어로, 상담사의 답변은 고객 언어로 번역됩니다. 끄면 상담 화면에서 번역과 관련된 것이 모두 사라집니다.

**위치:** 설정 > 운영 설정 > 번역

이 화면의 설정은 저장 버튼 없이 **변경 후 5초 이내에 적용**되고, 조직의 모든 상담원에게 똑같이 적용됩니다.

## 번역 켜고 방향 정하기

**위치:** 설정 > 운영 설정 > 번역 > 채팅 번역

1. `번역 사용`을 켭니다. 끄면 아래 설정은 적용되지 않습니다.
2. `번역 방향`의 `고객이 쓰는 언어`를 고릅니다. 고객의 국적이 다양하다면 `자동 감지`로 둡니다.
3. `상담사가 읽을 언어`를 고릅니다. 고객이 보낸 메시지를 이 언어로 번역해 보여 주고, 상담사가 보내는 메시지는 반대 방향으로 번역됩니다.

지원 언어는 `한국어`, `영어`, `일본어`, `중국어(간체)`, `중국어(번체)`, `태국어`, `스페인어(멕시코)`, `베트남어`입니다.

> **자동 감지는 이렇게 동작합니다**
>
> 자동 감지는 고객의 처음 세 메시지로 상담방 언어를 정하고, 이후에는 바뀌지 않습니다. 중간에 고객이 다른 언어로 바꿔 쓰거나 감지가 틀렸다면 상담원이 상담 화면의 언어 바에서 그 상담방만 직접 바꿀 수 있습니다. 반대로 여기서 특정 언어를 지정하면 모든 상담방이 그 언어로 시작하고 자동 감지는 돌지 않습니다. 한 나라의 고객만 상대하는 조직이 아니라면 `자동 감지`를 권장합니다.

## 상담원의 전송 방식 정하기

**위치:** 설정 > 운영 설정 > 번역 > 동작

번역을 켜면 상담원은 답변을 "번역한 뒤 확인하고 보내는" 두 단계로 보냅니다. `동작`의 두 옵션이 이 과정을 정합니다. 조직의 상담 방식에 맞게 고르세요.

| 옵션               | 켜면                                                                                           | 이런 조직에                                            |
| ---------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `번역·전송 버튼 합치기`   | 전송 버튼이 「번역」으로 바뀝니다. 한 번 누르면 번역하고, 한 번 더 누르면 번역문을 보냅니다. 번역 없이 보내려면 버튼 오른쪽 화살표에서 「바로 전송」을 고릅니다 | 거의 모든 답변을 번역해 보내는 조직. 번역을 빠뜨릴 일이 없어집니다            |
| `번역 없이 발송할 때 확인` | 상담원이 번역 버튼을 누르지 않고 전송하면 입력창 아래에 확인 문구를 띄웁니다. 전송을 한 번 더 누르면 그대로 보냅니다                          | 번역할 때와 안 할 때가 섞여 있는 조직. 실수로 한국어 그대로 보내는 일을 막아 줍니다 |

두 옵션 모두 **고객 언어와 상담사 언어가 같은 상담방에서는 동작하지 않고** 평소처럼 `전송`입니다. 버튼을 합치면 번역 없이 보내는 길이 「바로 전송」 하나뿐이라 확인 문구는 뜨지 않습니다.

## 자동 메시지도 번역하기

**위치:** 설정 > 운영 설정 > 번역 > 자동 메시지 번역

`자동 메시지 번역`을 켜면 상담 시작 안내 같은 [자동메시지](https://docs.certi.life/guide/studio/screens/org-settings/auto-messages)도 고객 언어로 나갑니다. 단, 상담방 언어가 정해진 뒤부터 적용됩니다. `자동 감지`를 쓰는 경우 언어가 정해지기 전에 나가는 첫 자동 메시지는 한국어로 나갑니다.

## 알아 둘 점

- 번역은 기계 번역입니다. 시술명, 제품명, 지점명 같은 고유명사는 상담원이 발송 전에 `실제 발송` 문구를 확인하는 것이 안전합니다. 확인 절차는 [상담 메시지 번역](https://docs.certi.life/guide/products/ai-chatbot/message-translation)을 참고하세요.
- 의료 판단이 필요한 내용은 번역 여부와 관계없이 의료진이나 담당자에게 연결합니다.
- 챗봇이 외국어 고객에게 직접 답하는 방식은 여기가 아니라 챗봇의 [`AI 설정` > `다국어 응대 방식`](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#외국어로-문의한-고객-응대하기)에서 정합니다.
