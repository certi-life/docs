# 챗봇 삭제 화면

> Studio 챗봇 설정의 챗봇 삭제 화면에서 삭제될 데이터를 확인하고 챗봇 이름과 계정 비밀번호를 입력해 챗봇을 영구 삭제하는 방법과 주의사항을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/delete-chatbot)

`챗봇 삭제`는 챗봇을 영구적으로 삭제하는 화면이며, 삭제한 챗봇은 되돌릴 수 없습니다. 챗봇 상세 화면에서 `설정` 탭을 열고 왼쪽 `설정 메뉴` 맨 아래의 `챗봇 삭제`를 누릅니다. 삭제하기 전에 같은 구성이 다시 필요할 가능성이 있다면 `기본 정보`의 `챗봇 내보내기`로 다른 챗봇에 복사해 두는 방법을 먼저 검토하세요.

## 챗봇 삭제

- **위치:** 챗봇 > 설정 > 챗봇 삭제
- **이 화면에서 할 수 있는 일:** 삭제될 데이터를 확인한 뒤 챗봇을 영구적으로 삭제합니다.
- **주요 항목:** `삭제될 데이터`(`챗봇 이름`, `플로우 수`, `시나리오 수`, `학습 파일 수`), `삭제 확인`.
- **주요 버튼:** `영구 삭제`
- **팁:** 챗봇을 삭제하면 챗봇 설정과 AI 학습 자료, 모든 플로우와 시나리오, 학습 파일이 영구적으로 삭제됩니다. 화면에 "삭제할 수 없습니다"가 표시되면 안내된 사유를 먼저 해결해야 합니다.
- **관련 가이드:** [기본 정보 화면](https://docs.certi.life/guide/studio/screens/basic-info#챗봇-내보내기), [개인정보 및 보안](https://docs.certi.life/guide/help/privacy-security)

## 삭제 확인

- **위치:** 챗봇 > 설정 > 챗봇 삭제 > 삭제 확인
- **이 화면에서 할 수 있는 일:** 챗봇 이름을 정확히 입력하고 `영구 삭제`를 누른 뒤, "정말 삭제하시겠습니까?" 창에서 계정 비밀번호를 입력해 삭제를 확정합니다.
- **주요 버튼:** `영구 삭제`, `삭제`, `취소`
- **팁:** 입력한 이름이 다르면 "챗봇 이름이 일치하지 않습니다"가 표시되고 삭제할 수 없습니다. 삭제는 AI 학습 파일, 시나리오, 플로우, 챗봇 순서로 진행되며 진행 상태가 화면에 표시됩니다. 실제 운영 중인 채널에 연결된 챗봇이라면 삭제하기 전에 채널 연결과 고객 안내를 먼저 정리하세요.
- **관련 가이드:** [채널 설정 화면](https://docs.certi.life/guide/studio/screens/channel-settings), [출시 체크리스트](https://docs.certi.life/guide/studio/launch-checklist)
