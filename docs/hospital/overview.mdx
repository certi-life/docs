# Hospital 안내

Hospital은 병원 사용자를 위한 CertiLife 서비스 진입점입니다.

## 지금 할 수 있는 일

- [CertiLife 서비스 구성](../getting-started/quick-tour)을 먼저 이해합니다.
- [병원용 로그인](https://hospital.certi.life/signin)으로 이동합니다.
- 계정이나 도입 관련 도움이 필요하면 [도입 문의](https://certi.life/contact)를 이용합니다.

## 사용 가이드 안내

인증서 발행과 고객관리 등 화면별 사용 가이드는 준비 중입니다. 현재 이용 중 도움이 필요하다면 조직의 CertiLife 담당자 또는 [도입 문의](https://certi.life/contact)를 통해 지원을 요청해 주세요.

:::note[안전한 화면 공유]
지원을 요청할 때 고객 또는 환자의 이름, 연락처와 같은 개인정보가 화면에 포함되지 않도록 확인하세요.
:::
