# 문제 해결

> CertiLife 공식 서비스 접속과 공개 로그인 문제를 안전하게 점검하는 방법입니다.

[사람이 읽는 원문](https://docs.certi.life/guide/help/troubleshooting)

접속·로그인 문제는 공식 주소, 인터넷 연결, 브라우저와 본인 계정을 순서대로 확인합니다. 계정 생성, 권한 변경 또는 제품 화면의 미확인 메뉴 위치는 다루지 않습니다. 점검 중에도 비밀번호, 인증 코드, 고객·환자 개인정보를 다른 사람에게 보내지 마세요.

## 1. 공식 주소인지 확인하기

먼저 주소 표시줄의 도메인을 직접 확인하세요.

- 병원용 서비스: [Hospital 로그인](https://hospital.certi.life/signin)
- 제조사용 서비스: [Manufacturer 로그인](https://manufacturer.certi.life/signin)
- Studio: [Studio 로그인](https://studio.certi.life)
- 공식 다운로드: [CertiLife 다운로드](https://certi.life/download)

검색 광고나 메신저 링크를 통해 접속했다면 위 링크로 새로 이동합니다. 공식 주소와 다른 페이지가 로그인 정보나 설치 파일을 요구하면 입력하거나 다운로드하지 마세요.

## 2. 로그인 페이지가 열리지 않을 때

1. 다른 일반 웹사이트가 열리는지 확인해 인터넷 연결 상태를 점검합니다.
2. 공식 주소를 새 탭에 직접 열고 페이지를 다시 불러옵니다.
3. 브라우저를 완전히 종료한 뒤 다시 실행합니다.
4. 현재 브라우저가 최신 상태인지 확인하거나, 조직에서 허용한 다른 최신 브라우저로 같은 공식 주소를 열어 봅니다.
5. 회사 또는 병원 네트워크에서만 문제가 발생한다면 다른 허용된 네트워크에서도 동일한지 확인합니다. 보안 설정을 임의로 해제하지 말고 조직의 담당자에게 알리세요.

브라우저의 인증서 경고나 안전하지 않은 연결 경고가 표시되면 경고를 무시하고 진행하지 마세요. 표시된 주소와 시각을 기록한 뒤 조직의 담당자에게 문의합니다.

## 3. 로그인할 수 없거나 로그인이 반복될 때

- 입력한 계정이 본인에게 발급된 계정인지 확인합니다.
- 키보드의 한글/영문 상태, 대문자 입력 상태와 앞뒤 공백을 확인합니다.
- 자동 완성에 오래된 정보가 들어갔다면 직접 다시 입력합니다. 비밀번호를 문서나 메신저에 복사해 확인하지 마세요.
- 브라우저의 비공개 창에서 공식 주소를 열어 같은 문제가 발생하는지 확인합니다.
- 여러 번 추측해 반복 입력하지 말고, 계정 또는 권한 확인이 필요하면 조직의 CertiLife 담당자에게 문의합니다.

공개 도움말은 비밀번호를 조회하거나 계정 권한을 변경할 수 없습니다. 화면에 안내되는 복구 방법이 있더라도 본인 계정에 대해서만 이용하고, 확인되지 않은 연락처가 인증 코드를 요구하면 제공하지 마세요.

## 4. 로그인 후 화면이 예상과 다를 때

조직의 이용 서비스, 계정 권한 또는 설정에 따라 보이는 범위가 다를 수 있습니다. 공개 문서에 없는 버튼이나 메뉴를 추측해 찾지 마세요. 먼저 페이지를 새로 열고 공식 주소인지 확인합니다. 계속 다르면 문제 발생 서비스, 대략적인 발생 시각, 브라우저 종류, 화면에 표시된 오류 문구를 정리해 조직의 담당자 또는 [도입 문의](https://certi.life/contact)에 전달하세요.

## 5. 문의 전에 준비할 정보

아래 정보는 문제 파악에 도움이 되며 비밀번호나 개인정보 없이 정리할 수 있습니다.

- 문제가 발생한 서비스: Hospital, Manufacturer 또는 Studio
- 접속한 공식 주소
- 문제가 발생한 날짜와 대략적인 시각
- 사용한 기기 종류와 브라우저 이름·버전
- 오류가 발생하기 직전 수행한 일반적인 동작 설명
- 화면에 표시된 오류 문구(개인정보 제거 후)
- 다른 허용된 브라우저나 네트워크에서도 같은지 여부

화면 캡처를 첨부해야 한다면 [개인정보 제거 체크리스트](https://docs.certi.life/guide/help/privacy-security)를 먼저 완료하세요. 고객·환자의 이름, 연락처, 진료·시술 정보뿐 아니라 직원 정보, 브라우저 탭, 주소 표시줄의 개인 식별 값, 알림과 파일명도 확인해야 합니다.

## 해결되지 않았나요?

조직의 CertiLife 담당자에게 먼저 문의하세요. 도입 또는 서비스 관련 외부 문의는 [CertiLife 도입 문의](https://certi.life/contact)를 이용할 수 있습니다. 로그인 정보, 인증 코드, 고객·환자 개인정보는 문의에 포함하지 마세요. 가격이나 도입 조건을 찾는 경우에는 [가격 안내](https://certi.life/pricing)도 함께 확인할 수 있습니다.
