# 챗봇 메뉴 시작하기

Studio 왼쪽 메뉴의 `챗봇`은 고객 문의에 자동으로 답하는 챗봇을 만들고 다듬는 곳입니다. 처음이라면 이 페이지에서 전체 그림을 먼저 잡고, 필요한 화면으로 이동하세요. 이미 운영 중이라면 아래 [하고 싶은 일로 찾기](#하고-싶은-일로-찾기) 표에서 바로 찾아가면 됩니다.

**위치:** 챗봇

## 챗봇은 세 가지 방식으로 답합니다

챗봇 하나 안에서 세 가지 답변 방식을 함께 씁니다. 어떤 질문을 어느 방식에 맡길지 정하는 것이 챗봇 구성의 핵심입니다.

| 방식 | 이런 질문에 맞습니다 | 어디서 만드나요 |
| --- | --- | --- |
| **시나리오** | 첫 인사, 업무시간 외 안내처럼 정해진 상황에 항상 같은 메시지를 보내야 할 때 | [`시나리오` 탭](./scenarios) |
| **플로우** | "예약 → 지점 선택 → 안내"처럼 버튼을 눌러 단계별로 따라가는 안내 | [`플로우` 탭](./flows) |
| **AI 답변** | 고객이 자유롭게 입력한 질문. 등록한 학습자료를 근거로 AI가 답합니다 | [`AI 설정`](./settings/ai-settings), [`AI 학습자료 설정`](./settings/training-materials) |

정답이 하나로 정해져 있고 틀리면 안 되는 안내(가격표, 예약 절차)는 시나리오와 플로우로 고정하고, 표현이 다양한 질문은 AI 답변에 맡기는 구성이 가장 안정적입니다.

## 처음 만들 때 권장 순서

1. **챗봇을 만듭니다.** [챗봇 목록](./list)에서 `새 챗봇 만들기`를 누릅니다. 빈 챗봇, 템플릿, 다른 챗봇 복제 중에서 고를 수 있습니다.
2. **AI가 참고할 자료를 넣습니다.** [`AI 학습자료 설정`](./settings/training-materials)에서 공개해도 되는 안내 자료를 올립니다. 어떤 자료를 넣을지는 [상담 지식 관리](../../knowledge-management)를 참고하세요.
3. **말투와 답변 범위를 정합니다.** [`AI 설정`](./settings/ai-settings)에서 페르소나를 고르고, 자료에 없는 내용은 답하지 않게 하려면 `학습자료로만 답변하기`를 켭니다.
4. **첫 인사와 고정 안내를 만듭니다.** [`시나리오` 탭](./scenarios)에서 `시작 시나리오`를 다듬고, 단계형 안내가 필요하면 [`플로우` 탭](./flows)에서 만듭니다. 고객이 사람을 부를 수 있게 하려면 카드 블럭의 버튼에 [`상담사 연결` 동작](./blocks#버튼-동작-정하기)을 넣습니다.
5. **응답하지 않을 시간을 정합니다.** [`작동시간`](./settings/operating-hours)에서 챗봇이 쉬는 시간과 그때 보낼 안내를 정합니다.
6. **채널에 연결합니다.** [`채널 설정`](./settings/channel-settings)에서 웹채팅 스크립트를 복사하거나 카카오톡·네이버 톡톡 등을 연결하고, [`채팅창 설정`](./settings/chat-window-settings)에서 웹채팅 모양을 맞춥니다.
7. **공개 전에 시험합니다.** 가상 질문으로 정상 답변, 답변 거절, 상담원 연결을 확인합니다. 어디서 시험하는지는 아래 [공개 전에 시험하기](#공개-전에-시험하기)에 있습니다. 점검 항목은 [출시 체크리스트](../../launch-checklist)에 있습니다.
8. **운영하면서 보강합니다.** [`통계` 탭](./statistics)에서 챗봇이 답하지 못한 질문을 찾아 답변을 보강합니다.

## 공개 전에 시험하기

**위치:** 챗봇 > (챗봇 선택) > 설정

`시나리오`, `플로우`, `설정` 탭에서 `저장`한 내용은 연결된 채널의 고객 대화에 바로 쓰입니다. 공개 전에 따로 배포하는 단계가 없습니다. 그래서 고객에게 알리기 전에 아래 도구로 시험합니다.

| 시험 도구 | 위치 | 확인할 수 있는 것 | 상담 기록과 통계 |
| --- | --- | --- | --- |
| `이 내용으로 대화해보기` | `설정` > `AI 설정` > `커스텀` (`커스텀 페르소나 설정` 창) | 편집 중인 시스템 프롬프트로 AI가 어떻게 답하는지 봅니다. 저장하지 않은 프롬프트로도 답합니다. 프롬프트와 `기본 페르소나` 외의 설정은 저장된 값을 씁니다 | 남지 않습니다 |
| `웹채팅 URL` | `설정` > `채널 설정` > `웹채팅` | 저장된 설정 전체로 고객과 똑같이 대화합니다. 시나리오, 버튼, AI 답변, 상담원 연결을 모두 확인할 수 있습니다 | 실제 상담으로 기록되고 통계에도 집계됩니다 |
| `미리보기` | `시나리오` 탭 오른쪽, `플로우` 탭 편집 패널의 눈 모양 아이콘 | 메시지와 버튼이 고객에게 어떻게 보이는지 봅니다. 저장하지 않은 편집도 보입니다. 버튼을 눌러 다음 단계로 넘어갈 수는 없습니다 | 남지 않습니다 |
| `실시간 미리보기` | `설정` > `채팅창 설정` | 웹채팅 창의 색, 버튼, 문구를 봅니다. 메시지는 보낼 수 없습니다 | 남지 않습니다 |

카카오톡, 네이버 톡톡 같은 메신저 채널은 연결한 뒤 그 메신저에서 직접 메시지를 보내 확인합니다. 이 대화도 실제 상담으로 기록됩니다.

| 챗봇이 엉뚱한 내용을 지어내지 않게 하고 싶어요 | [`AI 설정`의 `학습자료로만 답변하기`](./settings/ai-settings#자료에-있는-내용만-답하게-하기) |
| 답변에 쓸 자료를 추가하거나 바꾸고 싶어요 | [`AI 학습자료 설정`](./settings/training-materials) |
| 첫 인사 메시지를 바꾸고 싶어요 | [`시나리오` 탭](./scenarios) |
| 버튼으로 이어지는 안내를 만들고 싶어요 | [`플로우` 탭](./flows) |
| 밤이나 주말에는 챗봇을 끄고 싶어요 | [`작동시간`](./settings/operating-hours) |
| 고객이 사람과 대화하고 싶을 때 상담원에게 연결하고 싶어요 | 버튼으로 연결: [블럭과 버튼](./blocks#버튼-동작-정하기)의 `상담사 연결`, 채널 전체를 처음부터 사람이 받게: [`채널 설정`](./settings/channel-settings#챗봇-없이-바로-상담원에게-연결하기)의 `상담원 바로 연결`, 쉬는 시간 안내: [`작동시간`](./settings/operating-hours)의 `미작동 시나리오` |
| 홈페이지에 채팅 버튼을 달고 싶어요 | [`채널 설정`](./settings/channel-settings), [`채팅창 설정`](./settings/chat-window-settings) |
| 카카오톡·네이버 톡톡·Instagram 등에 연결하고 싶어요 | [`채널 설정`](./settings/channel-settings) |
| 챗봇이 대화 중에 고객 이름·연락 희망 시간을 챙기게 하고 싶어요 | [`도구`](./settings/tools) |
| 특정 상황에서 정해진 절차대로 응대하게 하고 싶어요 | [`매뉴얼`](./settings/manuals) |
| 챗봇이 답하지 못한 질문을 확인하고 싶어요 | [`통계` 탭](./statistics) |
| 챗봇을 지금 멈추고 싶어요 | [챗봇을 지금 멈추기](#챗봇을-지금-멈추기) |

## 챗봇을 지금 멈추기

**위치:** 챗봇 > (챗봇 선택) > 설정 > 채널 설정

Studio에는 챗봇 전체를 한 번에 끄는 스위치가 없습니다. 그래서 채널마다 챗봇 연결을 끊습니다. 연결을 끊어도 챗봇과 설정은 그대로 남으므로, 다시 연결하면 바로 이전처럼 답합니다.

| 채널 | 멈추는 방법 | 멈춘 뒤 고객이 메시지를 보내면 |
| --- | --- | --- |
| `웹채팅` | 웹사이트에 붙인 `SDK 스크립트`를 지웁니다. Studio에는 웹채팅만 끄는 스위치가 없습니다 | 채팅 버튼이 사라집니다. `웹채팅 URL`로는 계속 대화할 수 있습니다 |
| `카카오톡` (`오픈빌더 (스킬)`) | `카카오톡` 카드 제목 오른쪽의 스위치를 끄거나 `카카오 오픈빌더 Bot ID`를 `삭제`한 뒤 `저장`을 누릅니다 | 챗봇 답변 대신 "죄송합니다. 일시적인 오류로 답변을 준비하지 못했습니다. 잠시 후 다시 시도해 주세요."가 나갑니다 |
| `카카오톡` (`상담톡 봇`) | 상담톡 채널 선택을 지우고 `저장`을 누릅니다 | 챗봇 없이 상담 대기로 들어옵니다 |
| `네이버 톡톡` | `연결 해제`를 누르고 확인 창에서 `해제`를 누릅니다. `저장` 없이 바로 적용됩니다 | 챗봇 없이 상담 대기로 들어옵니다 |
| `Instagram`, `LINE`, `WhatsApp` | 카드의 `연동 채널` 선택칸에서 지우기 아이콘을 눌러 배정을 지웁니다. `저장` 없이 바로 적용됩니다 | 챗봇 없이 상담 대기로 들어옵니다 |

챗봇은 계속 연결해 두고 고객을 처음부터 상담원에게 보내려면 [`상담원 바로 연결`](./settings/channel-settings#챗봇-없이-바로-상담원에게-연결하기)을 켭니다. `카카오톡`에서 켜면 오픈빌더 방식은 모든 요청에 상담원 연결 안내 카드를 보내고, 상담톡 봇 방식은 바로 상담원에게 연결합니다. `네이버 톡톡`에서 켜면 챗봇이 답하지 않고 상담 대기로 시작합니다. `웹채팅`에서 켜면 첫 진입만 상담 대기로 시작하므로 챗봇을 완전히 멈추지는 않습니다.

정해진 시간에만 멈추려면 [`작동시간`](./settings/operating-hours)에서 쉬는 시간을 정합니다. 그 시간에는 모든 채널에서 AI 답변 대신 `미작동 시나리오`가 나갑니다. 채널에 따라 새 대화는 `미작동 시나리오` 대신 바로 상담원 연결로 이어질 수 있습니다. 하루 종일 멈추려면 요일마다 `종일`을 누릅니다.

웹채팅의 `상담 진행 여부`를 꺼도 챗봇은 계속 답합니다. 이 스위치는 상담원 연결만 막습니다. 챗봇을 아예 없애야 할 때만 [`챗봇 삭제`](./settings/delete-chatbot)를 씁니다. 삭제는 되돌릴 수 없습니다.

## 화면은 이렇게 생겼습니다

`챗봇` 메뉴에 들어오면 챗봇 카드 목록이 보이고, 위쪽에 `챗봇`, `도구`, `매뉴얼` 탭이 있습니다. `도구`와 `매뉴얼`은 조직의 모든 챗봇이 함께 쓰는 공용 목록이며 `v2 beta`로 표시됩니다.

카드의 `상세보기`를 누르면 챗봇 상세 화면으로 들어가고, 위쪽의 `시나리오`, `플로우`, `통계`, `설정` 네 탭으로 작업합니다. `시나리오`, `플로우`, `설정` 탭에서 바꾼 내용은 왼쪽 아래 `저장`을 눌러야 적용됩니다. 저장하지 않고 다른 곳으로 이동하려 하면 `저장하지 않은 변경사항이 있습니다` 확인 창이 나옵니다. 창의 버튼별 동작은 [설정 한눈에 보기](./settings/menu#저장하지-않은-변경사항이-있습니다)에 있습니다.

:::tip[v1과 v2]
챗봇마다 응답 버전(`v1` 또는 `v2`)이 있습니다. `도구`와 `매뉴얼`은 v2에서만 동작하며, 버전은 [`AI 설정`의 `응답 버전`](./settings/ai-settings#응답-버전-바꾸기)에서 바꿉니다.
:::
