# Studio 시작하기

이 영역은 Studio의 공개 사용 가이드를 위한 공간입니다. 기능을 추정하지 않고, 승인된 작업 시나리오와 실제 화면에서 검증한 내용만 단계별로 제공합니다.

## 문서화 우선순위

공개 가능한 범위가 확인되면 다음 순서로 가이드를 확장합니다.

1. Studio의 역할과 기본 구조
2. 워크스페이스 시작하기
3. 첫 AI 상담 구성하기
4. 안내 정보와 지식 준비하기
5. 테스트하고 운영 준비하기
6. 결과 확인과 개선하기

:::info[현재 상태]
구체적인 메뉴와 설정 절차는 작업 시나리오를 전달받은 뒤 실제 화면에서 검증하여 추가합니다.
:::

## 안전한 운영을 위한 기본 원칙

- 고객에게 공개해도 되는 정보만 사용합니다.
- 의료진의 판단이 필요한 질문과 일반 안내의 경계를 정합니다.
- 테스트 데이터에는 실제 고객이나 환자 정보를 넣지 않습니다.
- 공개 전 담당자가 답변 범위와 연결 조건을 확인합니다.
