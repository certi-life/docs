# AI 학습자료 설정 - 챗봇이 참고할 자료 넣기

AI 답변의 품질은 여기에 넣은 자료가 결정합니다. 챗봇은 학습자료에 있는 내용을 근거로 답하므로, 자료가 없거나 오래되면 답도 비거나 틀립니다. 자료를 넣는 방법은 챗봇의 응답 버전에 따라 다릅니다. **v1은 파일을 직접 올리고, v2는 백과사전에 등록된 문서를 연결합니다.**

**위치:** 챗봇 > (챗봇 선택) > 설정 > AI 학습자료 설정

왼쪽 메뉴 이름은 `AI 학습자료 설정`이고, 열린 화면의 제목은 `AI 학습자료 관리`입니다. 같은 화면입니다. 이 화면의 작업은 바로 적용되므로 왼쪽 아래 `저장` 버튼을 누르지 않습니다.

## 먼저 버전을 확인하세요

**위치:** 챗봇 > 설정 > AI 학습자료 설정 > AI 학습자료 관리

화면 제목 옆의 `v1` / `v2` 버튼은 **어느 버전의 자료를 관리할지** 고르는 것입니다. 챗봇이 실제로 어느 버전으로 답하는지는 여기가 아니라 [`AI 설정`의 `응답 버전`](./ai-settings#응답-버전-바꾸기)에서 정합니다.

| 챗봇의 응답 버전 | 자료를 넣는 방법 |
| --- | --- |
| v1 | [파일을 직접 올립니다](#v1-파일을-올려-학습시키기) |
| v2 | [백과사전 문서를 연결합니다](#v2-백과사전-문서를-연결하기) |

화면은 현재 응답 버전에 맞는 쪽을 자동으로 열어 줍니다. v2는 동기화한 자료를 사용하므로, 챗봇이 v2로 답하는데 v1 쪽에 새 파일을 올렸다면 [`AI 설정`의 `학습자료 동기화`](./ai-settings#응답-버전-바꾸기)를 실행해야 답변에 반영됩니다.

## v1: 파일을 올려 학습시키기

**위치:** 챗봇 > 설정 > AI 학습자료 설정 > 파일 업로드

1. `v1`을 고른 상태에서 `파일 업로드`를 누르고 파일을 선택합니다. 어떤 형식을 올릴 수 있는지는 `지원 파일 형식 보기`에서 확인합니다(문서, 텍스트, 마크업 등).
2. 업로드가 끝나면 `전체 파일 목록`에 파일이 나타나고 상태가 `처리중` → `업로드 완료` → `학습완료`로 바뀝니다. **`학습완료`가 되어야 챗봇이 그 자료로 답합니다.**
3. `실패`로 표시된 파일은 `재시도`를 누르거나, 파일을 확인해 다시 올립니다.

파일은 한 개에 50MB 이하여야 하고, 올릴 수 있는 개수는 화면에 표시됩니다. 위쪽 `파일 통계`에서 상태별 개수를 한눈에 볼 수 있습니다. 올린 파일은 `파일 다운로드`로 내려받거나 `파일 삭제`로 지웁니다.

:::caution[처리 중에는 화면을 떠나지 마세요]
업로드, 삭제, 재시도가 진행되는 동안에는 "처리가 완료될 때까지 페이지를 새로고침하거나 이동하지 마세요."라는 안내가 뜹니다. 처리 중인 파일은 삭제할 수 없습니다.
:::

파일 목록에 `보강 Q&A · 자동 관리`라고 표시된 파일은 [`통계` > `Q&A 보강`](../statistics#질문과-답을-직접-등록하고-시험하기)에서 저장한 보강 답변이 모인 파일입니다. 여기서는 지울 수 없고 통계 화면에서 관리합니다.

### 병원 기본 정보로 Q&A 자동 만들기

**위치:** 챗봇 > 설정 > AI 학습자료 설정 > 병원 정보 기반 학습자료 생성

자료를 준비할 시간이 없다면 `병원 정보 기반 학습자료 생성`의 `학습자료 생성`을 누르세요. 병원 기본 정보를 바탕으로 Q&A 학습자료가 자동으로 만들어집니다. 챗봇을 만들 때 자동 생성을 체크하지 않았거나 그때 실패했더라도 여기서 다시 만들 수 있습니다. 만들어진 내용은 실제 안내와 맞는지 꼭 확인하세요.

## v2: 백과사전 문서를 연결하기

**위치:** 챗봇 > 설정 > AI 학습자료 설정 > 연결된 학습자료

v2에서는 문서를 챗봇마다 따로 올리지 않습니다. 조직의 문서는 [`백과사전`](../../encyclopedia)에 한 번만 등록하고, 챗봇에는 그 문서를 **연결**합니다. 같은 문서를 여러 챗봇이 함께 쓰고, 백과사전에서 고치면 연결된 챗봇에 반영되는 구조입니다.

1. `v2`를 고르면 `연결된 학습자료`와 그 아래 백과사전 카탈로그 태그 목록이 보입니다.
2. `카탈로그 태그 검색`으로 찾거나 폴더를 펼쳐, 넣을 태그 옆의 +를 눌러 `추가할 학습자료`에 담습니다.
3. **`이 챗봇에 연결`을 누릅니다.** 담기만 해서는 연결되지 않습니다.
4. 위쪽 `연결된 학습자료` 목록에 나타났는지 확인합니다.

연결된 자료마다 상태가 표시됩니다.

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| (표시 없음) | 최신 내용이 자동으로 반영되고 있습니다 | 없음 |
| `수정 내용 미반영` | 특정 문서 버전에 고정되어, 백과사전에서 고친 내용이 반영되지 않고 있습니다 | `최신 내용 자동 반영`을 누릅니다 |
| `카탈로그 확인 필요` | 백과사전에서 태그가 비활성화되었거나 찾을 수 없습니다 | `백과사전`에서 태그 상태를 확인합니다 |

자료를 빼려면 `연결 해제`를 누릅니다. 이 챗봇에서만 빠질 뿐, 백과사전의 원본 문서와 다른 챗봇의 연결, v1 자료는 그대로 남습니다. 문서 내용을 고치려면 `수정`을 눌러 백과사전으로 이동합니다.

## 어떤 자료를 넣어야 하나요?

무엇을 넣을지는 화면 조작보다 중요합니다. 고객에게 공개해도 되는 정확한 자료만 넣고, 고객 기록이나 내부 메모는 넣지 않습니다. 같은 내용이 여러 자료에 다르게 적혀 있으면 챗봇 답변도 흔들립니다. 자료 선별과 갱신 기준은 [상담 지식 관리](../../../knowledge-management)와 [AI 상담 지식 준비](../../../../products/ai-chatbot/knowledge-preparation)에 정리되어 있습니다.

자료를 넣은 뒤에는 [`AI 설정`의 `학습자료로만 답변하기`](./ai-settings#자료에-있는-내용만-답하게-하기)를 켤지 정하고, 운영하면서 [`통계` 탭](../statistics)에서 챗봇이 답하지 못한 질문을 찾아 자료를 보완하세요.
