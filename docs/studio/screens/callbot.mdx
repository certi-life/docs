# 콜봇 - 전화를 받는 AI 상담원 만들기

`콜봇`은 전화 문의를 AI 상담원(에이전트)이 받도록 만드는 곳입니다. 채팅의 [챗봇](./chatbot/overview)과 같은 역할을 전화에서 합니다. 처음이라면 왼쪽의 `시작하기`부터 여세요. 조직을 만들고 실제 전화를 받기까지의 단계를 순서대로 안내하고, 어디까지 진행했는지 표시해 줍니다.

**위치:** 콜봇

:::info[조직의 이용 범위에 따라 보입니다]
`콜봇` 메뉴는 조직의 이용 범위에 따라 보이지 않을 수 있습니다. 필요하다면 조직의 CertiLife 담당자 또는 [도입 문의](https://certi.life/contact)로 확인하세요.
:::

## 메뉴 구성

| 그룹 | 메뉴 | 하는 일 |
| --- | --- | --- |
| `시작` | `시작하기` | 콜봇을 실제로 쓰기까지의 단계와 진행 상태를 봅니다 |
| `AI 상담원 만들기` | `에이전트` | AI 상담원을 만들고 배포합니다 |
| | `보이스` | 에이전트가 쓸 목소리를 관리합니다 |
| | `도구` | 통화 전환, API 호출 등 에이전트가 쓸 도구를 만듭니다 |
| | `매뉴얼` | 상황별 응대 절차를 작성합니다 |
| | `지식 베이스` | 에이전트가 참고할 문서를 담습니다 |
| `캠페인` | `캠페인` | 목록에 있는 번호로 콜봇이 전화를 겁니다 |
| `설정` | `번호 관리` | 전화번호를 구매·연동하고 에이전트에 연결합니다 |
| | `조직 인증` | 번호 구매 등에 필요한 사업자 인증을 신청합니다 |

## 실제 전화를 받기까지

**위치:** 콜봇 > 시작하기

`콜봇 시작하기` 화면의 단계를 따라가면 됩니다. 각 단계에서 자주 막히는 지점을 함께 적었습니다.

1. **에이전트 만들기** - `에이전트`에서 `새 에이전트`를 누릅니다. `통화 방향`, `에이전트 타입`, `생성 방식`을 차례로 고릅니다. 생성 방식은 `프롬프트`, `플로우`, `가져오기` 중에서, 타입은 `맞춤형`, `템플릿`, `스마트 ARS`, `빈 에이전트` 중에서 고릅니다. AI가 써 준 응대 내용은 초안이므로, 영업시간이나 가격처럼 사실이 걸린 문장은 반드시 확인하고 고치세요.
2. **도구 넣기** - 도구가 없으면 콜봇이 모르는 질문을 받았을 때 통화를 그냥 끝냅니다. 사람 연결이 필요한 업무라면 통화 전환 도구를 꼭 넣으세요.
3. **지식 베이스 만들기** - `지식 베이스`에서 `새 지식 베이스`를 만들고 문서를 추가합니다. 콜봇 지식 베이스에는 [백과사전](./encyclopedia)에 등록된 문서만 넣을 수 있습니다. 그리고 **문서를 담는 것만으로는 콜봇이 쓰지 않습니다. 에이전트에 연결해야** 실제 응대에 반영됩니다.
4. **조직 인증** - `조직 인증`에서 `인증 유형`과 `신청자 구분`을 고르고 사업자등록증(임직원 신청이면 재직증명서 포함)을 올려 `인증 신청`을 누릅니다. 승인 전에는 번호 구매가 막혀 있고 심사에 시간이 걸리니, 앞 단계를 진행하면서 미리 신청해 두세요.
5. **번호 연결** - `번호 관리`에서 `추가`를 눌러 번호를 구매하거나 `SIP 트렁크 연동`, `발신표기번호 등록`을 합니다. 번호만 발급받고 에이전트를 연결하지 않으면 전화가 와도 콜봇이 받지 않습니다.
6. **통화 결과 확인** - 연결한 번호로 직접 전화를 걸어 보고, 통화 기록을 [상담 내역](./conversation-history)의 `Vox 전화 상담 내역`이나 [전화상담](./phone-counsel)에서 확인합니다.

에이전트 내용을 고친 뒤에는 에이전트 상세 화면의 `배포`를 눌러야 실제 통화에 반영됩니다.

## 콜봇이 전화를 걸게 하기

**위치:** 콜봇 > 캠페인

`캠페인`은 콜봇이 목록의 번호로 전화를 거는 기능입니다. `에이전트 · 발신번호` → `대상` → `확인 · 시작` 세 단계로 진행하며, 마지막에 `캠페인 시작` 확인 창에서 발신 건수를 확인합니다.

:::caution[실제 전화가 걸리고 요금이 청구됩니다]
캠페인을 시작하면 목록의 번호로 실제 전화를 걸고, 통화 요금이 건별로 청구됩니다. 대상 목록과 발신번호, 에이전트가 맞는지 확인한 뒤 시작하세요. 화면에 캠페인 기능이 아직 준비되지 않았다는 안내가 보이면 조직의 CertiLife 담당자에게 문의하세요.
:::

## 알아 둘 점

- `발신표기번호 등록`에는 통신가입증명원이 필요하며 휴대폰 번호는 등록할 수 없습니다.
- 인증 서류는 JPEG, PNG, WebP, PDF 형식의 10MB 이하 파일만 올릴 수 있습니다.
- 콜봇의 `도구`와 `매뉴얼`은 챗봇의 [도구](./chatbot/settings/tools), [매뉴얼](./chatbot/settings/manuals)과 개념은 같지만 따로 관리됩니다.
- AI 음성 응대를 공개하기 전에는 듣기 쉬운 문장인지, 숫자와 시간을 정확히 말하는지, 사람 연결이 되는지를 직접 통화해 확인하세요. 점검 항목은 [출시 체크리스트](../launch-checklist)를 참고하세요.
