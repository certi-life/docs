# Studio 메뉴 한눈에 보기

Studio는 고객 상담을 **준비하고(챗봇·콜봇·백과사전), 응대하고(상담·전화상담), 돌아보는(상담 내역·통계)** 일을 한곳에서 하는 서비스입니다. 화면 왼쪽의 메뉴가 곧 업무의 종류입니다. 이 페이지에서 메뉴별 역할을 확인하고, 각 메뉴의 화면 안내로 이동하세요.

**위치:** Studio 로그인 후 왼쪽 메뉴

## 메뉴별로 하는 일

| 메뉴 | 한 줄 설명 | 화면 안내 |
| --- | --- | --- |
| `인증서` | 병원 관리 화면을 Studio 안에서 열어 인증서 업무를 봅니다 | [인증서](./certificates) |
| `CRM` | 고객 데이터를 모으고 캠페인·자동화 메시지를 운영합니다 | [CRM](./crm/overview) |
| `챗봇` | 채팅 문의에 자동으로 답하는 챗봇을 만들고 다듬습니다 | [챗봇](./chatbot/overview) |
| `콜봇` | 전화를 받는 AI 상담원(에이전트)을 만들고 번호를 연결합니다 | [콜봇](./callbot/overview) |
| `상담` | 들어온 채팅 상담에 상담원이 직접 응대합니다 | [상담](./counsel/overview) |
| `전화상담` | 콜봇과 상담사의 통화를 실시간으로 보고 응대합니다 | [전화상담](./phone-counsel) |
| `상담 내역` | 지난 상담을 검색하고 요약·결과를 확인하고 내보냅니다 | [상담 내역](./conversation-history) |
| `통계` | 전화 응대 현황과 유입·직원별 통계를 봅니다 | [통계](./stats) |
| `백과사전` | 챗봇·콜봇·상담원이 함께 쓰는 조직의 지식 문서를 관리합니다 | [백과사전](./encyclopedia) |
| `AI` | AI와 대화하며 문서를 작성·검토하고 챗봇 자료로 반영합니다 | [AI](./ai) |
| 설정 (왼쪽 아래 톱니 아이콘) | 상담 시간, 알림, 번역, 채널 연동 등 조직 공통 설정을 관리합니다 | [설정(조직 설정)](./org-settings/overview) |

:::info[메뉴가 안 보인다면]
모든 조직에 모든 메뉴가 보이는 것은 아닙니다. `인증서`는 병원 계정으로 직접 로그인했을 때만 보이고, `CRM`, `콜봇`, `전화상담`, `통계`는 조직의 이용 범위에 따라 보이지 않을 수 있습니다. 필요한 메뉴가 없다면 조직의 CertiLife 담당자 또는 [도입 문의](https://certi.life/contact)로 확인하세요.
:::

| 고객에게 알림톡·브랜드 메시지를 보내고 싶어요 | [CRM](./crm/overview) |

## 화면 공통 구성

- **왼쪽 메뉴:** 메뉴가 많아 한 화면에 다 보이지 않으면 위아래 화살표로 넘깁니다. 모바일에서는 왼쪽 위 메뉴 버튼을 눌러 엽니다.
- **위쪽 영역:** 조직 이름, `병원 페이지`(또는 `제조사 페이지`) 이동 버튼, `캘린더`, `즐겨찾기`가 있습니다. 자주 쓰는 화면은 `즐겨찾기`에 추가해 두면 빠르게 이동할 수 있습니다.
- **오른쪽 위 사용자 메뉴:** `설정`과 `로그아웃`이 있습니다. 공용 컴퓨터에서는 업무가 끝나면 로그아웃하세요. 계정 이용 원칙은 [Studio 계정 접속](../account-access)을 참고하세요.
