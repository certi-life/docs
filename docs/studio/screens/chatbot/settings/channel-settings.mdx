# 채널 설정 - 챗봇을 고객이 있는 곳에 연결하기

챗봇을 다 만들었다면 고객이 말을 걸 수 있는 곳에 연결해야 합니다. 연결 방법은 채널마다 다릅니다. **웹사이트는 `SDK 스크립트`(설치 스크립트, 설치 코드, 스니펫이라고도 부릅니다)를 복사해 붙이고, 메신저 채널은 조직에 먼저 연동한 계정을 이 화면에서 고릅니다.** 하나의 챗봇을 여러 채널에 동시에 연결할 수 있습니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > 채널 설정

## 어떤 채널에 연결할 수 있나요?

| 채널 | 연결 방법 | 먼저 필요한 것 |
| --- | --- | --- |
| `웹채팅` | `SDK 스크립트`를 웹사이트에 붙입니다 | 없음. 바로 가능합니다 |
| `카카오톡` | `오픈빌더 (스킬)` 또는 `상담톡 봇` 방식 중 선택 | 카카오 오픈빌더 봇 또는 조직에 연결된 상담톡 채널 |
| `네이버 톡톡` | 조직에 등록된 채널을 골라 `연결하기` | 조직의 채널 설정에 네이버 톡톡 등록 |
| `Instagram`, `LINE`, `WhatsApp` | `연동 채널`에서 계정을 고릅니다 | 조직의 채널 설정에 해당 계정 연동 |

`WeChat`은 화면에 `준비중`으로 표시됩니다. 메신저 계정을 조직에 새로 연동하는 작업은 이 화면이 아니라 설정(조직 설정)의 `채널 설정`에서 합니다. 절차는 [채널 연동](../../org-settings/channels)을 보세요. 이 화면의 목록에는 이미 연동된 계정만 나타납니다.

채널을 바꾼 뒤에는 왼쪽 아래 `저장`을 누릅니다.

## 홈페이지에 채팅 버튼 달기

**위치:** 챗봇 > 설정 > 채널 설정 > 웹채팅 > SDK 스크립트

설치 스크립트는 `웹채팅` 카드 안에 있습니다. `웹채팅` 카드는 화면 맨 위 `상담원 바로 연결` 카드 바로 아래에 있고, 제목 아래에 "웹사이트 임베드 채팅창 및 독립 페이지"라는 설명이 있습니다. 이 카드 안에는 작은 카드 세 개가 `상담 진행 여부`, `SDK 스크립트`, `웹채팅 URL` 순서로 들어 있습니다. 그중 `SDK 스크립트` 카드만 처음에 접혀 있어서, 제목과 설명만 보이고 스크립트와 `복사` 버튼은 보이지 않습니다.

1. `웹채팅` 카드 안의 `SDK 스크립트` 카드 제목 줄을 누릅니다. 줄 오른쪽의 화살표가 아래를 가리키면 펼쳐진 것입니다.
2. 펼쳐진 스크립트 오른쪽 위의 `복사`를 누릅니다. "웹챗 스크립트가 클립보드에 복사되었습니다"가 나오면 복사된 것입니다.
3. 챗봇을 붙일 웹사이트의 HTML에서 `</body>` 바로 앞에 붙여 넣습니다. 모든 페이지에 버튼이 보이게 하려면 모든 페이지가 함께 쓰는 공통 영역(공통 레이아웃, 푸터)에 넣습니다. 홈페이지를 직접 고칠 수 없다면 이 스크립트와 이 문서를 웹사이트 담당자에게 전달하세요.
4. 사이트를 새로 고쳐 오른쪽 아래에 채팅 버튼이 나타나는지 확인합니다. PC와 휴대폰에서 모두 확인하세요.

카드의 안내 문구는 "아래 스크립트를 복사하여 적용할 사이트의 `</head>` 혹은 `</body>` 태그 안에 삽입해주세요."입니다. 닫는 태그 바로 앞에 넣으라는 뜻입니다. `</head>` 바로 앞에 넣어도 버튼은 똑같이 나타납니다.

붙이기 전에 먼저 시험해 보고 싶다면 같은 `웹채팅` 카드의 `웹채팅 URL`을 `복사`해 브라우저에서 열어 보세요. 웹사이트 없이도 챗봇과 바로 대화할 수 있어, 출시 전 테스트에 유용합니다. 채팅 버튼과 창의 색, 문구는 [`채팅창 설정`](./chat-window-settings)에서 바꿉니다.

### 붙여 넣는 스크립트 살펴보기

복사한 스크립트는 아래와 같은 모양입니다. `botId` 자리에는 우리 챗봇의 ID가 이미 들어 있으므로 고칠 곳이 없습니다. 복사한 그대로 붙여 넣으세요.

```html
<script>
var wc = null;
(function(id, scriptSrc, callback) {
    var d = document,
        tagName = 'script',
        $script = d.createElement(tagName),
        $element = d.getElementsByTagName(tagName)[0];

    $script.id = id;
    $script.async = true;
    $script.src = scriptSrc;

    if (callback) {
        $script.addEventListener('load', function (e) { callback(null, e); }, false);
    }
    $element.parentNode.insertBefore($script, $element);
})('webchatSDK', 'https://webchat.certi.life/sdk/webchat.sdk.min.js', function() {
    wc = new WebChat({
        botId: '우리 챗봇의 ID',
        locale: 'ko'
    });
});
</script>
```

- **한 페이지에 한 번만 넣습니다.** 두 번 넣으면 채팅 버튼이 같은 자리에 두 개 만들어집니다.
- **스크립트는 챗봇마다 다릅니다.** 다른 챗봇으로 바꾸려면 그 챗봇의 `SDK 스크립트`를 복사해 기존 스크립트와 교체합니다.
- **모양을 바꿔도 다시 붙이지 않습니다.** `채팅창 설정`에서 버튼의 색, 문구, 위치를 바꾸고 `저장`하면 이미 붙인 스크립트에 그대로 반영됩니다.
- **페이지가 열리는 것을 막지 않습니다.** 스크립트는 페이지와 따로 내려받고, 페이지가 준비된 뒤에 채팅 버튼을 그립니다.
- **채팅 버튼을 없애려면** 붙여 넣은 스크립트를 지웁니다.

### 홈페이지 종류별로 붙이는 곳

홈페이지를 무엇으로 만들었는지에 따라 스크립트를 넣는 메뉴가 다릅니다. 아래 메뉴 이름은 각 서비스의 것이어서 개편되면 달라질 수 있습니다. 메뉴를 찾기 어려우면 함께 적은 각 서비스의 도움말을 확인하세요.

| 홈페이지 | 붙이는 곳 |
| --- | --- |
| 직접 만들었거나 제작 업체가 관리하는 사이트 | 모든 페이지가 함께 쓰는 공통 레이아웃(푸터) 파일의 `</body>` 바로 앞에 붙입니다. 제작 업체에 스크립트와 이 문서를 함께 전달하세요. |
| 아임웹 | 관리자 페이지의 `설정 > SEO`에서 고급 설정의 `공통 코드 삽입` 항목 중 `Footer Code`에 붙이고 `저장`을 누릅니다. [아임웹 공통 코드 삽입 도움말](https://imweb.me/faq?mode=view&category=29&category2=38&idx=71387)에 화면 안내가 있습니다. |
| 워드프레스 | 테마의 푸터 영역에 붙입니다. 테마 파일을 고치기 어렵다면 머리글·바닥글에 코드를 넣어 주는 플러그인을 씁니다. 예를 들면 [WPCode 플러그인](https://wordpress.org/plugins/insert-headers-and-footers/)의 footer 영역에 붙입니다. |
| 카페24 | 디자인 편집창에서 공통 레이아웃 파일을 `HTML보기`로 열어 `</body>` 바로 앞에 붙이고 `저장`을 누릅니다. 편집창 사용법은 [카페24 HTML디자인 편집창 도움말](https://sdsupport.cafe24.com/board/tip/read_intro.html?no=192&board_no=5)을 확인하세요. |
| Google 태그 관리자(GTM) | `태그`에서 `새로 만들기`를 누르고 `태그 구성`에서 `맞춤 HTML`을 고른 뒤 HTML 칸에 붙입니다. 모든 페이지에서 실행되는 트리거를 연결하고 컨테이너를 게시합니다. 순서는 [Google 태그 관리자 맞춤 태그 도움말](https://support.google.com/tagmanager/answer/6107167?hl=ko)에 있습니다. |

### 보안 정책(CSP)을 쓰는 사이트라면

웹사이트 담당자가 확인할 내용입니다. 사이트가 콘텐츠 보안 정책(CSP, Content Security Policy)으로 외부 스크립트를 제한할 때만 필요합니다. CSP를 쓰지 않는 사이트는 이 항목을 건너뛰어도 됩니다.

| 허용할 것 | CSP 설정 | 허용하지 않으면 |
| --- | --- | --- |
| 붙여 넣은 스크립트 | `script-src`에 `'unsafe-inline'` 또는 nonce·해시 | 채팅 버튼이 나타나지 않습니다 |
| 웹채팅 SDK 파일 | `script-src`에 `webchat.certi.life` | 채팅 버튼이 나타나지 않습니다 |
| 채팅창 | `frame-src`에 `webchat.certi.life` | 버튼은 5초쯤 뒤에 나타나지만 눌러도 채팅창이 열리지 않습니다 |
| 버튼과 말풍선의 스타일 | `style-src`에 `'unsafe-inline'` | 버튼이 아이콘 없는 사각형으로 보입니다 |

직접 올린 버튼 이미지(`커스텀형`)를 쓴다면 그 이미지의 도메인도 `img-src`에 허용해야 합니다. 차단된 항목과 도메인은 브라우저 개발자 도구의 콘솔에 표시됩니다.

### 상담원 연결만 잠시 막기

`상담 진행 여부`는 웹채팅에서 상담원 연결을 받을지 정하는 스위치입니다. 스위치 아래 설명은 "비활성화 시 웹채팅에서 상담을 진행하지 않습니다."입니다. 꺼도 채팅 버튼은 그대로 보이고 챗봇도 계속 답합니다. 고객이 상담원 연결을 요청하면 연결하지 않으며, 조직의 [자동메시지](../../org-settings/auto-messages)에서 `상담원 비활성화 메시지`가 켜져 있으면 그 문구를 보냅니다. 채팅 버튼 자체를 감추려면 웹사이트에서 스크립트를 지워야 합니다.

## 카카오톡 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 카카오톡

먼저 `카카오 연동 방식`을 고릅니다.

| 방식 | 설명 |
| --- | --- |
| `오픈빌더 (스킬)` | 카카오 오픈빌더의 Bot ID를 등록해 스킬 서버로 연동합니다 |
| `상담톡 봇` | 선택한 상담톡 채널로 들어오는 메시지를 이 챗봇이 처리합니다 |

**오픈빌더로 연결할 때**

1. `폴백 블록 스킬 주소`를 `복사`해 카카오 오픈빌더의 스킬 서버 URL로 등록합니다.
2. `웰컴 블록 스킬 주소`를 `복사`해 오픈빌더의 웰컴 블록에 설정합니다. 고객이 처음 들어왔을 때 시작 시나리오가 나가게 하는 주소입니다.
3. `카카오 오픈빌더 Bot ID`에 Bot ID를 입력하고 `저장`을 누릅니다.

**상담톡 봇으로 연결할 때**는 목록에서 상담톡 채널을 고릅니다. 목록이 비어 있으면 `채널 등록하러 가기`를 눌러 조직의 채널 설정에서 상담톡 채널을 먼저 연결하세요. 진행 중인 챗봇 상담이 있는 상태에서 방식을 바꾸면 저장할 때 그 상담이 종료된다는 경고가 표시됩니다.

### 채널을 추가한 고객만 이용하게 하기

`채널 옵션`의 `채널 추가시에만 챗봇 사용 가능`을 켜면 카카오톡 채널을 추가(친구추가)한 사용자만 챗봇을 이용할 수 있습니다. 이 옵션을 켜면 두 가지를 더 설정할 수 있습니다.

- `친구추가 시나리오로 이동`: 고객이 채널을 추가했을 때 보낼 메시지를 [`시나리오` 탭](../scenarios)에서 편집합니다.
- `상담원 연결 유도 이벤트`: 발송 채널과 `오픈빌더 이벤트 이름`을 등록하고, `메시지 편집하기`로 유도 메시지 내용을 편집합니다. 발송 채널에 REST API 키가 등록되어 있어야 하며, 등록 방법은 화면의 `사전 설정 가이드`를 참고하세요.

`AI 응답 안내 문구`에는 AI가 답변을 만드는 동안 고객에게 보일 메시지(예: "잠시만 기다려주세요. AI가 답변을 준비중입니다.")를 적습니다.

## 네이버 톡톡, Instagram, LINE, WhatsApp 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 네이버 톡톡 (`Instagram`, `LINE`, `WhatsApp` 카드도 같은 방식입니다)

- **네이버 톡톡:** 연결할 채널을 고르고 `연결하기`를 누릅니다. 연결된 뒤에는 `연결됨`으로 표시되고 `연결 해제`로 끊을 수 있습니다.
- **Instagram, LINE, WhatsApp:** 각 카드의 `연동 채널`에서 이 챗봇이 응답할 Instagram 비즈니스 계정, LINE 채널, WhatsApp 번호를 고릅니다. 연결되면 `배정된 채널`이 표시됩니다.

목록에 원하는 계정이 없다면 아직 조직에 연동되지 않은 것입니다. 새 Instagram 계정 연동(Facebook 로그인), LINE 채널 액세스 토큰 등록, WhatsApp 번호 연동은 설정(조직 설정)의 `채널 설정`에서 진행합니다. 이미 다른 챗봇에 연결된 채널은 그 챗봇 이름과 함께 표시됩니다.

## 챗봇 없이 바로 상담원에게 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 상담원 바로 연결

특정 채널은 챗봇을 거치지 않고 처음부터 사람이 받게 하고 싶다면 `상담원 바로 연결`에서 그 채널을 켭니다.

| 채널 | 켜면 이렇게 동작합니다 |
| --- | --- |
| `웹채팅` | 첫 진입 시 홈 시나리오 대신 상담 대기로 시작합니다 |
| `카카오톡` | 카카오 스킬 요청이 오면 상담원 연결 안내를 응답합니다 |
| `네이버 톡톡` | 고객이 톡톡을 시작하거나 메시지를 보내면 챗봇 없이 상담 대기로 시작합니다 |

상담원이 응대할 수 없는 시간에도 상담 대기로 들어오므로, 켜기 전에 상담 가능 시간과 [상담원 연결 정책](../../../../products/ai-chatbot/handoff-policy)을 먼저 정해 두세요. 챗봇이 답하다가 고객이 원할 때만 사람에게 넘기려면 이 설정 대신 카드 블럭의 버튼에 [`상담사 연결` 동작](../blocks#버튼-동작-정하기)을 넣습니다.

## 연결한 뒤에는

채널을 연결했다고 끝이 아닙니다. 고객에게 공개하기 전에 채널마다 가상 질문으로 정상 답변, 답변 거절, 상담원 연결, 업무시간 외 안내를 확인하세요. 점검 항목은 [출시 체크리스트](../../../launch-checklist)에 있습니다. 연결 상태는 [챗봇 목록](../list#챗봇-카드-읽는-법)의 카드에서도 한눈에 볼 수 있습니다.

## 문제가 생기면

### `복사에 실패했습니다`

브라우저가 클립보드 복사를 막았다는 뜻입니다.

1. `SDK 스크립트`를 펼친 상태에서 스크립트 글자를 처음부터 끝까지 마우스로 끌어 선택합니다.
2. Ctrl+C(Mac은 ⌘C)로 복사합니다.
3. 붙여 넣은 뒤 앞뒤가 잘리지 않았는지 확인합니다.

그래도 안 되면 다른 브라우저에서 다시 시도합니다.

### 홈페이지에 채팅 버튼이 보이지 않을 때

스크립트가 그 페이지에 들어가지 않았거나, 들어갔지만 실행되지 않은 것입니다.

1. 버튼이 안 보이는 페이지에서 브라우저의 페이지 소스 보기를 열고 `webchatSDK`를 찾습니다. 없으면 스크립트가 그 페이지에 들어가지 않은 것입니다. 모든 페이지가 함께 쓰는 공통 영역에 넣었는지 확인합니다. Google 태그 관리자로 넣었다면 페이지 소스에는 나오지 않으므로 3번으로 확인합니다.
2. 스크립트가 화면에 글자로 보이면 HTML을 입력하는 칸이 아닌 곳에 붙인 것입니다. 코드를 입력하는 칸으로 옮깁니다. 스크립트의 처음 `<script>`와 끝 `</script>`가 잘리지 않았는지도 확인합니다.
3. 브라우저 개발자 도구의 콘솔에 `typeof WebChat`을 입력합니다. `'function'`이 나오면 스크립트가 실행된 것이고, `'undefined'`가 나오면 실행되지 않은 것입니다.
4. 콘솔에 Content Security Policy 차단 메시지가 있으면 [보안 정책(CSP)을 쓰는 사이트라면](#보안-정책csp을-쓰는-사이트라면)의 항목을 허용합니다.
5. 홈페이지에 캐시 기능이 있으면 캐시를 비우고 새로 고칩니다.

그래도 안 되면 페이지 주소와 콘솔의 메시지를 적어 조직의 CertiLife 담당자에게 알립니다.

### 채팅 버튼은 보이는데 대화가 되지 않을 때

채팅창을 불러오지 못했거나, 스크립트가 가리키는 챗봇을 찾지 못한 것입니다.

1. `웹채팅 URL`을 `복사`해 브라우저에서 열고 대화가 되는지 확인합니다. 여기서 대화가 되면 챗봇은 정상이고 웹사이트 쪽을 확인하면 됩니다.
2. 버튼이 페이지를 열고 5초쯤 지나서야 나타나고 눌러도 채팅창이 열리지 않으면, 사이트의 보안 정책이 채팅창을 막은 것입니다. `frame-src`에 `webchat.certi.life`를 허용합니다.
3. 채팅창은 열리는데 대화가 시작되지 않으면 스크립트의 `botId` 값이 잘못된 것입니다. 붙여 넣을 때 값이 잘렸거나 없는 챗봇의 스크립트일 때 그렇습니다. 연결할 챗봇의 `SDK 스크립트`를 다시 복사해 교체합니다.

`웹채팅 URL`에서도 대화가 되지 않으면 챗봇 이름과 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.

### 채팅 버튼이 사이트의 다른 버튼과 겹칠 때

"맨 위로" 버튼이나 다른 채팅 버튼과 자리가 겹치면 `채팅창 설정`의 `플로팅 버튼`에서 `버튼 위치`와 `아래 여백`을 바꿉니다. 방법은 [채팅 버튼 모양과 위치 바꾸기](./chat-window-settings#채팅-버튼-모양과-위치-바꾸기)에 있습니다. 스크립트는 다시 붙이지 않아도 됩니다.

### `상담 진행 여부가 꺼져 있어 상담원 바로 연결을 위해 함께 활성화됩니다. 저장을 눌러 적용해주세요.`

웹채팅의 `상담원 바로 연결`을 켰는데 `상담 진행 여부`가 꺼져 있어서, `상담 진행 여부`도 함께 켜졌다는 뜻입니다. 아직 저장되지 않았으므로 왼쪽 아래 `저장`을 누릅니다.

### `선택한 채널에 카카오 REST API 키가 등록되지 않았습니다. 조직 설정에서 등록해주세요.`

`상담원 연결 유도 이벤트`의 발송 채널로 고른 카카오 채널에 REST API 키가 없다는 뜻입니다. 키가 없으면 유도 메시지를 보낼 수 없습니다.

1. 설정(조직 설정)의 [`채널 설정`](../../org-settings/channels)에서 그 카카오 채널에 REST API 키를 등록합니다.
2. 이 화면으로 돌아와 발송 채널을 다시 고르고 `저장`을 누릅니다.

등록 방법은 화면의 `사전 설정 가이드`를 참고합니다. 그래도 같은 경고가 나오면 채널 이름과 화면의 문구를 적어 조직의 CertiLife 담당자에게 알립니다.
