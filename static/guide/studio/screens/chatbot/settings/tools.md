# 도구 - 챗봇에게 할 수 있는 일 늘려 주기

> Studio 챗봇 설정의 도구에서 대화 정보 추출, 병원 진료시간 활용, 컴플레인 대응, 알림톡 보내기, 브랜드메시지 보내기를 추가하는 방법과 챗봇 메뉴의 도구 목록에서 API 도구를 만드는 방법을 목적별로 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/chatbot/settings/tools)

기본 챗봇은 질문에 답만 합니다. `도구`를 추가하면 챗봇이 **답변 이상의 일**을 합니다. 대화에서 고객 이름과 연락 희망 시간을 챙기고, 화가 난 고객을 감지해 상담사에게 알리고, 담당자에게 알림톡을 보내는 식입니다. 도구를 쓰는 방법은 두 가지입니다. 바로 쓸 수 있는 `기본 제공` 도구를 추가하거나, 우리 조직의 시스템과 연결하는 API 도구를 직접 만듭니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > 도구

> **v2 beta 기능입니다**
>
> `도구`는 메뉴에 `v2 beta`로 표시되며 응답 버전이 v2인 챗봇에서만 동작합니다. v1 챗봇에서는 "v2에서 사용할 수 있습니다. AI 설정 상단에서 응답 버전을 변경해주세요."라는 안내가 보입니다. 버전은 [`AI 설정`](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#응답-버전-바꾸기)에서 바꿉니다. 베타 기능이라 동작과 문구가 바뀔 수 있습니다.

## 어떤 도구가 있나요?

| 도구                      | 이런 걸 하고 싶을 때                                        |
| ----------------------- | --------------------------------------------------- |
| `대화 정보 추출`              | 챗봇이 대화하면서 고객 이름, 관심 시술, 연락 희망 시간 같은 정보를 챙기게 하고 싶을 때 |
| `병원 진료시간 활용`            | 진료시간 질문에 조직 설정에 등록한 최신 진료시간으로 답하게 하고 싶을 때           |
| `컴플레인 대응`               | 화가 난 고객을 챗봇이 붙잡고 있지 않고 상담사에게 바로 알리고 싶을 때            |
| `알림톡 보내기`, `브랜드메시지 보내기` | 대화 중 특정 상황이 되면 메시지를 자동으로 보내고 싶을 때                   |
| API 도구                  | 예약 조회처럼 우리 조직의 시스템을 챗봇이 직접 호출하게 하고 싶을 때             |

## 도구 추가하고 빼기

**위치:** 챗봇 > 설정 > 도구

1. 오른쪽 위 `추가`를 누르고 목록에서 도구를 고릅니다. `기본 제공` 표시가 붙은 것이 바로 쓸 수 있는 도구입니다.
2. 추가된 도구가 왼쪽 목록에 나타납니다. 도구를 누르면 오른쪽에서 이 챗봇에서의 설정을 볼 수 있습니다.
3. 빼려면 도구를 고르고 `이 챗봇에서 제거`를 누릅니다.

추가와 제거, 도구별 설정은 **바꾸는 즉시 저장**됩니다. 왼쪽 아래 `저장` 버튼은 누르지 않습니다. 목록에 `삭제됨`으로 표시되는 도구는 조직의 도구 목록에서 이미 지워진 것이니 제거해 주세요.

## 대화 중에 고객 정보 챙기기

**위치:** 챗봇 > 설정 > 도구 > 대화 정보 추출

상담사가 나중에 연락하려면 이름이나 연락 가능한 시간이 필요합니다. `대화 정보 추출`을 추가하면 챗봇이 대화 중에 자연스럽게 물어 정보를 모읍니다.

1. `대화 정보 추출`을 추가하고 `필드 추가`를 누릅니다.
2. `추출할 정보 추가` 창에서 `필드 이름`(예: 이름, 연락받을 시간)을 적습니다.
3. `추출 가이드`에 무엇을 어떻게 확인할지 구체적으로 적습니다. 예: "고객이 상담 연락을 받기 편한 요일과 시간대를 기록해 주세요."
4. `저장`을 누릅니다.

필드는 20개까지 만들 수 있고 새 대화부터 적용됩니다. 챗봇은 필요한 정보를 대화 흐름에 맞춰 질문하며, 고객이 거절하면 다시 묻지 않습니다. 필드를 삭제해도 이미 모은 정보는 지워지지 않습니다.

> **꼭 필요한 정보만 받으세요**
>
> 수집 항목이 많을수록 고객은 부담을 느끼고, 조직이 관리해야 할 개인정보도 늘어납니다. 상담에 실제로 쓰는 항목만 등록하세요. 기준은 [개인정보 및 보안](https://docs.certi.life/guide/help/privacy-security)을 참고하세요.

## 진료시간을 항상 최신으로 안내하기

**위치:** 챗봇 > 설정 > 도구 > 병원 진료시간 활용

학습자료에 적어 둔 진료시간은 바뀔 때마다 자료를 고쳐야 합니다. `병원 진료시간 활용`을 추가하면 챗봇이 `설정` > `운영 설정` > `병원 진료시간`에 등록된 요일별 진료시간, 임시 휴진일, 정기 휴무 예외일로 답합니다. 학습자료의 진료시간과 운영 설정 값이 다르면 **운영 설정 값을 우선** 안내합니다. 도구를 제거하면 학습자료의 진료시간만 사용합니다.

진료시간 등록 화면은 [설정(조직 설정)](https://docs.certi.life/guide/studio/screens/org-settings/overview)을 참고하세요.

## 화난 고객을 상담사에게 바로 알리기

**위치:** 챗봇 > 설정 > 도구 > 컴플레인 대응

`컴플레인 대응`을 추가하면 챗봇이 고객의 직전 메시지를 대화 흐름과 함께 보고 감정을 판단합니다. '매우 부정'(격앙, 욕설, "됐어요 그만" 같은 체념)으로 판단되거나 고객이 명시적으로 항의하면, 챗봇은 감정에 맞대응하지 않고 최소한의 정보만 받은 뒤 상담사 연결을 안내합니다. 동시에 상담사 화면에 "컴플레인이 감지되었어요" 알림이 뜹니다.

알아 둘 점은 두 가지입니다.

- 챗봇은 **알림만** 띄웁니다. 상담 대기열에 넣거나 상담원을 배정하지는 않으므로, 상담사가 알림을 보고 직접 방을 열어야 합니다.
- 제3자나 과거 경험에 대한 불만, 단순한 실망은 해당하지 않습니다.

판단 결과는 [상담 내역](https://docs.certi.life/guide/studio/screens/conversation-history)의 챗봇 답변 위에 "고객 감정" 태그로 남습니다.

## 상황에 맞춰 알림톡 보내기

**위치:** 챗봇 > 설정 > 도구 > 알림톡 보내기 (`브랜드메시지 보내기`도 같은 구성입니다)

"고객이 상담사 연락을 남기고 싶다고 하면 담당자에게 알림톡을 보낸다"처럼, 상황과 메시지를 묶은 것을 **발송 슬롯**이라고 합니다. 슬롯 하나가 챗봇의 도구 하나가 됩니다.

1. `알림톡 보내기`를 추가하고 `슬롯 추가`를 누릅니다.
2. `이름`을 적고, `언제 보낼지 (챗봇에게 설명)`에 발송 상황을 문장으로 적습니다.
3. `담당자 수신 번호`에 알림을 받을 **병원 담당자** 번호를 적습니다. 고객 번호가 아닙니다. 여기 적은 번호로만 발송됩니다.
4. `발송 채널`과 `템플릿`을 고릅니다.
5. `템플릿 변수`마다 값을 어떻게 채울지 고릅니다. `챗봇이 대화에서 파악`을 고르면 설명을 적고, `고정 값`을 고르면 값을 직접 적습니다. 아래 `발송 예시`에서 결과를 미리 봅니다.
6. `저장`을 누릅니다.

> **실행 전 고객에게 동의 받기는 언제 켜나요?**
>
> 담당자에게 가는 내부 알림이라면 끄고, 고객에게 가는 안내라면 켜세요. 켜면 챗봇이 보내기 전에 고객에게 확인을 받습니다. 슬롯은 챗봇당 10개까지 만들 수 있고, 같은 대화에서는 슬롯당 한 번만 발송됩니다.

발송 전 점검 항목은 [CRM 메시지 발송 전 체크리스트](https://docs.certi.life/guide/products/crm-messaging/message-checklist)를 참고하세요.

## 조직 공용 API 도구 만들기

**위치:** 챗봇 > 도구 (화면 제목 `도구 목록`)

예약 조회처럼 우리 시스템의 API를 챗봇이 호출하게 하려면 API 도구를 만듭니다. API 도구는 챗봇 하나가 아니라 **조직 공용**으로 만들고, 어느 챗봇이 쓸지는 각 챗봇의 `설정` > `도구`에서 `추가`로 정합니다. 개발 담당자와 함께 진행하는 것을 권장합니다.

1. [챗봇 목록](https://docs.certi.life/guide/studio/screens/chatbot/list) 위쪽의 `도구` 탭(`v2 beta`)을 열고 `새 API 도구`를 누릅니다.
2. `기본 정보`에 `도구 이름`(영숫자, 하이픈, 언더스코어만 가능)과 `도구 설명`을 적습니다. AI는 이 설명을 보고 도구를 언제 쓸지 판단하므로, "고객이 말한 값만 인자로 쓴다" 같은 조건까지 적어 두면 좋습니다.
3. `엔드포인트`에 HTTP 메서드와 주소, 타임아웃을 정합니다. 내부망이나 사설 IP 주소는 허용되지 않습니다.
4. `파라미터`에 AI가 넘길 인자를 JSON Schema로 정의합니다. `예시 넣기`로 시작하면 편합니다.
5. 필요하면 `API 인증`, `커스텀 헤더`, `고정 필드`를 켭니다.
6. `응답 처리`를 고릅니다. 결과가 답변에 필요한 조회 도구는 `결과 기다리기`, 완료 여부만 보내면 되는 발송 도구는 `보내고 바로 진행`입니다.
7. `실행 전 확인`에서 `실행 전 고객 동의 받기`를 정하고 `저장`합니다.

> **되돌리기 어려운 도구는 동의를 받으세요**
>
> 발송, 예약, 변경처럼 실행하면 되돌리기 어려운 도구는 `실행 전 고객 동의 받기`를 켜 두세요. 챗봇이 실행할 내용을 고객에게 확인하고 동의한 뒤에만 호출합니다. 기본값은 GET은 꺼짐, 그 외는 켜짐입니다.

`기본 제공`과 `시스템 제공` 도구는 이 화면에서 고치거나 지울 수 없고, 각 챗봇에서 추가와 제거만 할 수 있습니다.
