# 설정(조직 설정) - 조직 공통 설정 관리하기

챗봇 하나에만 해당하는 설정은 [챗봇의 `설정` 탭](./chatbot/settings/menu)에 있고, **조직 전체에 공통으로 적용되는 설정**은 여기에 있습니다. 상담 가능 시간, 상담이 들어왔을 때의 알림, 번역, 메신저 채널 계정 연동이 대표적입니다. 화면 위쪽에는 `설정`, 왼쪽에는 `설정 메뉴`라고 표시되며, 다른 화면의 안내 문구에서는 이곳을 "조직 설정"이라고 부릅니다.

**위치:** 왼쪽 아래 톱니 아이콘 > 설정 메뉴

:::info[PC에서 설정하세요]
설정은 모바일 환경에서 지원하지 않습니다. 화면에 `읽기 전용 모드`가 표시되면 내용을 볼 수만 있고, 변경은 PC에서 해야 합니다.
:::

## 어디서 무엇을 바꾸나요

| 설정 메뉴 | 여기서 하는 일 |
| --- | --- |
| `운영 설정` | 상담 시간, 관리자·상담사 알림, 상황별 콜백, 번역 |
| `채널 설정` | 알림톡 발송 채널, 상담톡, 네이버 톡톡, Instagram, LINE, WhatsApp, AI 콜봇 채널 연동 |
| `회원 관리` | 채널별 `전체 회원 목록`과 `인증회원 목록` |
| `상담 파일 관리` | 상담 메시지 첨부파일의 저장 용량과 초과 파일 |
| `고객 태그` | 상담 화면에서 고객에게 붙이는 태그 목록 (보기 전용) |
| `헤더 고객 정보` | 채팅방 헤더의 고객 이름 옆에 보여 줄 고객 정보 |
| `자동메시지` | 상담 진행 중 고객에게 자동으로 나가는 메시지 |
| `상담 기록 설정` | 상담 기록에 담을 값을 조직에 맞게 정의 (이용 범위에 따라 표시) |

## 상담 운영 기준 정하기

**위치:** 설정 > 운영 설정

`운영 설정`은 다섯 개 탭으로 나뉩니다.

| 탭 | 하는 일 |
| --- | --- |
| `상담 시간` | `채팅 상담`, `AI 챗봇`, `AI 콜봇`의 운영 시간을 정합니다. 병원 조직은 `병원 진료시간`도 여기서 등록합니다 |
| `관리자 알림` | 상담이 들어왔을 때 관리자에게 알림톡을 보낼 기준을 정합니다 |
| `상담사 알림` | 상담사에게 알림을 어떻게 보낼지 정합니다 |
| `상황별 콜백` | 상황에 따른 콜백 동작을 정합니다 |
| `번역` | 채팅 번역을 켜고 번역 방향과 동작을 정합니다 |

**상담 시간**을 바꾸면 화면 아래에 "변경사항이 있습니다" 저장 바가 나타나고, `저장`을 눌러야 적용됩니다. `병원 진료시간`에 등록한 값은 챗봇의 [`병원 진료시간 활용` 도구](./chatbot/settings/tools#진료시간을-항상-최신으로-안내하기)가 답변에 사용합니다.

**관리자 알림**은 `상담원 연결 요청시 발송`과 `챗봇 상담 시작시 발송` 중에서 고릅니다. 조직의 모든 채널에 공통으로 적용되며, 고르면 저장 버튼 없이 5초 이내에 적용됩니다. **상담사 알림**도 같은 방식으로, 알림 대상을 `전체 상담사` 또는 `배정 상담사 + 참조자`로 정하고 챗봇이 응대하는 동안 알림을 받을지 고릅니다.

**번역**에서 `번역 사용`을 켜면 아래 설정이 활성화됩니다. `번역 방향`에서 `고객이 쓰는 언어`와 `상담사가 읽을 언어`를 정하는데, 고객 언어를 `자동 감지`로 두면 고객의 처음 세 메시지로 상담방 언어를 정하고 이후에는 바뀌지 않습니다. `동작`에서는 `자동 메시지 번역`, `번역·전송 버튼 합치기`, `번역 없이 발송할 때 확인`을 고릅니다. 상담원이 번역을 실제로 쓰는 방법은 [상담](./counsel#외국어-고객과-대화하기)과 [상담 메시지 번역](../../products/ai-chatbot/message-translation)을 보세요.

## 메신저 채널 계정 연동하기

**위치:** 설정 > 채널 설정

카카오톡이나 Instagram 같은 메신저를 쓰려면 **먼저 여기서 조직에 계정을 연동**하고, 그다음 [챗봇의 `채널 설정`](./chatbot/settings/channel-settings)에서 어느 챗봇이 그 채널에 응답할지 고릅니다. 두 단계라는 점을 기억하세요.

탭은 `알림톡 채널`, `상담톡 채널`, `네이버 톡톡`, `Instagram`, `LINE`, `WhatsApp`, `AI 콜봇` 순서이며 `위챗 (준비중)`은 아직 쓸 수 없습니다. 채널마다 연동에 필요한 것이 다릅니다. 예를 들어 Instagram은 Facebook 로그인으로, LINE은 채널 액세스 토큰 등록으로 연동합니다. 각 탭의 안내에 따라 진행하세요.

## 그 밖의 설정

**위치:** 설정 > 설정 메뉴

- **`고객 태그`:** 상담 화면에서 고객에게 붙이는 태그 목록을 확인합니다. 이 화면은 보기 전용이며, 추가와 수정은 [백과사전](./encyclopedia)에서 합니다.
- **`헤더 고객 정보`:** 채팅방 헤더의 고객 이름 옆에 함께 보여 줄 고객 정보를 고릅니다. 켜면 고객 태그는 아랫줄로 내려갑니다.
- **`자동메시지`:** 상담 진행 중 고객에게 자동으로 나가는 메시지 문구를 관리합니다.
- **`상담 기록 설정`:** 상담 기록에 담을 값을 직접 정의합니다. 필드 구성 방법은 [상담 기록 필드 설정](../consultation-records)에 자세히 있습니다.
- **`상담 파일 관리`:** 첨부파일 저장 용량을 확인하고 초과 파일을 정리합니다.

## 알아 둘 점

- 이 화면의 설정은 조직의 모든 상담원과 모든 채널에 영향을 줍니다. 바꾸기 전에 책임자와 상의하세요.
- 상담 시간과 알림 기준은 [상담원 연결 정책](../../products/ai-chatbot/handoff-policy)과 함께 정하는 것이 좋습니다. 챗봇이 쉬는 시간은 챗봇마다 [`작동시간`](./chatbot/settings/operating-hours)에서 따로 정합니다.
