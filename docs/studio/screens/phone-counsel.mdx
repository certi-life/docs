# 전화상담 - 콜봇과 상담사의 통화 응대하기

`전화상담`은 전화 응대를 위한 작업 화면입니다. 지금 [콜봇](./callbot)이 받고 있는 전화, 상담사 연결을 기다리는 전화, 내가 통화 중인 전화가 실시간으로 보입니다. 통화를 고르면 대화록과 녹음, AI 분석을 확인하고 상담 기록을 남길 수 있습니다. 메뉴 이름은 화면에 `전화상담`으로 붙여 표시됩니다.

**위치:** 전화상담 > 상담하기

:::info[조직의 이용 범위에 따라 다르게 보입니다]
`전화상담` 메뉴는 콜봇을 이용하는 조직에 표시됩니다. 조직의 이용 범위에 따라 이 메뉴가 `상담하기` 화면 대신 [상담 내역](./conversation-history)의 전화 상담 내역으로 연결될 수 있습니다. 또 일부 기능은 화면에 "아직 준비되지 않았습니다"로 표시될 수 있으며, 그 경우 해당 기능은 아직 쓸 수 없습니다.
:::

## 화면 구성

화면은 세 열입니다. 왼쪽에서 통화를 고르고, 가운데에서 통화 내용을 보고 기록하고, 오른쪽에서 고객을 확인합니다.

| 영역 | 탭 | 내용 |
| --- | --- | --- |
| 왼쪽 목록 | `콜봇` | 지금 콜봇이 응대 중인 콜 (실시간) |
| | `대기` | 지금 상담원 연결을 기다리는 콜 (실시간) |
| | `응대` | 지금 내가 통화 중인 콜 (실시간) |
| | `콜백` | 내게 배정된 미완료 콜백 예약 |
| | `전체콜` | 오늘 조직으로 들어온 콜 전부 (콜봇 응대 종료 포함) |
| 가운데 | `상담 정보`, `콜백 예약` | 대화록, 녹음, `AI 분석`, 콜백 예약, 아래쪽 `상담 기록` |
| 오른쪽 | `고객 정보`, `고객 메모`, `콜백` | 고객 분류와 메모, 이 고객의 콜백, `상담이력` |

아무것도 고르지 않았을 때는 가운데에 "왼쪽에서 통화를 선택하세요."가 보입니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 콜봇이 지금 뭐라고 응대하는지 보고 싶어요 | `콜봇` 탭에서 통화를 눌러 `대화록`을 봅니다 |
| 연결을 기다리는 고객을 확인하고 싶어요 | `대기` 탭 |
| 고객에게 전화를 걸고 싶어요 | [고객에게 전화 걸기](#고객에게-전화-걸기) |
| 자리를 비워 전화 연결을 받지 않으려 해요 | [내 상태 바꾸기](#내-상태-바꾸기) |
| 통화 내용을 기록으로 남기고 싶어요 | [통화 내용 확인하고 기록 남기기](#통화-내용-확인하고-기록-남기기) |

## 통화 내용 확인하고 기록 남기기

**위치:** 전화상담 > 상담하기 > (통화 선택) > 상담 정보

1. 왼쪽 목록에서 통화를 누릅니다.
2. 가운데 `상담 정보`에서 `대화록`을 확인합니다. 진행 중인 통화는 `실시간`으로 갱신되고, `전체`, `콜봇·상담사`, `고객`으로 걸러 보거나 검색할 수 있습니다.
3. 통화가 끝나면 `AI 분석`에 요약, 키워드, 감정이 자동으로 채워집니다. `요약을 메모로 복사`를 누르면 요약을 상담 메모로 가져옵니다.
4. 아래쪽 `상담 기록`에서 `플래그`, `고객 분류`, `처리 결과`를 고르고 `메모`를 적은 뒤 `저장`합니다. 후속 처리까지 끝났다면 `후처리 완료`를 누릅니다.

:::tip[대화록은 참고용입니다]
대화록은 음성 인식 결과라 일부 부정확할 수 있습니다. 이름, 숫자, 날짜처럼 중요한 내용은 녹음을 들어 확인하세요. 민감정보 저장 거부가 설정된 통화는 녹음이 보관되지 않습니다.
:::

상담 기록에 어떤 필드를 둘지는 조직에서 정할 수 있습니다. 설계 방법은 [상담 기록 필드 설정](../consultation-records)을 참고하세요.

## 고객에게 전화 걸기

**위치:** 전화상담 > 상담하기 > 전화걸기

1. `전화걸기`를 누릅니다.
2. `상담사 번호`와 `발신번호`를 고르고 고객 전화번호를 입력합니다.
3. 콜봇이 먼저 안내하게 하려면 `아웃콜 멘트 사용`을 켜고 `에이전트`를 고릅니다.
4. `통화 걸기`를 누릅니다.

발신에는 통화 요금이 발생합니다. 상담사 번호가 없으면 [콜봇](./callbot)의 `사용자 관리`에서, 발신할 번호가 없으면 `번호 관리`에서 먼저 준비해야 합니다.

## 내 상태 바꾸기

**위치:** 전화상담 > 상담하기 > 상담사 상태

`상담사 상태`를 누르면 상담사 번호별 상태를 바꿀 수 있습니다. 콜봇은 **통화대기 상태인 상담사에게만** 전화를 넘깁니다. 자리를 비울 때 상태를 바꿔 두지 않으면 받을 수 없는 전화가 넘어올 수 있습니다. 착신전환용 번호는 상태와 관계없이 바로 전환됩니다.

## 고객 정보와 메모 남기기

**위치:** 전화상담 > 상담하기 > 고객 정보

오른쪽 `고객 정보`에서 연필 아이콘을 눌러 `고객 분류`와 `차단 표식`을 기록하고, `고객 메모`에 다음 통화에서 참고할 내용을 남깁니다. `차단 표식`은 표시만 할 뿐 실제로 전화 수신을 차단하지는 않습니다. 웹 통화는 고객 번호가 없어 고객 정보와 메모를 저장할 수 없습니다.
