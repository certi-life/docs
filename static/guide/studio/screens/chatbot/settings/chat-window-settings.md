# 채팅창 설정 - 웹채팅 모양을 우리 사이트에 맞추기

> Studio 챗봇 설정의 채팅창 설정에서 상담 유도 메시지(말풍선), 화면 맥락 전달(고객이 보던 페이지 알려 주기), 디자인 설정(헤더·테마 색상·제목), 창 크기, 채팅창 테두리/그림자, 플로팅 버튼, 커스텀 메뉴를 바꿔 웹채팅 창을 꾸미는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings)

웹사이트에 붙인 채팅 버튼과 채팅창은 기본 파란색으로 나옵니다. `채팅창 설정`에서 우리 브랜드 색과 문구로 바꿀 수 있습니다. 바꾸는 즉시 오른쪽 `실시간 미리보기`에 반영되니 결과를 보면서 조정하고, 마음에 들면 왼쪽 아래 `저장`을 누르세요. **`저장`을 눌러야 실제 웹사이트의 채팅창이 바뀝니다.**

**위치:** 챗봇 > (챗봇 선택) > 설정 > 채팅창 설정

이 설정은 웹채팅에만 적용됩니다. 카카오톡이나 네이버 톡톡 같은 메신저 채널의 모양은 각 메신저가 정합니다. 웹채팅을 사이트에 붙이는 방법은 [`채널 설정`](https://docs.certi.life/guide/studio/screens/chatbot/settings/channel-settings#홈페이지에-채팅-버튼-달기)을 보세요.

## 이럴 때 사용하세요

| 하고 싶은 일                                      | 섹션                                                                                                                                |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 채팅 버튼 위에 "도움이 필요하신가요?" 말풍선을 띄우고 싶어요          | [방문자에게 먼저 말 걸기](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings#방문자에게-먼저-말-걸기)                 |
| 고객이 "이거 얼마예요?"라고 물으면 어느 페이지 얘기인지 챗봇이 알았으면 해요 | [고객이 보던 페이지를 챗봇에 알려 주기](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings#고객이-보던-페이지를-챗봇에-알려-주기) |
| 채팅창을 브랜드 색으로 바꾸고 제목을 넣고 싶어요                  | [채팅창 색과 제목 바꾸기](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings#채팅창-색과-제목-바꾸기)                 |
| 채팅 버튼이 사이트의 다른 버튼과 겹쳐요                       | [채팅 버튼 모양과 위치 바꾸기](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings#채팅-버튼-모양과-위치-바꾸기)           |
| 채팅창 아래에 "오시는 길", "연락하기" 바로가기를 넣고 싶어요         | [바로가기 메뉴 넣기](https://docs.certi.life/guide/studio/screens/chatbot/settings/chat-window-settings#바로가기-메뉴-넣기)                       |

## 방문자에게 먼저 말 걸기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 상담 유도 메시지 설정

`말풍선 표시`를 켜면 채팅 버튼 위에 말풍선이 떠서 방문자의 상담 참여를 유도합니다. `제목`과 `내용`을 적으세요. 기본 문구는 "도움이 필요하신가요?"와 "안녕하세요! 버튼을 눌러서 채팅상담을 시작해보세요."입니다. "예약 문의는 여기서 바로 하세요"처럼 무엇을 물어볼 수 있는지 알려 주는 문구가 효과적입니다.

## 고객이 보던 페이지를 챗봇에 알려 주기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 화면 맥락 전달

고객은 상품 페이지를 보다가 "이거 예약돼요?", "여기 주차 돼요?"처럼 묻습니다. `화면 맥락 전달`을 켜면 고객이 메시지를 보낼 때, 그 순간 보고 있던 페이지의 정보가 함께 전송되어 챗봇이 "이거", "여기"가 무엇인지 이해합니다. 기본값은 꺼짐입니다.

| 보내는 것                              | 보내지 않는 것                |
| ---------------------------------- | ----------------------- |
| 페이지 주소(쿼리 제외), 페이지 제목, 선택된 메뉴·탭 이름 | 본문 내용, 고객이 입력한 값, 클릭 이력 |

메시지를 보내기 전에는 아무것도 전송되지 않습니다.

1. `화면 맥락 전달` 스위치를 켭니다.
2. 개인정보가 보이는 페이지처럼 보내면 안 되는 주소가 있으면 `제외할 경로 (한 줄에 하나, * 사용 가능)`에 한 줄에 하나씩 적습니다. 예: `/reserve/check`. 경로 끝에 `*`를 붙이면 그 아래의 주소를 한꺼번에 뺍니다.
3. 왼쪽 아래 `저장`을 누릅니다.

> **사이트에 먼저 고지하세요**
>
> 전송된 값은 상담 기록에 함께 저장됩니다. 켜기 전에 사이트 이용약관과 개인정보 처리방침에 이 내용을 고지하세요.

> **실제로 어떤 값이 가는지 보기**
>
> 웹채팅이 설치된 페이지에서 브라우저 개발자 도구의 콘솔을 열고 `WebChat.inspectContext()`를 입력하면, 챗봇이 받는 값을 확인할 수 있습니다. 홈페이지 담당자에게 확인을 부탁해도 됩니다.

## 채팅창 색과 제목 바꾸기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 디자인 설정

1. `헤더 타입`을 고릅니다. `기본형`은 제목과 소제목, `단순형`은 제목만, `배너형`은 이미지를 배경으로 씁니다.
2. `테마 색상`에서 브랜드 색을 고릅니다. 팔레트에 없으면 직접 색상을 선택할 수 있습니다.
3. 색을 바꿨더니 글자가 잘 안 보이면 `헤더 영역 글자 색상`과 `글자 색상 (메시지)`를 조정합니다.
4. `제목`(최대 15자)과 `소제목`(최대 20자)을 적습니다. 고객에게 보이는 채팅창 이름이므로 조직 이름이나 "○○ 상담"처럼 알아보기 쉽게 적습니다.

`배너형`을 고르면 `배너 업로드`로 이미지를 올리고 `높이`와 `투명도 (%)`를 맞춥니다. 제목 `정렬`도 바꿀 수 있습니다.

### 창 크기와 테두리

**위치:** 챗봇 > 설정 > 채팅창 설정 > 창 크기

`창 크기`에서 PC 웹채팅창의 `가로`와 `세로`를 정합니다. PC에만 적용되며, 모바일에서는 모바일에 맞는 크기로 자동 제공됩니다.

사이트 배경이 흰색이라 채팅창 경계가 잘 안 보인다면 `채팅창 테두리/그림자`에서 `테두리 사용`이나 `그림자 사용`을 켜세요. 테두리는 색상과 두께를, 그림자는 색상과 `흐림 정도`, `확산 정도`, `수직 오프셋`을 조정할 수 있습니다.

## 채팅 버튼 모양과 위치 바꾸기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 플로팅 버튼

화면 구석에 떠 있는 채팅 시작 버튼이 플로팅 버튼입니다.

- **모양:** `버튼 타입`이 `기본형`이면 `버튼 프리셋`에서 고르고 색을 정합니다. `커스텀형`이면 `이미지 업로드`로 직접 만든 버튼 이미지를 씁니다. `버튼 크기`와 `모서리 둥글기`도 조정할 수 있습니다.
- **위치:** `버튼 위치`에서 `왼쪽 정렬` 또는 `오른쪽 정렬`을 고르고, 옆 여백과 `아래 여백`으로 미세 조정합니다.

사이트에 "맨 위로" 버튼이나 다른 채팅 버튼이 이미 있다면 겹치지 않게 `아래 여백`을 늘리거나 반대쪽으로 옮기세요. 미리보기 아래에 현재 채팅창 크기와 버튼 위치가 숫자로 표시됩니다.

## 바로가기 메뉴 넣기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 커스텀 메뉴

`커스텀 메뉴 사용`을 켜면 채팅창 하단에 바로가기 메뉴가 생깁니다. 기본 메뉴는 `처음으로`, `오시는 길`, `연락하기`, `상담하기`이며 `메뉴 설정`에서 메뉴마다 아이콘, 이름, 연결을 바꿉니다.

- `채팅방 진입 시 메뉴 노출`: 메뉴를 처음부터 펼쳐 둘지 정합니다. `안읽은 메시지가 있을 경우에만 닫힘`, `항상 열림`, `항상 닫힘` 중에서 고릅니다.
- `커스텀 메뉴 타이틀`: 메뉴가 닫혀 있을 때 표시될 문구입니다.
- `레이아웃`, `메뉴 색상`, `글씨 색상`: 메뉴의 배치와 색을 정합니다.
- `배지 설정`: 눈에 띄게 하고 싶은 메뉴 하나에만 배지를 붙일 수 있습니다.

## 처음 상태로 되돌리기

**위치:** 챗봇 > 설정 > 채팅창 설정 > 설정 초기화

화면 맨 아래 `설정 초기화`를 누르면 모든 채팅창 설정이 초기값으로 돌아갑니다. 초기화도 `저장`을 누르기 전까지는 실제 채팅창에 반영되지 않으므로, 잘못 눌렀다면 저장하지 않고 화면을 벗어나면 됩니다.
