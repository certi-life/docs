# 대시보드 - 발행 현황과 처리할 일 확인하기

> Hospital 대시보드에서 총 발행 인증서 수, 당일 발행 수, 등록 환자 수, 주간 발행 추이, 제품별 발행 수를 확인하고, 상단 안내 배너와 서비스 공지사항, 사용 가이드를 보는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/hospital/screens/dashboard)

로그인하면 가장 먼저 보이는 화면이 `대시보드`입니다. 대시보드는 두 가지를 알려 줍니다. **인증서가 얼마나 발행되고 있는지**, 그리고 **지금 처리해야 할 일이 있는지**입니다. 하루를 시작할 때 위쪽 안내 배너부터 확인하세요.

**위치:** 대시보드

안과 병원에서는 화면의 "인증서"가 모두 "확인서"로 표시됩니다.

## 먼저 처리할 일 확인하기

**위치:** 대시보드 > 상단 안내 배너

화면 위쪽에 안내 배너가 뜨면 처리할 일이 있다는 뜻입니다. 배너는 X를 눌러 닫을 수 있습니다.

| 배너 문구                                      | 뜻                          | 할 일                                                                                            |
| ------------------------------------------ | -------------------------- | ---------------------------------------------------------------------------------------------- |
| "병원 정보 관리에서 비밀번호를 변경해주세요."                 | 처음 로그인한 계정입니다              | [병원 정보 관리](https://docs.certi.life/guide/hospital/screens/hospital-info#비밀번호-바꾸기)에서 비밀번호를 바꿉니다 |
| "'인증서 관리' 메뉴에서 병원 보증사항을 입력해 주세요."          | 인증서에 들어갈 병원 보증 내용이 비어 있습니다 | [인증서 설정](https://docs.certi.life/guide/hospital/screens/certificate-settings)에서 입력합니다          |
| "놓친 예약이 있어요. 환자에게 연락하여 예약 일정을 확정해주세요."     | 확정하지 않은 예약이 있습니다           | [예약 관리](https://docs.certi.life/guide/hospital/screens/reservations-reviews)에서 확정합니다           |
| "서티라이프 새로운 버전이 나왔습니다. 새로고침을 눌러 업데이트 해주세요." | 새 버전이 배포되었습니다              | 브라우저를 새로고침합니다                                                                                  |

## 발행 현황 보기

**위치:** 대시보드

- **숫자 카드:** `총 발행 인증서 수`, `당일 발행 인증서 수`, `전체 등록 환자 수`, `인증서 수신 환자 수`
- **`주간 발행 인증서 수`:** 최근 일주일간 날마다 발행한 수를 차트로 봅니다.
- **`제품별 발행 인증서 수`:** 어떤 제품의 인증서가 많이 발행되었는지 봅니다. 아직 발행 내역이 없으면 "아직 인증서가 발행된 제품이 없습니다."가 표시됩니다.

`전체 등록 환자 수`에 비해 `인증서 수신 환자 수`가 많이 적다면 인증서를 받지 못한 환자가 많다는 뜻입니다. [발행 내역](https://docs.certi.life/guide/hospital/screens/history)에서 발송 상태를 확인해 보세요.

## 공지사항 확인하기

**위치:** 대시보드 > 서비스 공지사항

오른쪽 `서비스 공지사항`에 최근 공지가 보이고, 새 글에는 N 표시가 붙습니다. 글을 누르면 상세가 열립니다. 전체 공지는 왼쪽 메뉴의 `안내` > `공지사항`에서 봅니다. 목록은 `10개씩 보기`, `20개씩 보기`, `50개씩 보기`로 바꿀 수 있고, 상세에서 `첨부파일`을 내려받을 수 있습니다.

중요한 공지는 로그인할 때 `공지사항` 창으로 뜹니다. `확인`을 누르면 닫히고, `다시 보지 않기`를 누르면 같은 공지가 다시 뜨지 않습니다.

`안내` > `사용 가이드`나 대시보드의 사용 가이드 배너를 누르면 사용 가이드가 새 창으로 열립니다.
