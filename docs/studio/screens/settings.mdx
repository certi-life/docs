# 설정 탭 화면

챗봇 상세 화면의 `설정` 탭은 챗봇 하나의 이름, AI 동작, 작동시간, 학습자료, 채널, 채팅창 모양을 정하는 화면입니다. 왼쪽 `설정 메뉴`에서 항목을 고르면 오른쪽에 그 항목의 설정이 열립니다. 챗봇 상세 화면 위쪽에는 `시나리오`, `플로우`, `통계`, `설정` 탭이 있습니다.

## 설정 메뉴

- **위치:** 챗봇 > 설정
- **이 화면에서 할 수 있는 일:** 챗봇 설정 항목을 고르고, 바꾼 내용을 왼쪽 아래 `저장`으로 적용합니다.
- **주요 항목:** `기본 정보`, `AI 설정`, `도구`, `매뉴얼`, `작동시간`, `AI 학습자료 설정`, `채널 설정`, `채팅창 설정`, `챗봇 삭제`.
- **주요 버튼:** `저장`
- **팁:** `도구`와 `매뉴얼`은 메뉴에 `v2 beta`로 표시되는 챗봇 v2용 베타 기능이며 동작과 문구가 바뀔 수 있습니다. `도구`, `매뉴얼`, `AI 학습자료 설정`, `챗봇 삭제`는 바꾸는 즉시 적용되므로 `저장` 버튼이 비활성화됩니다. 저장하지 않고 다른 항목으로 이동하면 "저장하지 않은 변경사항이 있습니다" 확인 창이 뜹니다.

## 설정 항목별 안내

- **위치:** 챗봇 > 설정 > 설정 메뉴
- **이 화면에서 할 수 있는 일:** 아래 표에서 바꾸려는 내용에 맞는 설정 항목을 찾습니다.

| 설정 메뉴 | 여기서 하는 일 | 화면 안내 |
| --- | --- | --- |
| `기본 정보` | 챗봇 프로필 이미지, 이름, 설명을 바꾸고 내보내기 코드를 만듭니다. | [기본 정보 화면](./basic-info) |
| `AI 설정` | 응답 버전, 페르소나, 답변 범위, 언어를 정합니다. | [AI 설정 화면](./ai-settings) |
| `도구` | 챗봇이 답변할 때 함께 쓰는 도구를 추가하거나 제거합니다. | [도구 화면](./tools) |
| `매뉴얼` | 특정 상황에서 챗봇이 따를 매뉴얼을 연결합니다. | [매뉴얼 화면](./manuals) |
| `작동시간` | 챗봇이 작동하지 않는 시간과 특수일을 정합니다. | [작동시간 화면](./operating-hours) |
| `AI 학습자료 설정` | 챗봇이 답변 근거로 쓰는 학습자료를 올리고 연결합니다. | [AI 학습자료 설정 화면](./training-materials) |
| `채널 설정` | 웹채팅, 카카오톡, 네이버 톡톡 등 채널을 연동합니다. | [채널 설정 화면](./channel-settings) |
| `채팅창 설정` | 웹채팅 창과 플로팅 버튼의 모양을 꾸밉니다. | [채팅창 설정 화면](./chat-window-settings) |
| `챗봇 삭제` | 챗봇을 영구적으로 삭제합니다. | [챗봇 삭제 화면](./delete-chatbot) |
