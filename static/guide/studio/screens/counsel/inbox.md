# 응대할 상담 찾기 - 상태 탭, 필터, 검색

> Studio 상담 화면에서 대기·진행중·완료·종료 상태 탭과 기간·채널·챗봇·태그 필터, 활성 유저만·내 상담만·안읽음만 토글, 고객 이름·연락처·상담사·상담내용 검색으로 응대할 상담을 찾고 검색 필터 설정으로 시작 화면을 정하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/counsel/inbox)

상담이 많아지면 "지금 누구에게 답해야 하는지" 찾는 것부터가 일입니다. 방법은 세 가지를 조합하는 것입니다. **상태 탭으로 단계를 고르고, 필터로 좁히고, 검색으로 특정 고객을 찾습니다.**

**위치:** 상담 > 상담 목록

## 상태 탭 이해하기

| 탭     | 어떤 상담인가요                    | 상담원이 할 일                 |
| ----- | --------------------------- | ------------------------ |
| `대기`  | 챗봇이 응대 중이거나 상담원 연결을 기다리는 상담 | 상담원을 기다리는 고객부터 응대를 시작합니다 |
| `진행중` | 상담원이 응대 중인 상담               | 답변을 이어 갑니다               |
| `완료`  | 응대를 마친 상담                   | 필요하면 다시 열어 봅니다           |
| `종료`  | 닫힌 상담                       | 기록 확인용입니다                |

탭마다 세부 토글이 있습니다. `대기` 탭에서 `상담원 대기만`을 켜면 챗봇이 응대 중인 방은 빼고 **사람을 기다리는 고객만** 볼 수 있습니다. 반대로 `챗봇만`을 켜면 챗봇이 응대 중인 방만 봅니다. `완료`와 `종료` 탭에도 챗봇이 끝낸 것과 상담원이 끝낸 것을 나누는 토글이 있습니다.

## 필터로 좁히기

**위치:** 상담 > 상담 목록 > 필터

- **기간:** `오늘`, `1주일`, `1개월`, `6개월` 또는 `직접설정`
- **채널:** `카카오`, `웹챗`, `네이버`, `인스타그램`
- **`챗봇 전체`**, **`태그 전체`:** 특정 챗봇이나 고객 태그의 상담만 봅니다
- **`내 상담만`:** 내가 담당인 상담만 봅니다
- **`안읽음만`:** 아직 읽지 않은 메시지가 있는 상담만 봅니다
- **`활성 유저만`:** 실제로 말을 건 고객만 봅니다

> **활성 유저만이 뭔가요?**
>
> '활성 유저'는 챗봇에게 한 번이라도 말을 건 사람입니다. 켜면 챗봇 인사 후 실제로 메시지를 보낸 고객만 보이고, 끄면 인사 메시지만 받고 아무 말도 하지 않은 방까지 모두 보입니다. 목록이 너무 길다면 켜 두세요.

바쁜 시간에는 `대기` 탭 + `상담원 대기만` + `안읽음만` 조합이 "지금 답해야 할 상담"을 가장 빨리 보여 줍니다. 조건을 모두 지우려면 `초기화`를 누릅니다.

## 고객이나 내용으로 검색하기

**위치:** 상담 > 상담 목록 > 검색

검색창 아래에서 기준을 고른 뒤 검색합니다.

| 기준       | 찾는 방법                                         |
| -------- | --------------------------------------------- |
| `고객 이름`  | 이름으로 찾습니다                                     |
| `고객 연락처` | 숫자만, 전체 번호(10\~11자리)로 찾습니다. 일부 자리만으로는 찾지 않습니다 |
| `상담사`    | 담당 상담사 이름으로 찾습니다                              |
| `상담내용`   | 대화 내용으로 찾습니다. 2자 이상 입력해야 합니다                  |

## 매번 같은 조건으로 시작하기

**위치:** 상담 > 상담 목록 > 검색 필터 설정

필터 옆 톱니(`검색 필터 설정`)를 누르면 `검색 필터 설정` 창에서 필터마다 `순서`, `노출` 여부, `시작 상태`를 정할 수 있습니다. 채팅 화면에 들어올 때마다 여기서 정한 대로 시작합니다.

> **조직 전체에 적용됩니다**
>
> 이 설정은 나만의 설정이 아니라 조직 전체에 적용됩니다. 숨긴 필터는 화면에서 사라지고, 그 필터로 걸러 두었던 값도 함께 비워집니다. 다른 상담원과 상의해서 바꾸세요.

## 고객을 직접 등록하기

**위치:** 상담 > 고객 등록

상태 탭 오른쪽의 `고객 등록`을 누르면 이름이나 연락처로 기존 고객을 찾아 정보를 고치거나, `신규 고객 등록`으로 새 고객을 등록할 수 있습니다. 전화로 먼저 연락 온 고객을 미리 등록해 둘 때 씁니다. 같은 연락처의 고객이 이미 있으면 "같은 연락처 고객이 있습니다"라는 안내와 함께 `이 고객 수정하기`, `선택 고객 병합`, `새 고객으로 등록` 중에서 고르게 됩니다.
