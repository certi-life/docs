# 상담 기록 설정 - 전화상담 기록 양식 만들기

통화가 끝나면 상담사는 "무슨 문의였고 어떻게 처리했는지"를 기록합니다. 기록 양식이 조직의 업무와 맞지 않으면 기록이 제각각이 되어 나중에 통계로 쓸 수 없습니다. `상담 기록 설정`에서는 **기록에 담을 항목을 조직에 맞게 직접 정의**합니다. 여기서 만든 필드는 [전화상담](../phone-counsel) 화면의 `상담 기록`과 통화 기록 상세에 그대로 나타납니다.

**위치:** 설정 > 상담 기록 설정

이 메뉴는 조직의 이용 범위에 따라 표시됩니다. 조작은 저장 버튼 없이 즉시 반영됩니다. 화면에 "사용자 정의 필드 설정 기능이 아직 준비되지 않았습니다"라는 안내가 보이면 아직 쓸 수 없는 상태입니다.

## 기록 양식은 두 부분입니다

| 부분 | 내용 | 예 |
| --- | --- | --- |
| `상담 메모 양식 항목` | 메모를 쓸 때 미리 채워지는 제목들. 새 상담 메모가 이 구조로 시작합니다 | 문의 내용, 안내한 내용, 특이사항 |
| 선택 필드 | 클릭해서 고르는 분류 항목. 통화 기록의 태그와 필터로 쓰입니다 | 문의 유형: 예약 / 가격 / 위치 |

## 메모 양식 만들기

**위치:** 설정 > 상담 기록 설정 > 상담 메모 양식 항목

1. 입력란에 항목 이름을 적어 추가합니다. 예: "특이사항"
2. 항목마다 설명을 적을 수 있습니다. AI가 이 항목을 뽑아낼 때 참고하는 설명이며 최대 500자입니다. 예: "월 요금을 원 단위 숫자로"
3. 오른쪽 `미리보기`에서 새 상담 메모가 어떻게 시작하는지 확인합니다.

상담 요약 발송도 이 항목 구조를 따릅니다.

## 선택 필드 만들기

**위치:** 설정 > 상담 기록 설정 > 새 필드 추가

1. `새 필드 추가`에 필드 이름을 적습니다. 예: "상담 채널"
2. `단일 선택` 또는 `복수 선택`을 고릅니다. 하나만 해당하는 분류는 단일, 여러 개가 해당할 수 있으면 복수입니다.
3. 설명을 적습니다(선택, 최대 100자). AI가 이 필드를 분류할 때 힌트로 씁니다. 예: "회원가입 방법을 물었을 때만 선택"
4. `필드 추가`를 누른 뒤, 만들어진 필드 카드에서 항목을 하나씩 추가합니다.

필드는 끌어서 순서를 바꾸고, 이름을 고치거나 삭제할 수 있습니다.

:::tip[필드는 적을수록 좋습니다]
화면에도 안내되어 있듯 필드가 많으면 상담사의 입력이 느려집니다. 통계로 실제로 볼 분류만 남기세요. 어떤 필드를 둘지 설계하는 방법은 [상담 기록 필드 설정](../../consultation-records)에 자세히 있습니다.
:::

## AI가 기록을 대신 채우게 하기

**위치:** 설정 > 상담 기록 설정 > AI 자동 선택

`AI 자동 선택`을 켜면 통화가 끝났을 때 AI의 분류 결과가 상담 기록 필드에 자동으로 선택(저장)됩니다. 꺼 두면 AI 결과는 참고용으로만 표시되고 상담사가 직접 고릅니다. 켠 뒤의 통화부터 적용됩니다.

:::caution[상담사가 적은 내용을 덮어씁니다]
이 기능이 켜져 있는 동안에는 통화가 끝날 때마다 AI가 상담사가 선택해 둔 기록 값과 작성해 둔 메모를 **모두 덮어씁니다.** 상담사가 통화 중에 직접 기록하는 조직이라면 꺼 두고 참고용으로만 쓰는 것이 안전합니다. 켜더라도 AI의 분류가 맞는지 주기적으로 확인하세요.
:::
