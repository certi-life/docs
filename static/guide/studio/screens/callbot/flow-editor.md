# 플로우 편집 - 통화의 대화 순서 직접 그리기

> Studio 콜봇의 플로우 편집 화면에서 대화·도구·분기·추출·에이전트 전환·통화 전환·통화 종료 노드로 통화 흐름을 구성하고, 변수를 쓰고, 검증하고 저장하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/callbot/flow-editor)

플로우 타입 에이전트는 AI가 알아서 대화하게 두지 않고, **통화가 어떤 순서로 진행될지 노드로 직접 그립니다.** 본인 확인 → 용건 확인 → 예약 안내처럼 순서가 중요하고 빠뜨리면 안 되는 통화에 적합합니다. 자유로운 문의 응대가 목적이라면 프롬프트 타입이 더 간단합니다.

**위치:** 콜봇 > 에이전트 > (플로우 에이전트 선택) > 플로우 편집기 열기

플로우 에이전트의 [에이전트 설정](https://docs.certi.life/guide/studio/screens/callbot/agent-settings) 화면에서 `플로우 편집기 열기`를 누르면 `플로우 편집` 화면이 열립니다.

## 노드 종류

화면 아래 팔레트에서 노드를 추가하고 선으로 연결합니다.

| 노드        | 쓰임새                                     |
| --------- | --------------------------------------- |
| `시작`      | 통화가 시작되는 지점입니다. 하나만 있으며 추가할 수 없습니다      |
| `대화`      | 고객과 대화하는 단계입니다. 이 단계에서 무엇을 묻고 안내할지 적습니다 |
| `분기`      | 조건에 따라 다음 단계를 나눕니다                      |
| `추출`      | 대화에서 이름, 날짜 같은 값을 뽑아 변수로 저장합니다          |
| `도구`      | API 호출 같은 도구를 실행합니다                     |
| `에이전트 전환` | 다른 에이전트에게 통화를 넘깁니다                      |
| `통화 전환`   | 상담사에게 통화를 넘깁니다                          |
| `통화 종료`   | 통화를 끝냅니다                                |
| `코멘트`     | 흐름에 설명을 남기는 메모입니다. 통화에는 영향을 주지 않습니다     |

## 플로우 만들고 저장하기

**위치:** 콜봇 > 에이전트 > 플로우 편집

1. 팔레트에서 필요한 노드를 추가합니다. 새 플로우 에이전트는 "시작 → 대화 → 통화 종료" 기본 그래프로 만들어져 있습니다.
2. 노드를 눌러 내용을 적고, 노드 사이를 선으로 연결합니다.
3. 노드가 많아져 복잡해지면 `자동 정렬`로 깊이 기준으로 다시 배치합니다.
4. `검증`을 누릅니다. "문제가 없어요. 저장할 수 있습니다."가 나오면 통과입니다. "고쳐야 할 곳이 N군데 있어요"가 나오면 표시된 곳을 고칩니다.
5. `저장`을 누릅니다. "플로우가 저장되었습니다. 상세 페이지에서 테스트·배포할 수 있어요."가 표시됩니다.

> **저장과 배포는 다릅니다**
>
> `저장`은 플로우를 저장할 뿐 실제 통화에 반영하지는 않습니다. 에이전트 설정 화면으로 돌아가 테스트한 뒤 [`배포`](https://docs.certi.life/guide/studio/screens/callbot/agent-settings#시험하고-배포하기)를 눌러야 실제 통화에 쓰입니다. 저장하지 않고 화면을 벗어나려 하면 `저장하지 않은 변경사항이 있어요` 확인 창("지금 나가면 편집한 내용이 사라집니다. 저장하지 않고 나갈까요?")이 나옵니다. `계속 편집`을 누르면 편집 화면에 머물고, `나가기`를 누르면 편집한 내용이 사라집니다. 새로고침하거나 브라우저 탭을 닫을 때는 브라우저가 직접 떠날지 묻습니다.

## 변수 사용하기

**위치:** 콜봇 > 에이전트 > 플로우 편집 > 변수

왼쪽 변수 패널의 변수를 누르면 복사되고, 프롬프트나 조건에 붙여 넣어 씁니다.

- `시스템 변수`: `에이전트 ID`, `발신 번호`, `통화 ID`, `수신 번호`, `현재 시각`
- `추출 변수`: `추출` 노드에서 뽑은 값. 예를 들어 앞 단계에서 뽑은 예약 희망일을 뒤 단계의 안내 문장에 넣을 수 있습니다

## 권장 운영법

- 고객이 예상 밖의 말을 했을 때 갈 곳이 없으면 통화가 어색하게 끊깁니다. 분기마다 "그 밖의 경우"가 상담사 연결이나 다시 묻기로 이어지게 하세요.
- 모든 경로가 `통화 종료` 또는 `통화 전환`으로 끝나는지 `검증`으로 확인합니다.
- 처음에는 핵심 흐름 하나만 만들어 배포하고, [전화상담](https://docs.certi.life/guide/studio/screens/phone-counsel)에서 실제 통화를 보며 가지를 늘려 갑니다.
