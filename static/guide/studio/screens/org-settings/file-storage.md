# 상담 파일 관리 - 첨부파일 저장 용량 확인하고 정리하기

> Studio 설정의 상담 파일 관리에서 상담 메시지 첨부파일의 사용량과 파일 수, 용량 초과로 차단된 파일을 확인하고 파일을 삭제해 용량을 확보하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/org-settings/file-storage)

채팅 상담에서 주고받은 이미지와 파일은 조직의 저장 용량을 차지합니다. 용량이 가득 차면 오래된 파일이 `용량 초과` 상태가 되어 열 수 없게 됩니다. `상담 파일 관리`에서는 지금 얼마나 쓰고 있는지 확인하고, 필요 없는 파일을 지워 용량을 확보합니다.

**위치:** 설정 > 상담 파일 관리

## 사용량 확인하기

화면 위쪽 요약에서 한눈에 확인합니다.

| 항목      | 뜻                                   |
| ------- | ----------------------------------- |
| `사용량`   | 사용 중인 용량과 한도. 한도가 없으면 `무제한`으로 표시됩니다 |
| `파일 수`  | 용량 측정이 끝난 파일 수                      |
| `차단 파일` | 용량 초과로 차단된 파일의 용량                   |
| `집계`    | 아직 용량이 측정되지 않은 파일 수                 |

수치가 최신이 아닌 것 같으면 `새로고침`을 누릅니다. 화면의 안내처럼 기능 적용 이후의 채팅 파일만 집계되며, 최신 파일부터 한도 안에 포함됩니다. 즉 용량이 넘치면 **오래된 파일부터** 차단됩니다.

## 파일 지워 용량 확보하기

**위치:** 설정 > 상담 파일 관리 > 파일 목록

1. `파일 목록`에서 지울 파일을 찾습니다. `파일`, `용량`, `발송자`(`고객 발송` / `상담사 발송`), `상태`, `메시지 시각`이 표시됩니다.
2. 파일의 삭제 버튼을 누르고 "이 파일을 삭제하시겠습니까?" 확인 창에서 `삭제`를 누릅니다.

파일 상태는 `사용 가능`, `용량 초과`, `삭제 대기`, `삭제됨`, `삭제 실패`로 표시됩니다. `삭제 실패`인 파일은 삭제 버튼을 다시 눌러 재시도합니다.

> **삭제한 파일은 상담 기록에서도 열 수 없습니다**
>
> 파일을 지우면 그 상담의 대화 내용에서도 해당 첨부를 더 이상 볼 수 없습니다. 분쟁이나 확인에 필요할 수 있는 파일은 조직의 보관 기준에 따라 남겨 두세요.

## 용량이 부족할 때

정리해도 부족하다면 화면의 안내대로 고객 센터에 저장 용량 증설을 문의하세요. 평소에는 상담원이 큰 파일 대신 링크로 안내하도록 하면 용량을 아낄 수 있습니다. 상담원이 파일을 첨부하는 방법은 [상담의 답변 도구](https://docs.certi.life/guide/studio/screens/counsel/reply-tools#파일과-이미지-보내기)를 참고하세요.
