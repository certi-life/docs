# 상담 시간 - 진료시간과 상담·챗봇·콜봇 운영 시간 정하기

`상담 시간`에는 비슷해 보이지만 **서로 다른 네 가지 시간**이 있습니다. 병원이 문을 여는 시간, 상담원이 채팅에 답할 수 있는 시간, 챗봇이 작동하는 시간, 콜봇이 전화를 받는 시간입니다. 네 가지는 따로 저장되고 쓰임새도 다르므로, 무엇을 바꾸려는지부터 확인하세요.

**위치:** 설정 > 운영 설정 > 상담 시간

| 탭 | 이 시간이 쓰이는 곳 |
| --- | --- |
| `병원 진료시간` | 챗봇이 "진료시간이 어떻게 되나요?"에 답할 때 (병원 조직에만 표시) |
| `채팅 상담` | 상담원이 채팅 상담을 받을 수 있는 시간. 시간 외에는 운영 시간 외 메시지가 나갑니다 |
| `AI 챗봇` | 챗봇이 작동하지 않을 시간 |
| `AI 콜봇` | 콜봇이 전화를 받는 시간과 상담사 연결 가능 시간 |

## 병원 진료시간 등록하기

**위치:** 설정 > 운영 설정 > 상담 시간 > 병원 진료시간

병원 진료시간은 상담·챗봇·콜봇의 운영시간과는 별개로 저장되는, 말 그대로 병원이 진료하는 시간입니다. 챗봇에 [`병원 진료시간 활용` 도구](../chatbot/settings/tools#진료시간을-항상-최신으로-안내하기)를 추가하면 챗봇이 이 값으로 진료시간을 안내합니다.

1. `요일별 진료시간`에서 `진료일`을 고르고 `진료시간`과 `점심시간`을 입력합니다. 모든 요일이 같다면 `모든 요일 시간 동일`을 켜면 한 번에 입력됩니다. 점심시간이 없으면 `점심시간 없음`을 체크합니다.
2. 임시로 쉬는 날은 `임시 휴진일 설정`의 `날짜 추가`로 등록합니다. 등록한 날짜는 진료시간이 설정되어 있어도 휴진으로 처리됩니다.
3. 반대로 정기 휴무 요일인데 그날만 진료한다면 `정기 휴무 예외일 설정`의 `예외일 추가`로 날짜와 그날의 진료시간을 등록합니다.
4. 화면 아래 저장 바의 `저장`을 누릅니다.

지나간 휴진일은 흐리게 표시되며 자동으로 지워지지 않습니다. `지난 날짜 삭제`로 정리하세요.

## 채팅 상담 가능 시간 정하기

**위치:** 설정 > 운영 설정 > 상담 시간 > 채팅 상담

1. `24시간 상담 가능`을 끄면 `상담 가능 시간 설정`이 나타납니다.
2. 요일마다 상담 가능 시간을 넣습니다. `평일 업무시간 (09:00~18:00) 적용`으로 한 번에 채우거나, `병원 진료시간 적용`으로 진료시간과 똑같이 맞출 수 있습니다. 한 요일의 설정은 `다른 요일에 복사`로 옮깁니다.
3. 공휴일처럼 특정 날짜만 다르게 하려면 `특수일 상담 설정`에서 날짜와 `상담 가능` / `상담 불가`를 등록합니다.
4. 저장 바의 `저장`을 누릅니다.

`근무 외 시간 상담 인입 허용`을 켜면 상담 시간이 아닐 때도 상담을 접수하고, 안내 메시지와 정보 수집 메시지를 발송합니다. 밤사이 들어온 문의를 다음 날 아침에 이어서 응대하려면 켜 두세요. 이때 고객에게 나가는 문구는 [자동메시지](./auto-messages)의 `운영 시간 외`에서 정합니다.

## 모든 챗봇의 작동시간을 한 번에 바꾸기

**위치:** 설정 > 운영 설정 > 상담 시간 > AI 챗봇

챗봇 작동시간은 원래 챗봇마다 [`작동시간`](../chatbot/settings/operating-hours)에서 따로 정합니다. 챗봇이 여러 개인데 모두 같은 시간으로 맞추고 싶을 때 이 화면을 씁니다.

1. `적용 방식`에서 전체 일괄 또는 특정 챗봇을 고릅니다.
2. 미작동 시간을 설정합니다. 챗봇 화면과 마찬가지로 **체크한 시간이 챗봇이 작동하지 않는 시간**입니다.
3. `저장`을 누릅니다. 버튼에 "챗봇 N개에 저장"처럼 대상 수가 표시됩니다.

:::caution[기존 설정을 덮어씁니다]
전체 일괄로 저장하면 "저장하면 챗봇 N개의 작동시간이 지금 설정으로 덮어써집니다"라는 경고가 나옵니다. 챗봇마다 다르게 맞춰 둔 시간이 있다면 사라지니 확인하고 저장하세요. 일부 챗봇에서 실패하면 결과에 실패한 챗봇이 표시되고, 저장 버튼을 다시 누르면 실패한 챗봇만 재시도합니다.
:::

## 콜봇 운영시간 정하기

**위치:** 설정 > 운영 설정 > 상담 시간 > AI 콜봇

콜봇 화면은 네 개의 카드로 나뉘고 카드마다 따로 저장합니다.

| 카드 | 하는 일 |
| --- | --- |
| `운영시간 설정` | 요일별 `운영 시간`, `24시간 운영`, `휴일`을 정합니다. 휴일에는 운영 외 흐름이 동작합니다 |
| `상담사 바로 연결시간` | 통화 전환을 허용할 시간을 콜봇 운영시간과 별개로 정합니다. 끄면 콜봇 운영시간을 그대로 따릅니다 |
| `휴식시간 설정` | 점심시간처럼 운영시간 안의 쉬는 시간을 추가합니다 |
| `휴무일 관리` | 지정한 날짜는 요일 설정과 무관하게 종일 운영시간 외로 처리됩니다. `매년 반복`을 켤 수 있습니다 |

카드에 "저장 기능이 아직 준비되지 않았습니다"라는 안내가 보이면 그 카드의 값은 아직 저장되지 않는 상태입니다. 이 경우 콜봇 운영시간은 조직의 CertiLife 담당자에게 문의하세요.

## 권장 운영법

- 네 가지 시간이 서로 어긋나면 "챗봇도 쉬고 상담원도 없는" 빈 시간이 생깁니다. 챗봇이 쉬는 시간에는 상담원이 응대할 수 있는지 맞춰 보세요.
- 명절과 임시 휴진은 미리 등록하고, 연휴가 끝나면 `지난 날짜 삭제`로 정리합니다.
- 연결 기준은 [상담원 연결 정책](../../../products/ai-chatbot/handoff-policy)을 참고하세요.
