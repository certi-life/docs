# AI 설정 - 챗봇의 말투와 답변 범위 정하기

> Studio 챗봇 설정의 AI 설정에서 페르소나 선택, 커스텀 페르소나 설정(시스템 프롬프트 작성·버전 관리·이 내용으로 대화해보기), 학습자료로만 답변하기, 응답 버전(v1·v2), 챗봇 기본 언어와 다국어 응대 방식을 목적별로 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings)

`AI 설정`은 챗봇이 **어떤 말투로, 어디까지, 어떤 언어로** 답할지 정하는 화면입니다. 챗봇의 성격을 바꾸는 방법은 두 가지입니다. 준비된 페르소나 중에서 고르거나, `커스텀`을 골라 시스템 프롬프트를 직접 씁니다. 여기에 "자료에 있는 내용만 답하기"와 외국어 응대 방식을 더하면 AI 답변의 기본 설정이 끝납니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > AI 설정

이 화면은 Studio(studio.certi.life)에 로그인해서 엽니다. 맨 위 `응답 버전`은 접힌 한 줄로 보이고, 눌러야 펼쳐집니다. 화면의 항목은 위에서부터 `응답 버전`, `페르소나`, `AI 응답 타이틀`, `플로우 선택 안내 메시지`, `학습자료로만 답변하기`, `AI 답변 시나리오 사용하기`, `이미지·미디어 답변`, `챗봇 기본 언어`, `다국어 응대 방식` 순서입니다. 이 문서는 목적별로 묶어 설명하므로 화면 순서와 다릅니다.

## 이럴 때 사용하세요

| 하고 싶은 일                   | 이 페이지의 섹션                                                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------ |

| 역할과 응대 규칙을 직접 써서 넣고 싶어요   | [프롬프트를 직접 써서 챗봇 성격 정하기](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#프롬프트를-직접-써서-챗봇-성격-정하기) |
| 챗봇이 없는 내용을 지어내지 않게 하고 싶어요 | [자료에 있는 내용만 답하게 하기](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#자료에-있는-내용만-답하게-하기)         |

| 외국인 고객 응대 방식을 정하고 싶어요     | [외국어로 문의한 고객 응대하기](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#외국어로-문의한-고객-응대하기)           |

`응답 버전`만 선택 즉시 적용되고, 나머지는 왼쪽 아래 `저장`을 눌러야 적용됩니다.

## 준비된 페르소나 고르기

**위치:** 챗봇 > 설정 > AI 설정 > 페르소나

`페르소나` 카드 중 하나를 누르고 `저장`하면 챗봇의 대화 스타일이 바뀝니다. 지금 적용된 카드에는 `사용중` 표시가 붙습니다.

| 페르소나           | 성격                 | 이런 응대에 맞습니다           | 화면 표시           |
| -------------- | ------------------ | --------------------- | --------------- |
| `의료 전문 상담 매니저` | 정중하고 정보 중심, 실무적    | 빠르고 정확한 진료 정보를 원하는 고객 | 선택 가능           |
| `의사 어시스턴트형`    | 객관적이고 근거 중심        | 의학적 근거와 임상 정보가 필요한 고객 | `준비중` 배지, 선택 불가 |
| `AI 의료 큐레이터형`  | 중립적이고 분석적, 추천 중심   | 여러 옵션을 비교해 추천받고 싶은 고객 | `준비중` 배지, 선택 불가 |
| `커스텀`          | 직접 작성한 시스템 프롬프트 사용 | 우리 조직만의 응대 방식이 필요한 경우 | 선택 가능           |

`준비중` 배지가 붙은 카드는 아직 고를 수 없습니다. 지금 고를 수 있는 것은 `의료 전문 상담 매니저`와 `커스텀` 두 가지입니다. 카드에 마우스를 올리면 대상 고객과 예시 문장을 볼 수 있습니다. 어느 것을 골라야 할지 모르겠다면 `의료 전문 상담 매니저`로 시작해 실제 답변을 본 뒤 바꾸세요.

## 프롬프트를 직접 써서 챗봇 성격 정하기

**위치:** 챗봇 > 설정 > AI 설정 > 페르소나 > 커스텀 (창 제목 `커스텀 페르소나 설정`)

`페르소나` 카드 중 `커스텀`을 누르면 `커스텀 페르소나 설정` 창이 열립니다. 이 창에서는 AI의 역할과 응대 방식을 정의하는 시스템 프롬프트를 직접 쓰고, 고친 이력을 버전으로 남기고, 적용하기 전에 미리 대화해 볼 수 있습니다.

1. `기본 페르소나`를 고릅니다.
   - `자율형`: 작성한 프롬프트만 기준으로 응답합니다.
   - `병원 최적화`: 병원 안내 전용 안전 규칙을 함께 적용합니다. 병원 상담용이라면 이쪽이 안전합니다.
2. `시스템 프롬프트`에 역할, 말투, 하면 안 되는 것을 적습니다. 제목 옆 전구 아이콘(`작성 팁`)을 누르면 작성 요령을 볼 수 있습니다.
3. **`이 내용으로 대화해보기`를 눌러 먼저 시험합니다.** 오른쪽에 `이 프롬프트로 대화해보기` 창이 열리고, 고객처럼 질문을 보내 답변을 확인할 수 있습니다. 저장하지 않은 내용으로 답하며, 이 대화는 상담 기록과 통계에 남지 않습니다.
4. 마음에 들면 `변경 메모 (선택)`에 무엇을 바꿨는지 적고 `수정사항 저장하기`를 누릅니다.

> **저장과 적용은 다릅니다**
>
> `수정사항 저장하기`는 새 버전으로 **기록만** 합니다. 챗봇은 지금 사용 중인 내용으로 계속 답합니다. 저장과 동시에 챗봇에 적용하려면 `저장하고 바로 활용하기`를 체크하세요. 버튼 아래 안내 문구에 어느 쪽으로 동작할지 표시됩니다.

프롬프트를 잘 쓰는 요령은 화면의 `작성 팁`과 같습니다. AI의 역할과 정체성을 분명히 정의하고, 응대 스타일과 톤을 구체적으로 적고, 제약사항과 금지사항을 포함하고, 예시 답변 형식을 주면 응답이 더 일관됩니다.

### 이전 버전으로 되돌리거나 비교하기

창 오른쪽 `버전` 목록에 저장한 이력이 쌓입니다.

- **되돌리기:** 목록에서 버전을 누르면 그 내용이 편집기에 불러와집니다. `이 버전 사용하기`를 누르면 챗봇이 바로 그 내용으로 응답합니다.
- **비교하기:** `비교`를 누르고 두 버전을 선택한 뒤 `확인`하면 `왼쪽`과 `오른쪽`으로 나란히 달라진 부분을 볼 수 있습니다.
- **표시 읽기:** 챗봇에 적용된 버전에는 `사용 중`, 편집기에 열려 있는 버전에는 `편집중`이 붙습니다. 페르소나 카드의 `사용중`과 띄어쓰기가 다르지만 뜻은 같습니다.

다른 버전을 불러올 때 쓰고 있던 내용은 사라지지 않고 `저장 전 초안` 항목에 남습니다. 단, 초안은 지금 쓰는 브라우저에만 보관되므로 다른 컴퓨터에서는 보이지 않습니다.

편집기 내용이 챗봇에 적용된 내용과 같을 때는 버튼 대신 `사용 중` 표시만 보입니다. 내용을 고치면 `수정사항 저장하기`가, 적용 중이 아닌 버전을 불러오면 `이 버전 사용하기`가 나타납니다.

## 자료에 있는 내용만 답하게 하기

**위치:** 챗봇 > 설정 > AI 설정 > 학습자료로만 답변하기

`학습자료로만 답변하기`를 켜면 챗봇은 등록한 학습자료에 있는 내용만 답하고, 없는 내용은 답하지 않습니다. 끄면 학습자료에 일반 AI 지식을 더해 답합니다.

병원이나 의료 관련 상담이라면 **켜 두는 것을 권장합니다.** AI가 일반 지식으로 그럴듯하게 답한 내용이 우리 조직의 실제 안내와 다를 수 있기 때문입니다. 대신 자료에 없는 질문에는 답하지 못하므로, [`AI 학습자료 설정`](https://docs.certi.life/guide/studio/screens/chatbot/settings/training-materials)에 자료를 충분히 넣고 [`통계` 탭](https://docs.certi.life/guide/studio/screens/chatbot/statistics)에서 답하지 못한 질문을 보강해 주세요.

## 응답 버전 바꾸기

**위치:** 챗봇 > 설정 > AI 설정 > 응답 버전

화면 맨 위 `응답 버전`에서 고객에게 답변할 버전을 `v1`과 `v2` 중에서 고릅니다. 이 항목은 평소에 접혀 있어 `응답 버전`과 `현재 v2 사용 중`(또는 `현재 v1 사용 중`)이 적힌 한 줄만 보입니다. 그 줄을 눌러 펼쳐야 `v1`, `v2` 버튼과 `학습자료 동기화`가 나타납니다. [`도구`](https://docs.certi.life/guide/studio/screens/chatbot/settings/tools)와 [`매뉴얼`](https://docs.certi.life/guide/studio/screens/chatbot/settings/manuals)은 v2에서만 동작합니다.

|             | `v1`                                                                                                            | `v2`                                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 학습자료를 넣는 방법 | [파일을 직접 올립니다](https://docs.certi.life/guide/studio/screens/chatbot/settings/training-materials#v1-파일을-올려-학습시키기) | [백과사전 문서를 연결합니다](https://docs.certi.life/guide/studio/screens/chatbot/settings/training-materials#v2-백과사전-문서를-연결하기) |
| `도구`, `매뉴얼` | 동작하지 않습니다                                                                                                       | 동작합니다                                                                                                               |
| 학습자료 동기화    | 누를 수 있습니다                                                                                                       | 누를 수 없습니다. v1로 전환한 뒤에 동기화합니다                                                                                        |

응답 버전은 `저장`을 누르지 않아도 선택 즉시 고객 답변에 적용됩니다. 상담이 많은 시간을 피해 바꾸세요. v2에서 v1로 되돌리는 것도 같은 자리에서 합니다.

1. `응답 버전` 줄을 눌러 펼친 뒤 `v2`를 누릅니다. 처음 바꿀 때는 "학습자료 동기화를 진행하시겠습니까?" 창이 뜹니다.
2. `동기화 후 v2로 전환`을 누르면 기존 학습자료를 v2용으로 가져오기 시작합니다. 자료 양에 따라 몇 분 이상 걸릴 수 있습니다.
3. 준비가 끝나면 자동으로 v2로 전환됩니다. **그동안은 현재 버전으로 계속 응답하므로 상담이 끊기지 않습니다.**

동기화는 `원본 확인` → `문서·태그 등록` → `검색 준비 확인` → `챗봇 연결` → `기존 자료 정리` 순서로 진행되며 파일별 진행 상황을 볼 수 있습니다. 중간에 화면을 닫아도 현재 단계까지 저장되어, 다시 열고 `이어서 진행`을 누르면 됩니다. 실패한 파일이 있으면 `실패 항목 다시 시도`가 나타납니다.

v2로 답하는 동안에는 `학습자료 동기화`를 누를 수 없습니다. 화면에는 "v2로 응답하는 동안에는 학습자료를 동기화할 수 없습니다. 동기화 도중의 자료가 고객 답변에 바로 쓰이기 때문입니다. 원본 자료를 다시 가져오려면 v1로 전환해 동기화한 뒤 v2로 전환해 주세요."라고 표시됩니다. v1 쪽에 새 파일을 올려서 v2 자료를 다시 맞추고 싶다면 `v1`로 전환하고 `학습자료 동기화`를 실행한 뒤 다시 `v2`로 전환하세요. 문제가 생겨 문의할 때는 화면에 표시되는 작업 번호를 함께 알려 주면 확인이 빠릅니다.

## AI 답변에 형식 입히기

**위치:** 챗봇 > 설정 > AI 설정 > AI 답변 시나리오 사용하기

AI가 만든 답변을 그대로 글로만 내보내지 않고 카드나 버튼을 덧붙이고 싶을 때 씁니다. `AI 답변 시나리오 사용하기`를 켜면 `AI 답변 시나리오 설정` 카드가 나타나고, `AI 답변 시나리오로 이동`을 누르면 [`시나리오` 탭](https://docs.certi.life/guide/studio/screens/chatbot/scenarios)의 `AI 답변 시나리오` 편집 화면이 열립니다.

## AI 응답 제목과 안내 문구 바꾸기

**위치:** 챗봇 > 설정 > AI 설정 > AI 응답 타이틀

- `AI 응답 타이틀`: AI 답변 위에 표시되는 제목입니다.
- `플로우 선택 안내 메시지`: 같은 태그를 가진 [플로우](https://docs.certi.life/guide/studio/screens/chatbot/flows)가 여러 개일 때 고객에게 "다음 중 어떤 항목을 확인하시겠습니까?"처럼 묻는 문구입니다.

둘 다 비워 두고 저장하면 기본 안내 문구가 자동으로 사용됩니다.

## 고객이 보낸 이미지에 답하기

**위치:** 챗봇 > 설정 > AI 설정 > 이미지·미디어 답변

`이미지·미디어 답변`을 켜면 고객이 보낸 이미지 등을 AI가 확인하고 답합니다. 끄면 `off일 때 챗봇이 뭐라고 답할까요?`에 적어 둔 안내 멘트가 대신 나갑니다. 고객이 증상 사진을 보내 판단을 요청할 수 있는 업종이라면 끄고, "사진은 확인이 어려우니 내용을 글로 알려 달라"는 안내를 적어 두는 편이 안전합니다.

## 외국어로 문의한 고객 응대하기

**위치:** 챗봇 > 설정 > AI 설정 > 다국어 응대 방식

먼저 `챗봇 기본 언어`를 고릅니다. 챗봇의 AI 답변, 시나리오, 학습자료가 이 언어로 운영된다고 간주합니다. 페르소나와 시스템 프롬프트, 학습자료의 언어를 하나로 통일해야 챗봇이 일관된 언어로 답합니다. 목록의 언어 이름은 `한국어 (Korean)`, `中文 (Chinese)`, `日本語 (Japanese)`처럼 표시됩니다. 이 목록은 상담 번역이 지원하는 8개 언어 목록과 다르고, 중국어를 간체와 번체로 나누지 않습니다. 전체 선택지는 화면에서 확인하세요.

그다음 `다국어 응대 방식`에서 고객이 다른 언어로 말했을 때의 대응을 고릅니다.

| 방식          | 동작                           | 이럴 때 고르세요               |
| ----------- | ---------------------------- | ----------------------- |
| `일반 응답`     | 외국어 질문에도 기본 언어로 답합니다         | 외국인 고객이 거의 없을 때         |
| `자동 번역 응답`  | AI 답변과 학습자료를 고객 언어로 번역해 답합니다 | 외국인 문의를 챗봇이 1차로 받아야 할 때 |
| `상담원 연결 안내` | 고객 언어로 상담원 연결 버튼을 보여 줍니다     | 외국어 상담은 사람이 직접 하고 싶을 때  |

> **자동 번역의 한계**
>
> 시나리오 카드, 플로우, 버튼은 자동 번역되지 않고 운영자가 입력한 그대로 나갑니다. 또 학습자료가 번역되는 과정에서 뜻이 정확히 전달되지 않을 수 있습니다. 정확한 안내가 중요한 언어는 그 언어 전용 챗봇을 따로 만드는 것을 권장합니다. 전용 챗봇을 만든 뒤에는 [채널 설정](https://docs.certi.life/guide/studio/screens/chatbot/settings/channel-settings)에서 그 언어 고객이 들어오는 채널(예: LINE, WhatsApp, 별도 웹채팅)을 그 챗봇에 연결합니다.

상담원이 외국어 고객과 직접 대화할 때의 번역은 [상담 메시지 번역](https://docs.certi.life/guide/products/ai-chatbot/message-translation)을 참고하세요.

## 문제가 생기면

### `확인 필요`

접힌 `응답 버전` 줄에 `확인 필요`가 보이면 학습자료 동기화가 실패했거나, 일부 항목을 정리하지 못했거나, 응답 버전을 읽지 못했다는 뜻입니다.

1. `응답 버전` 줄을 눌러 펼칩니다.
2. 진행 상황 아래의 안내를 읽습니다. `파일별 진행 상황`을 펼치면 `실패`로 표시된 파일과 사유가 보입니다.
3. `실패 항목 다시 시도`(또는 `정리 다시 시도`)가 보이면 누릅니다.
4. 펼친 영역 아래의 `상태 다시 확인`을 눌러 결과를 다시 읽습니다.

그래도 `확인 필요`가 남으면 화면의 `문의 시 작업 번호:` 뒤의 번호와 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.

### `지식관리에서 수정한 문서인데 원본 파일도 바뀌었습니다. 어느 쪽을 사용할지 선택해 주세요.`

동기화할 파일이 백과사전에서 고친 문서이고, v1 원본 파일도 그 뒤에 바뀌었다는 뜻입니다. 어느 쪽을 쓸지 정해야 다시 시도할 수 있습니다.

1. 파일마다 `원본으로 덮어쓰기` 또는 `내 수정 유지`를 고릅니다. `원본으로 덮어쓰기`를 골라도 백과사전에서 고친 내용은 문서의 버전 기록에 남습니다.
2. 모든 충돌 파일을 고른 뒤 `실패 항목 다시 시도`를 누릅니다.

### `정리하지 못한 항목 N개 · 학습자료 연결은 완료됐습니다`

v2 학습자료 연결은 끝났고, 이전 자료를 정리하는 단계에서 일부 항목만 남았다는 뜻입니다. 챗봇 답변에는 영향이 없습니다. `정리 다시 시도`를 누르고, 같은 항목이 계속 남으면 작업 번호를 적어 조직의 CertiLife 담당자에게 알립니다.

### `응답 버전을 확인하지 못했습니다. 다시 확인해 주세요.`

지금 챗봇이 어느 버전으로 답하는지 읽지 못했다는 뜻입니다. 챗봇의 응답 버전이 바뀐 것은 아닙니다.

1. 펼친 영역 아래의 `상태 다시 확인`을 누릅니다.
2. 그래도 같으면 브라우저를 새로고침합니다.

"처리 결과를 확인하지 못했습니다. 상태를 다시 확인해 주세요. 이미 처리된 작업은 서버에 보존됩니다."가 나올 때도 같은 순서로 확인합니다. "학습자료를 동기화할 권한이 없습니다. 관리자에게 문의해 주세요."나 "동기화를 시작할 수 없습니다. 데이터 저장 환경 확인이 필요합니다. 관리자에게 문의해 주세요."가 나오면 다시 눌러도 달라지지 않으므로, 화면의 문구를 적어 조직의 CertiLife 담당자에게 알립니다.

### `응답 버전` 줄의 표시

| 화면 표시                      | 뜻                                                                                                        |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `현재 v1 사용 중`, `현재 v2 사용 중` | 지금 고객에게 답하는 버전입니다                                                                                        |
| `확인 중`                     | 응답 버전을 읽고 있습니다                                                                                           |
| `처리 중`                     | 버전을 바꾸거나 동기화하는 중입니다. 화면을 닫아도 현재 단계까지 저장됩니다                                                               |
| `동기화 이어서 진행`               | 멈춘 동기화가 있습니다. 펼쳐서 `이어서 진행`을 누릅니다                                                                         |
| `확인 필요`                    | 위의 [`확인 필요`](https://docs.certi.life/guide/studio/screens/chatbot/settings/ai-settings#확인-필요) 순서대로 확인합니다 |

`응답 버전`을 뺀 나머지 항목은 왼쪽 아래 `저장`을 눌러야 적용됩니다. 저장하지 않고 다른 설정으로 이동하면 바꾼 내용이 사라지며, 저장 방식은 [설정 한눈에 보기](https://docs.certi.life/guide/studio/screens/chatbot/settings/menu#저장은-이렇게-됩니다)에 정리되어 있습니다.
