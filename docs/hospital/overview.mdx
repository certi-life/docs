# Hospital 시작하기

Hospital은 병원 사용자를 위한 CertiLife 서비스 진입점입니다. 이 문서는 공개 가능한 작업 시나리오를 기준으로 단계별 가이드가 확장될 예정입니다.

## 지금 할 수 있는 일

- [CertiLife 서비스 구성](../getting-started/quick-tour)을 먼저 이해합니다.
- [병원용 로그인](https://hospital.certi.life/signin)으로 이동합니다.
- 계정이나 도입 관련 도움이 필요하면 [도입 문의](https://certi.life/contact)를 이용합니다.

## 추가될 가이드

실제 화면과 공개 범위를 확인한 뒤 다음 과업을 우선 문서화합니다.

1. 대시보드 둘러보기
2. 인증서 발행하기
3. 고객 정보 확인하기
4. 메시지와 캠페인 관리하기
5. 기본 설정 확인하기

:::note[작성 원칙]
메뉴명, 버튼명, 권한 조건은 실제 제품에서 재현한 뒤 게시합니다. 고객 또는 환자의 실제 정보가 포함된 화면은 사용하지 않습니다.
:::

## 작업 시나리오 제안 형식

가이드를 요청할 때 아래 내용을 알려주면 더 정확하게 작성할 수 있습니다.

- **목표:** 사용자가 최종적으로 완료할 일
- **시작 위치:** 처음 진입하는 화면
- **사전 조건:** 필요한 권한이나 준비물
- **단계:** 클릭과 입력 순서
- **완료 상태:** 성공했을 때 보이는 결과
- **주의사항:** 공개하면 안 되는 정보 또는 예외
