# 백과사전 - 조직의 상담 지식 문서 관리하기

`백과사전`은 조직의 상담 지식을 한곳에 모아 두는 문서 보관소입니다. 여기 등록한 문서는 세 군데에서 함께 쓰입니다. v2 챗봇의 학습자료로 연결되고, 콜봇의 지식 베이스에 들어가고, 상담원이 [`상담`](./counsel) 화면 가운데의 `상담 백과사전`에서 찾아봅니다. 그래서 **문서를 한 번만 잘 관리하면 모든 응대가 같은 내용으로 맞춰집니다.**

**위치:** 백과사전 (화면 제목은 `상담 백과사전`으로 표시됩니다)

## 구조 이해하기: 폴더, 태그, 문서

백과사전은 **태그**를 중심으로 정리합니다. 태그 하나가 주제 하나(예: "주차 안내", "보톡스")이고, 그 태그에 문서가 연결됩니다. 태그가 많아지면 **폴더**로 묶습니다. 왼쪽 목록은 세 부분입니다.

| 영역 | 내용 |
| --- | --- |
| `즐겨찾기` | 자주 쓰는 폴더와 태그. ★를 눌러 추가합니다 |
| `폴더` | 폴더와 그 안의 태그 |
| `폴더 없음` | 어느 폴더에도 속하지 않은 태그 |

위쪽 `태그 키워드 검색`으로 태그를 찾고, `모두 접기` / `모두 열기`로 목록을 정리합니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 가지고 있는 안내 파일을 등록하고 싶어요 | [파일을 올려 문서 등록하기](#파일을-올려-문서-등록하기) |
| 안내 내용이 바뀌어 고치고 싶어요 | [문서 내용 고치기](#문서-내용-고치기) |

| 등록한 문서를 챗봇이 쓰게 하고 싶어요 | [`AI 학습자료 설정`에서 연결](./chatbot/settings/training-materials#v2-백과사전-문서를-연결하기) |

## 파일을 올려 문서 등록하기

**위치:** 백과사전 > 추가 > 파일 업로드

1. 왼쪽 아래 `추가`를 누르고 `파일 업로드`를 고릅니다. 태그를 선택한 상태라면 위쪽 `업로드` 버튼으로도 올릴 수 있습니다.
2. `문서 업로드` 창에 파일을 끌어다 놓거나 눌러서 선택합니다. Office, PDF, CSV 파일을 올릴 수 있고, 형식·개수·크기 한도는 창에 표시됩니다.
3. Excel 파일이라면 `Excel 시트 처리`를 고릅니다. `한 문서로 합치기`는 파일 전체를 문서 하나로, `시트마다 문서로 분리`는 시트마다 「파일명_시트명」 태그를 만듭니다.
4. `업로드`를 누릅니다.

올린 파일은 문서로 변환되는 데 시간이 걸립니다. 변환 중에는 "문서를 변환하는 중입니다"가 표시되고 끝나면 자동으로 나타납니다. 진행 상황은 오른쪽 아래 업로드 트레이에서 볼 수 있습니다.

## 문서 내용 고치기

**위치:** 백과사전 > (태그 선택) > 본문 편집

1. 왼쪽에서 태그를 누르면 오른쪽에 연결된 문서가 열립니다. 문서가 여러 개면 `문서 선택`에서 고릅니다.
2. 본문을 고치고 `저장`을 누릅니다.

올렸던 원본 파일이 필요하면 `원본 다운로드`를 누릅니다. 직접 작성한 문서처럼 업로드 원본이 없는 문서는 내려받을 수 없습니다.

:::tip[고치면 어디에 반영되나요?]
v2 챗봇에 연결된 문서는, 챗봇 쪽 연결이 "최신 내용 자동 반영"으로 되어 있으면 백과사전에서 고친 내용이 검색 준비가 끝난 뒤 자동으로 쓰입니다. 특정 버전에 고정된 연결은 [`AI 학습자료 설정`](./chatbot/settings/training-materials#v2-백과사전-문서를-연결하기)에 `수정 내용 미반영`으로 표시되니 거기서 `최신 내용 자동 반영`을 눌러 주세요.
:::

## 폴더와 태그로 정리하기

**위치:** 백과사전 > 추가

- **만들기:** `추가`에서 `폴더 추가` 또는 `태그 추가`를 고릅니다.
- **고치기:** 태그를 고른 뒤 `태그 수정`에서 `폴더`, `태그색`을 바꾸고 `적용`합니다. 폴더는 `폴더 수정`에서 `폴더명`을 바꿉니다.
- **옮기기:** 태그를 끌어서 순서를 바꾸거나 다른 폴더로 옮깁니다.
- **잠시 끄기:** 태그의 `활성`을 끄면 그 태그는 쓰이지 않습니다. 상위 폴더가 비활성이면 그 안의 태그도 함께 꺼진 것으로 취급되며, 태그 각각의 설정은 유지됩니다.

:::caution[삭제와 이름 변경]
폴더를 삭제하면 안에 있던 태그는 `폴더 없음`으로 이동합니다. 태그명 수정은 현재 일시적으로 제한되어 있어, 이름을 바꾸려 하면 "태그명 수정은 일시적으로 제한되어 있습니다"라는 안내가 나옵니다. 태그를 만들 때 이름을 신중하게 정하세요.
:::

## 어떤 문서를 넣어야 하나요?

백과사전의 문서는 챗봇과 콜봇이 고객에게 그대로 안내할 수 있는 내용입니다. 고객에게 공개해도 되는 승인된 자료만 넣고, 고객 기록이나 내부 메모, 직원 연락처는 넣지 마세요. 같은 내용이 여러 문서에 다르게 적혀 있으면 답변이 흔들리므로 주제당 기준 문서를 하나로 정리하는 것이 좋습니다. 선별과 갱신 기준은 [상담 지식 관리](../knowledge-management)에 있습니다.
