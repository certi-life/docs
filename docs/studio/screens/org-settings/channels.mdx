# 채널 연동 - 메신저 계정을 조직에 연결하기

카카오톡, 네이버 톡톡, Instagram 같은 메신저로 상담하려면 **조직에 계정을 먼저 연동**해야 합니다. 연동 방식은 채널마다 다릅니다. 로그인 한 번으로 끝나는 채널도 있고, 키를 복사해 넣고 상대 서비스에 웹훅 주소를 등록해야 하는 채널도 있습니다. 연동이 끝나면 [챗봇의 `채널 설정`](../chatbot/settings/channel-settings)에서 어느 챗봇이 그 채널에 응답할지 고릅니다.

**위치:** 설정 > 채널 설정

## 채널별로 필요한 것

| 탭 | 연동 방식 | 미리 준비할 것 |
| --- | --- | --- |
| `알림톡 채널` | 채널 확인 후 관리자 휴대폰 인증 | 카카오톡 채널 아이디, 채널 관리자 휴대폰 |
| `상담톡 채널` | 단계별 연동 창에서 발신프로필 등록과 휴대폰 인증 | 카카오 채널 프로필 ID, 채널 관리자 휴대폰 |
| `네이버 톡톡` | 채널 ID와 인증 값 입력 후 웹훅 등록 | 톡톡 파트너센터 접속 권한 |
| `Instagram` | Facebook 로그인 | Instagram 비즈니스 계정과 연결된 Facebook 페이지 권한 |
| `LINE` | 토큰과 시크릿 입력 후 웹훅 등록 | LINE Developers Console 접속 권한 |
| `WhatsApp` | Meta 로그인 또는 직접 입력 | WhatsApp 비즈니스 계정 |
| `AI 콜봇` | 직접 연동하지 않습니다 | 담당자를 통해 연동 |

`위챗 (준비중)`은 아직 쓸 수 없습니다.

## 카카오 알림톡 채널 연동하기

**위치:** 설정 > 채널 설정 > 알림톡 채널

알림톡은 예약 안내처럼 정보성 메시지를 보내는 채널입니다. [CRM](../crm/overview) 캠페인, [상황별 콜백](./callback-situations), 챗봇의 알림톡 도구가 모두 이 채널로 발송합니다.

1. `채널 목록`의 더하기(+) 또는 `알림톡 채널 연동`을 누릅니다. `카카오 알림톡 채널 연동` 창이 열립니다.
2. **`채널 확인`:** `채널 아이디`와 `채널 표시 이름`을 입력합니다. 표시 이름을 비우면 회사명이 사용됩니다.
3. **`관리자 인증`:** `채널 관리자 휴대폰 번호`를 입력하고 `인증번호 요청`을 누른 뒤, 받은 6자리 `인증번호`와 `업종 카테고리`를 입력합니다.
4. `채널 연동`을 누릅니다.

같은 창에서 `상담톡도 함께 연동합니다`를 체크하면 상담톡까지 한 번에 연동합니다. 연동을 마치면 "상담톡도 연동할까요?"라는 안내가 한 번 나오며, `나중에 하기`를 골라도 됩니다.

## 카카오 상담톡 채널 연동하기

**위치:** 설정 > 채널 설정 > 상담톡 채널 > 상담톡 연동

상담톡은 고객과 카카오톡으로 일대일 상담을 주고받는 채널입니다.

1. `채널 목록`의 더하기(+)를 누릅니다. `상담톡 연동` 창이 `채널 확인` → `발신프로필` → `휴대폰 인증` → `연동` 순서로 진행됩니다.
2. `채널 이름`, `카카오 채널 프로필 ID`, `채널 카테고리`를 입력합니다. 프로필 ID는 카카오 비즈니스의 채널 정보에서 채널 URL 뒤에 오는 값입니다.
3. `채널 관리자 휴대폰 번호`로 인증합니다. **채널 관리자 알림 설정에 등록된 휴대폰 번호만** 인증할 수 있고, 인증번호는 7분간 유효합니다.
4. `상담톡 연동`을 누릅니다.

"카카오 심사 대기 중입니다."가 보이면 발신프로필이 아직 승인되지 않은 것입니다. 연동은 되지만 승인 전까지는 메시지를 주고받을 수 없습니다.

:::caution[상담톡 해지는 되돌릴 수 없습니다]
상담톡 연동을 해지하면 즉시 해지되고, 연결된 모든 상담방이 일괄 종료됩니다. 다시 쓰려면 발신프로필 연동을 처음부터 다시 해야 합니다.
:::

### 카카오 상담톡 유료 메시지

**위치:** 설정 > 채널 설정 > 상담톡 채널 > 카카오 상담톡 유료 메시지

이 옵션이 꺼져 있으면 카카오 채널에서는 무료 자동메시지가 발송됩니다. 이때 상담 시작과 운영 시간 외 문구가 카카오의 기본 문구로 대체되고, 상담원 배정과 고객 정보 수집 메시지는 발송되지 않습니다. 켜면 상담원 응대와 같은 유료 메시지로 발송되어 [자동메시지](./auto-messages)에 적은 문구가 그대로 나갑니다.

## 네이버 톡톡 연동하기

**위치:** 설정 > 채널 설정 > 네이버 톡톡 > 새 채널 등록

1. 목록의 더하기(+)를 누르면 오른쪽에 `새 채널 등록` 입력란이 열립니다.
2. `네이버 톡톡 채널 ID`, `채널 이름`, `보내기 API Authorization`을 입력합니다. 값은 톡톡 파트너센터의 채널 > 연동 관리 > 챗봇 API 설정에서 확인합니다.
3. `채널 저장`을 누릅니다.
4. **저장한 뒤 화면에 표시되는 웹훅 URL을 톡톡 파트너센터에 등록합니다.** 이때 send, open, leave 이벤트를 반드시 활성화해야 합니다.

4번을 빠뜨리면 연동은 되어 보여도 메시지가 들어오지 않습니다.

## Instagram 연동하기

**위치:** 설정 > 채널 설정 > Instagram > 연결

`연결`을 누르면 Facebook 로그인 화면으로 이동합니다. 연동할 Instagram 비즈니스 계정이 연결된 Facebook 페이지의 권한을 허용하면 자동으로 연동이 끝납니다. 연동 뒤 상태가 `재인증 필요`나 `구독 실패`로 바뀌면 `재연동` 또는 `재구독`을 누르세요. `챗봇 미지정 — 상담 대기열로 인입`으로 표시되면 이 계정에 응답할 챗봇이 정해지지 않아 모든 메시지가 상담 대기로 들어오는 상태입니다.

## LINE 연동하기

**위치:** 설정 > 채널 설정 > LINE > 새 채널 등록

1. 더하기(+)를 눌러 `채널 액세스 토큰 (장기)`과 `채널 시크릿`을 입력하고 `채널 저장`을 누릅니다. 두 값은 LINE Developers Console의 Messaging API 탭과 Basic settings 탭에 있습니다.
2. **표시되는 웹훅 URL을 LINE Developers Console의 Messaging API > Webhook URL에 직접 등록하고, 같은 화면의 Use webhook을 켭니다.** 켜지 않으면 메시지가 아예 도착하지 않습니다.

저장할 때는 액세스 토큰만 확인됩니다. 시크릿이 맞는지는 첫 메시지가 도착해야 알 수 있으니, 연동 후 직접 메시지를 보내 시험하세요. 보안상 저장된 값은 다시 볼 수 없고, 바꾸려면 `자격증명 재등록`을 누릅니다.

## WhatsApp 연동하기

**위치:** 설정 > 채널 설정 > WhatsApp

`WhatsApp 비즈니스 계정 연결`을 누르고 Meta 로그인 창에서 사용할 전화번호를 고르면 연동이 끝납니다. 별도의 토큰 발급이나 웹훅 설정은 필요하지 않습니다. 이 버튼을 쓸 수 없다는 안내가 나오면 `직접 입력(고급)`을 펼쳐 `WABA ID`, `전화번호 ID (Phone Number ID)`, 영구 액세스 토큰을 입력합니다. 임시 토큰은 곧 만료되므로 쓰지 마세요.

연동 뒤에는 상태 카드에서 `번호 상태`, `품질 등급`, `발송 한도`를 확인할 수 있습니다. "웹훅 구독에 실패했습니다."가 보이면 메시지가 도착하지 않을 수 있으니 자격증명을 다시 등록하세요.

## AI 콜봇

**위치:** 설정 > 채널 설정 > AI 콜봇

이 탭은 연동 상태(`연동됨` / `미연동`)를 확인하는 곳입니다. AI 콜봇은 영업담당자를 통해 연동하므로 이 화면에서 직접 입력하지 않습니다. 이용이나 변경, 해지가 필요하면 조직의 CertiLife 담당자에게 문의하세요.

## 연동한 다음에는

1. [챗봇의 `채널 설정`](../chatbot/settings/channel-settings)에서 채널에 응답할 챗봇을 지정합니다.
2. 직접 메시지를 보내 도착하는지, 답이 나가는지 확인합니다.
3. 채널마다 [출시 체크리스트](../../launch-checklist)의 항목을 점검한 뒤 고객에게 공개합니다.

연동에 쓰는 토큰과 시크릿은 비밀번호와 같습니다. 메신저나 이메일 본문으로 주고받지 말고, 담당자가 직접 입력하세요.
