# 5분 만에 CertiLife 둘러보기

CertiLife는 인증서 발행으로 시작한 고객 접점을 상담과 CRM 마케팅으로 이어갈 수 있도록 구성되어 있습니다.

## 1. 고객에게 정보를 전달합니다

[인증서](../products/certificate)는 시술 또는 제품 정보를 고객이 확인하기 쉬운 형태로 전달하는 서비스입니다.

## 2. 반복 상담을 줄입니다

[AI 상담](../products/ai-chatbot)은 반복되는 채팅 문의를 돕고, 병원 구성원이 더 중요한 업무에 집중할 수 있도록 지원합니다.

## 3. 관계를 이어갑니다

[CRM 메시징](../products/crm-messaging)을 활용하면 고객에게 필요한 안내와 메시지를 전달할 수 있습니다.

## 4. 브랜드 경험을 확장합니다

[이벤트 마케팅](../products/event-marketing)은 고객과 병원의 접점을 넓히는 데 활용할 수 있습니다.
