# 작동시간 - 챗봇이 쉬는 시간 정하기

챗봇은 기본적으로 24시간 응답합니다. 하지만 "상담원이 있는 낮에는 사람이 받고, 챗봇은 밤에만" 또는 "밤에 온 카톡은 챗봇이 답하지 말고 아침에 사람이 받게"처럼 운영하고 싶을 수 있습니다. `작동시간`에서는 챗봇이 **응답하지 않을 시간**을 정합니다. 그 시간에 들어온 문의에는 챗봇이 답하지 않고 상담원 연결 안내(`미작동 시나리오`)가 나갑니다. 업무 외 시간의 채팅 문의는 이 `미작동 시나리오`로 안내하고, 담당자가 다음 업무시간에 [상담](../../counsel/overview) 화면에서 확인하는 것이 기본 흐름입니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > 작동시간

헷갈리기 쉬운 점이 하나 있습니다. 이 화면에서 정하는 것은 "작동하는 시간"이 아니라 "**작동하지 않는 시간**"입니다. 바꾼 내용은 왼쪽 아래 `저장`을 눌러야 적용됩니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 챗봇을 항상 켜 두고 싶어요 | `챗봇 24시간 작동`을 켜 둡니다 (기본값) |
| 평일 낮에는 상담원이 직접 받고 싶어요 | `챗봇 24시간 작동`을 끄고 `평일 업무시간 (09:00~18:00)`을 누릅니다 |
| 요일마다 다르게 하고 싶어요 | [요일별로 쉬는 시간 정하기](#요일별로-쉬는-시간-정하기) |
| 공휴일이나 휴진일은 따로 정하고 싶어요 | [특정 날짜만 다르게 하기](#특정-날짜만-다르게-하기) |

## 요일별로 쉬는 시간 정하기

**위치:** 챗봇 > 설정 > 작동시간 > 챗봇 미작동 시간 설정

1. `챗봇 24시간 작동`을 끕니다. 아래에 `챗봇 미작동 시간 설정`이 나타납니다.
2. `요일별 미작동 시간`에서 요일을 펼치고 `시간대 추가`로 시작 시간과 종료 시간을 넣습니다. `종일`, `오전`, `오후`, `저녁` 버튼으로 빠르게 채울 수도 있습니다.
3. 같은 시간을 다른 요일에도 쓰려면 `다른 요일에 복사`를 누르고, `미작동 시간 복사` 창에서 복사할 요일과 적용할 요일을 고릅니다.
4. 왼쪽 아래 `저장`을 누릅니다.

평일 근무시간에만 끄는 경우가 가장 흔해서, `평일 업무시간 (09:00~18:00)` 버튼 하나로 월~금 설정을 한 번에 채울 수 있습니다. 처음부터 다시 하려면 `전체 초기화`를 누릅니다.

## 쉬는 시간에 보낼 안내 정하기

**위치:** 챗봇 > 설정 > 작동시간 > 미작동 시나리오 설정

`챗봇 24시간 작동`을 끄면 `미작동 시나리오 설정` 카드가 나타납니다. `미작동 시나리오로 이동`을 누르면 [`시나리오` 탭](../scenarios)의 `미작동 시나리오` 편집 화면이 열립니다. 여기에 "지금은 상담원이 직접 응대하는 시간입니다" 또는 "상담 가능 시간은 평일 9시~18시입니다"처럼, 고객이 언제 어떻게 답을 받을 수 있는지 적어 두세요.

`챗봇 24시간 작동`이 켜져 있는 동안에는 `미작동 시나리오`가 잠겨 있어 편집할 수 없습니다.

## 특정 날짜만 다르게 하기

**위치:** 챗봇 > 설정 > 작동시간 > 특수일 작동 설정

명절 연휴나 임시 휴진일처럼 요일 설정과 다르게 움직여야 하는 날은 특수일로 등록합니다. 특수일 설정은 그 날짜에 한해 요일별 설정보다 우선합니다.

1. `특수일 작동 설정`에서 날짜를 고르고 설명(예: 크리스마스)을 적습니다.
2. 그날 챗봇을 `챗봇 작동`으로 둘지 `챗봇 미작동`으로 둘지 고릅니다.
3. 하루 전체면 `종일`을 체크하고, 일부 시간만이면 시작·종료 시간을 넣습니다.
4. `추가`를 누르고, 끝나면 왼쪽 아래 `저장`을 누릅니다.

등록한 특수일은 목록에서 눌러 `특수일 수정` 창에서 고칠 수 있습니다. 지난 날짜가 쌓이면 `지난 날짜 삭제`로 정리합니다.

### 공휴일을 한 번에 등록하기

**위치:** 챗봇 > 설정 > 작동시간 > 특수일 작동 설정 > 공휴일 자동 설정

`공휴일 자동 설정`을 누르면 연도별 공휴일 목록이 나옵니다. 설정 옵션(`챗봇 작동` 또는 `챗봇 미작동`)을 고르고 원하는 날짜를 선택한 뒤 `일괄 추가`를 누르세요. 이미 특수일로 등록된 날짜는 `등록됨 (덮어쓰기)`로 표시되며, 선택하면 기존 설정을 덮어씁니다.

## 권장 운영법

- 챗봇이 쉬는 시간과 상담원이 실제로 응대할 수 있는 시간이 맞는지 확인하세요. 둘 다 비는 시간이 있으면 고객 문의가 방치됩니다.
- 상담 가능 시간과 연결 기준은 [상담원 연결 정책](../../../../products/ai-chatbot/handoff-policy)과 [상담 시나리오와 사람 연결](../../../scenario-and-handoff)을 참고해 정하세요.
- 고객이 대화 중에 직접 사람을 부르는 버튼은 [블럭과 버튼](../blocks#버튼-동작-정하기)의 `상담사 연결` 동작으로 답니다. 특정 채널을 챗봇 없이 처음부터 사람이 받게 하려면 [채널 설정](./channel-settings#챗봇-없이-바로-상담원에게-연결하기)의 `상담원 바로 연결`을 켭니다.
- 연말에는 다음 해 공휴일을 `공휴일 자동 설정`으로 미리 등록해 둡니다.
