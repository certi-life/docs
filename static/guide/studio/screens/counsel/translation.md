# 외국어 고객과 대화하기 - 상담 화면에서 번역 쓰기

> Studio 상담 화면에서 언어 바로 고객 언어와 상담사 언어를 정하고, 고객 메시지의 번역을 읽고, 답변을 번역해 원문과 실제 발송 문구를 확인한 뒤 보내는 방법, 바로 전송, 언어 변경 제안, 번역이 안 될 때의 대처를 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/counsel/translation)

번역을 켜 둔 조직에서는 외국어로 들어온 메시지가 **자동으로 상담사 언어로 번역되어 보이고**, 상담사가 한국어로 쓴 답변은 **고객 언어로 번역해 보낼 수 있습니다.** 상담사가 할 일은 두 가지입니다. 언어가 맞게 잡혔는지 확인하는 것, 그리고 보내기 전에 번역된 문구를 한 번 읽는 것입니다.

**위치:** 상담 > 대화창 > 언어 바

입력창 바로 위에 고객 언어와 상담사 언어가 표시되는 줄이 있습니다. 화면에 이름이 붙어 있지는 않으며, 이 문서에서는 이 줄을 언어 바라고 부릅니다.

> **번역 버튼이 안 보인다면**
>
> 조직 설정에서 번역이 꺼져 있는 것입니다. 꺼져 있으면 언어 바, 입력창의 번역 버튼, 메시지의 번역 버튼이 모두 나타나지 않습니다. 관리자에게 [번역 설정](https://docs.certi.life/guide/studio/screens/org-settings/translation)에서 `번역 사용`을 켜 달라고 요청하세요.

## 언어가 맞게 잡혔는지 확인하기

입력창 바로 위의 언어 바에 `고객` 언어 → `상담사` 언어가 표시됩니다. 옆의 꼬리표로 지금 상태를 알 수 있습니다.

| 꼬리표            | 뜻                                               |
| -------------- | ----------------------------------------------- |
| `자동 감지 중`      | 아직 고객 언어가 정해지지 않았습니다. 고객 메시지 3건이 모이면 자동으로 정해집니다 |
| `자동 감지됨`       | 고객의 처음 메시지들로 언어가 정해졌습니다                         |
| `회사 설정 · (언어)` | 조직 설정에서 지정한 언어로 번역하고 있습니다                       |
| `고정`           | 이 상담방에서 상담사가 직접 언어를 골랐습니다                       |

언어가 틀렸거나 세 건을 기다리지 않고 바로 정하고 싶다면 언어 바의 `고객` 언어 목록에서 직접 고릅니다. 고객 명단이 아니라 언어 목록이며, 조직 설정 화면의 `고객이 쓰는 언어`와 같은 항목입니다. 이 상담방에만 적용됩니다. 되돌리려면 `자동 감지`를 고릅니다. `상담사` 쪽은 `회사 설정 · 한국어` 같은 꼬리표가 붙은 조직 설정 값이 기본이고, 필요하면 이 방에서만 다른 언어로 바꿀 수 있습니다.

지원 언어는 `한국어`, `영어`, `일본어`, `중국어(간체)`, `중국어(번체)`, `태국어`, `스페인어(멕시코)`, `베트남어`입니다.

### 고객이 중간에 다른 언어로 바꿨을 때

정해진 고객 언어와 고객이 실제로 쓴 언어가 다르면 고객 메시지 아래에 "설정한 고객 언어와 고객이 쓴 언어가 다른 것 같습니다. 고객 언어를 …로 변경할까요?"라는 제안이 나타납니다. 맞다면 `변경하기`를 누르세요.

## 고객 메시지 읽기

고객의 외국어 메시지는 말풍선 안에 **원문이 위에, 번역문이 아래에** 함께 표시됩니다. 번역문에는 `번역` 꼬리표가 붙고, 고객이 설정과 다른 언어로 쓴 메시지는 `번역 · 중국어(간체)`처럼 언어가 함께 표시됩니다.

- 번역이 진행 중이면 `번역 중`, 실패하면 `번역 실패`와 사유가 표시됩니다.
- 번역이 붙지 않은 메시지는 말풍선에 마우스를 올려 `번역` 버튼을 누르면 그 메시지만 번역합니다.
- "이미 상담사 언어로 작성된 메시지입니다"가 나오면 번역할 필요가 없는 메시지입니다.

## 답변을 번역해서 보내기

**위치:** 상담 > 대화창 > 입력창 > 번역

1. 입력창에 평소처럼 한국어로 답변을 씁니다.
2. 입력창 오른쪽의 번역 버튼(`고객 언어로 번역`)을 누릅니다.
3. 입력창이 두 칸으로 나뉩니다. 왼쪽 `원문`은 내가 쓴 글, 오른쪽 `실제 발송`은 고객에게 나갈 번역문입니다.
4. **`실제 발송` 문구를 읽어 봅니다.** 오른쪽 칸은 직접 고칠 수 있습니다. 시술명, 제품명, 지점명이 이상하게 번역됐다면 여기서 바로잡으세요.
5. `전송`을 누릅니다.

번역이 마음에 들지 않아 원문부터 다시 쓰고 싶다면 `번역 전으로 되돌리기`를 누릅니다. 번역 직후에는 번역 버튼이 잠기고("이미 번역한 문장입니다"), 문장을 고치거나 되돌리면 다시 번역할 수 있습니다.

> **번역문은 꼭 읽고 보내세요**
>
> 번역은 기계 번역입니다. 숫자, 날짜, 금액, 고유명사는 특히 확인이 필요합니다. 의료 판단이 필요한 내용은 번역해서 답하기보다 의료진이나 담당자에게 연결하세요. 확인 절차는 [상담 메시지 번역](https://docs.certi.life/guide/products/ai-chatbot/message-translation)에 자세히 있습니다.

### 번역하지 않고 보내려면

짧은 인사나 이미 고객 언어로 쓴 문장은 번역할 필요가 없습니다.

- **번역 버튼이 따로 있는 조직:** 번역을 누르지 않고 `전송`을 누릅니다. 조직 설정에 따라 입력창 아래에 "아직 번역을 하지 않으셨습니다. 번역을 하지 않고 바로 보내시겠습니까?"가 뜨며, `전송`을 한 번 더 누르면 그대로 나갑니다.
- **전송 버튼이 `번역`으로 바뀌어 있는 조직:** 버튼 오른쪽 화살표를 눌러 `바로 전송`을 고릅니다. 이 방식에서는 버튼을 한 번 누르면 번역, 한 번 더 누르면 발송입니다. Ctrl+Enter도 같은 순서로 동작합니다.

어느 방식인지는 관리자가 [번역 설정의 `동작`](https://docs.certi.life/guide/studio/screens/org-settings/translation#상담원의-전송-방식-정하기)에서 정합니다. 고객 언어와 상담사 언어가 같은 상담방에서는 번역 단계 없이 평소처럼 `전송`입니다.

## 보낸 메시지를 내 언어로 다시 보기

예전에 보낸 번역 메시지가 무슨 뜻이었는지 확인하려면 보낸 메시지에 마우스를 올려 `상담사 언어로 보기`를 누릅니다. 보낸 말풍선에는 `상담사 원문`과 `실제 발송`이 구분되어 표시됩니다.

## 번역이 안 될 때

| 화면의 안내                                  | 원인과 대처                                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------------------------- |
| "고객 언어가 아직 정해지지 않았습니다 (바로 위 줄에서 지정하세요)" | 자동 감지가 끝나지 않았습니다. 언어 바에서 고객 언어를 직접 고르세요                                                      |
| "번역할 내용을 입력하세요"                         | 입력창이 비어 있습니다                                                                                 |
| "번역 중입니다. 잠시만 기다려 주세요."                 | 번역이 진행 중입니다. 끝난 뒤 다시 누르세요                                                                    |
| "번역 서비스에 연결할 수 없습니다"                    | 일시적인 연결 문제입니다. 잠시 후 다시 시도하고, 계속되면 관리자에게 알리세요                                                 |
| "번역할 수 있는 문장이 아닙니다"                     | 번역할 문장으로 인식되지 않았습니다. 문장을 고쳐 다시 번역하거나 그대로 전송하세요                                               |
| 고객 메시지에 `번역 실패`와 사유가 붙어 있음              | 받은 메시지의 번역이 실패한 것입니다. 말풍선에 마우스를 올려 `번역` 버튼이 보이면 눌러 다시 시도하세요. 계속 실패하면 원문을 복사해 확인하고 관리자에게 알리세요 |
