# 기본 정보 화면

`기본 정보`는 챗봇의 프로필 이미지, 이름, 설명을 정하고 다른 계정으로 챗봇을 복사할 수 있는 내보내기 코드를 만드는 화면입니다. 챗봇 상세 화면에서 `설정` 탭을 열고 왼쪽 `설정 메뉴`의 `기본 정보`를 누릅니다. 이미지, 이름, 설명은 왼쪽 아래 `저장`을 눌러야 적용됩니다.

## 기본 정보

- **위치:** 챗봇 > 설정 > 기본 정보
- **이 화면에서 할 수 있는 일:** 챗봇 프로필 이미지, 챗봇 이름, 설명을 바꿉니다.
- **주요 항목:** `챗봇 프로필 이미지`, `챗봇 이름`, `설명`, `챗봇 내보내기`.
- **주요 버튼:** `이미지 업로드`, `병원 이미지 가져오기`, `제조사 이미지 가져오기`, `삭제`, `저장`
- **팁:** 프로필 이미지는 웹채팅에서 챗봇 메시지 옆에 표시됩니다. 권장 크기는 200x200px, 최대 5MB이며 PNG, JPG, GIF, WebP 형식을 지원합니다. 이미지를 올리거나 삭제한 뒤에도 `저장`을 눌러야 적용됩니다.
- **관련 가이드:** [설정 탭 화면](./settings), [채팅창 설정 화면](./chat-window-settings)

## 챗봇 내보내기

- **위치:** 챗봇 > 설정 > 기본 정보 > 챗봇 내보내기
- **이 화면에서 할 수 있는 일:** 이 챗봇을 다른 계정이나 같은 계정에 복사할 수 있는 내보내기 코드를 만듭니다.
- **주요 버튼:** `챗봇 내보내기`, `복사`, `코드 삭제`
- **팁:** 코드는 60분간 유효하고 1회만 사용할 수 있습니다. 채팅 기록과 통계는 복사되지 않습니다. 만든 코드는 챗봇 목록의 `새 챗봇 만들기` > `챗봇 가져오기`에 입력합니다.
- **관련 가이드:** [챗봇 목록 화면](./chatbot-list#챗봇-가져오기)
