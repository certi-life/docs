# CRM - 고객 데이터를 모아 메시지 운영하기

`CRM`은 "고객을 모으고 → 나누고 → 메시지를 보내는" 일을 하는 곳입니다. 화면의 `CRM 운영 홈`에도 이 흐름이 네 단계로 그려져 있습니다. 데이터 수집, 고객 프로필, 세그먼트, 메시지 운영입니다. 메시지를 보내는 방법은 두 가지입니다. 한 번 보내는 **캠페인**과, 조건이 맞으면 자동으로 나가는 **시나리오 자동화**입니다.

**위치:** CRM

:::info[조직의 이용 범위에 따라 보입니다]
`CRM` 메뉴는 조직의 이용 범위에 따라 보이지 않을 수 있습니다. 필요하다면 조직의 CertiLife 담당자에게 문의하세요.
:::

## 메뉴 구성

| 그룹 | 메뉴 | 하는 일 |
| --- | --- | --- |
| | `운영 홈` | 발송량, 전환, 활성 고객, 이탈 위험 등 운영 지표를 한눈에 봅니다 |
| `일정 관리` | `캘린더` | 일정과 예약을 등록하고 관리합니다 |
| `고객 데이터` | `고객 목록` | 고객을 등록하고 검색·필터하고 세그먼트로 저장합니다 |
| | `데이터 연동` | 인증서·EMR 등 외부 데이터에서 고객을 가져옵니다 |
| `메시지 운영` | `메시지 템플릿` | `알림톡`, `브랜드 메시지`, `WhatsApp` 템플릿을 만듭니다 |
| | `캠페인` | 대상을 골라 메시지를 한 번 발송하거나 예약합니다 |
| | `시나리오 자동화` | 조건에 맞는 고객에게 자동으로 메시지가 나가는 흐름을 만듭니다 |
| | `발송 현황` | 오늘 발송, 예약 대기, 발송 완료를 확인하고 예약을 취소합니다 |

## 이럴 때 사용하세요

| 하고 싶은 일 | 섹션 |
| --- | --- |
| 고객 명단을 넣고 싶어요 | [고객 등록하기](#고객-등록하기) |
| "최근 방문한 30대"처럼 고객을 나누고 싶어요 | [조건으로 고객 나누기](#조건으로-고객-나누기) |
| 이벤트 안내를 한 번 보내고 싶어요 | [캠페인으로 메시지 보내기](#캠페인으로-메시지-보내기) |
| 시술 후 3일 뒤 안내처럼 자동으로 보내고 싶어요 | [조건에 따라 자동으로 보내기](#조건에-따라-자동으로-보내기) |

## 고객 등록하기

**위치:** CRM > 고객 목록 > 고객 추가

고객을 넣는 방법은 세 가지입니다.

| 방법 | 이럴 때 | 위치 |
| --- | --- | --- |
| `직접 등록` | 한두 명을 바로 넣을 때 | `고객 추가` > `직접 등록` |
| `CSV 업로드` | 기존 명단을 한꺼번에 넣을 때 | `고객 추가` > `CSV 업로드` |
| 데이터 연동 | 인증서·EMR 데이터에서 계속 가져올 때 | `데이터 연동` > `새 연동` |

`직접 등록`에서는 `이름`, `연락처`, `이메일`, `생년월일`, `성별`, `상담태그`, `마케팅 수신동의` 등을 입력하고 `등록`합니다. `CSV 업로드`는 `파일 업로드` → `컬럼 매핑` → `결과` 세 단계로 진행되며, 한 번에 .csv 파일 하나(최대 5MB, 5,000행 이하)를 올립니다.

:::caution[마케팅 수신동의를 정확히 기록하세요]
광고성 메시지는 수신에 동의한 고객에게만 보낼 수 있습니다. 명단을 넣을 때 `마케팅 수신동의` 값을 실제 동의 여부대로 기록하세요. 발송 기준은 [CRM 메시지 발송 전 체크리스트](../../products/crm-messaging/message-checklist)를 참고하세요.
:::

## 조건으로 고객 나누기

**위치:** CRM > 고객 목록 > 필터 조건으로 세그먼트 만들기

1. `고객 목록`에서 필터로 원하는 조건의 고객만 남깁니다.
2. `필터 조건으로 세그먼트 만들기`(또는 `새 세그먼트`)를 누릅니다.
3. `현재 필터를 세그먼트로 저장` 창에 `세그먼트 이름`을 적고 `저장`합니다.

저장한 세그먼트는 캠페인과 자동화의 발송 대상으로 씁니다. 어떤 기준으로 나눌지는 [CRM 세그먼트 계획](../../products/crm-messaging/segment-planning)을 참고하세요. 목록에서 고객을 여러 명 선택하면 아래쪽에 `메시지 보내기`, `시나리오 할당`, `태그 관리`, `내보내기(CSV)` 같은 일괄 작업이 나타납니다.

## 캠페인으로 메시지 보내기

**위치:** CRM > 캠페인 > 새 캠페인

먼저 `메시지 템플릿`에서 보낼 템플릿을 만들어 두어야 합니다. 알림톡은 카카오 검수를, WhatsApp은 Meta 심사를 거치며, **승인된 템플릿만 캠페인과 자동화에 연결**됩니다.

1. `캠페인`에서 `새 캠페인`을 누릅니다.
2. `대상 선택` → `메시지` → `예약` → `확인 · 발송` 네 단계를 순서대로 진행합니다. 대상은 세그먼트를 고르거나 즉석 필터로 만듭니다.
3. 마지막 단계의 `테스트 발송 (선택)`에 내 번호를 넣어 먼저 받아 봅니다. 테스트 발송은 실제 대상 수에 포함되지 않습니다.
4. `발송 시작`(예약이면 `예약 확정`)을 누릅니다. 중간에 멈추려면 `초안 저장`으로 남겨 두었다가 이어서 편집합니다.

발송 뒤에는 `발송 현황`에서 결과를 보고, 실패 건은 캠페인 화면에서 다시 발송할 수 있습니다. 기간별 성과는 `캠페인 성과`에서 확인합니다.

## 조건에 따라 자동으로 보내기

**위치:** CRM > 시나리오 자동화 > 새 시나리오

`시나리오 자동화`는 블록을 이어 흐름을 만듭니다. 왼쪽 팔레트에서 `트리거`(세그먼트·고객 속성 조건), `대기`(시간 경과·예약 대기), `분기`, `A/B 분할`, `알림톡`, `브랜드 메시지`, `종료` 블록을 끌어다 놓고 연결한 뒤 `저장`하고 `활성화`합니다. `고객 편입`으로 대상 고객을 넣고, `진행 현황`에서 고객별 진행 상태를 봅니다.

:::caution[운영 중인 시나리오는 잠깁니다]
운영 중인 시나리오는 고객 편입과 예약 발송 기준을 보호하기 위해 편집이 잠깁니다. 고치려면 `일시 정지 후 수정`을 누르세요. 브랜드 메시지는 마케팅 수신 동의를 받은 고객에게만, 정해진 시간대에만 발송해야 하므로 활성화 전에 대상과 시간대, 템플릿 변수를 확인하라는 안내가 나옵니다. 시나리오를 삭제하면 진행 중이던 고객 편입도 함께 취소되며 되돌릴 수 없습니다.
:::

여기의 "시나리오"는 챗봇의 [`시나리오` 탭](./chatbot/scenarios)과 이름만 같고 다른 기능입니다.
