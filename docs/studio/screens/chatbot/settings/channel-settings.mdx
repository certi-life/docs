# 채널 설정 - 챗봇을 고객이 있는 곳에 연결하기

챗봇을 다 만들었다면 고객이 말을 걸 수 있는 곳에 연결해야 합니다. 연결 방법은 채널마다 다릅니다. **웹사이트는 스크립트를 복사해 붙이고, 메신저 채널은 조직에 먼저 연동한 계정을 이 화면에서 고릅니다.** 하나의 챗봇을 여러 채널에 동시에 연결할 수 있습니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > 채널 설정

## 어떤 채널에 연결할 수 있나요?

| 채널 | 연결 방법 | 먼저 필요한 것 |
| --- | --- | --- |
| `웹채팅` | `SDK 스크립트`를 웹사이트에 붙입니다 | 없음. 바로 가능합니다 |
| `카카오톡` | `오픈빌더 (스킬)` 또는 `상담톡 봇` 방식 중 선택 | 카카오 오픈빌더 봇 또는 조직에 연결된 상담톡 채널 |
| `네이버 톡톡` | 조직에 등록된 채널을 골라 `연결하기` | 조직의 채널 설정에 네이버 톡톡 등록 |
| `Instagram`, `LINE`, `WhatsApp` | `연동 채널`에서 계정을 고릅니다 | 조직의 채널 설정에 해당 계정 연동 |

`WeChat`은 화면에 `준비중`으로 표시됩니다. 메신저 계정을 조직에 새로 연동하는 작업은 이 화면이 아니라 [설정(조직 설정)의 `채널 설정`](../../org-settings)에서 합니다. 이 화면의 목록에는 이미 연동된 계정만 나타납니다.

채널을 바꾼 뒤에는 왼쪽 아래 `저장`을 누릅니다.

## 홈페이지에 채팅 버튼 달기

**위치:** 챗봇 > 설정 > 채널 설정 > 웹채팅

1. `웹채팅` 카드에서 `SDK 스크립트` 옆의 `복사`를 누릅니다.
2. 챗봇을 붙일 웹사이트의 `</head>` 또는 `</body>` 태그 안에 붙여 넣습니다. 홈페이지를 직접 고칠 수 없다면 이 스크립트를 웹사이트 담당자에게 전달하세요.
3. 사이트를 열어 오른쪽 아래에 채팅 버튼이 나타나는지 확인합니다.

붙이기 전에 먼저 시험해 보고 싶다면 `웹채팅 URL`을 `복사`해 브라우저에서 열어 보세요. 웹사이트 없이도 챗봇과 바로 대화할 수 있어, 출시 전 테스트에 유용합니다. 채팅 버튼과 창의 색, 문구는 [`채팅창 설정`](./chat-window-settings)에서 바꿉니다.

`상담 진행 여부`를 끄면 웹채팅에서 상담을 진행하지 않습니다. 점검 등으로 웹채팅만 잠시 멈출 때 씁니다.

## 카카오톡 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 카카오톡

먼저 `카카오 연동 방식`을 고릅니다.

| 방식 | 설명 |
| --- | --- |
| `오픈빌더 (스킬)` | 카카오 오픈빌더의 Bot ID를 등록해 스킬 서버로 연동합니다 |
| `상담톡 봇` | 선택한 상담톡 채널로 들어오는 메시지를 이 챗봇이 처리합니다 |

**오픈빌더로 연결할 때**

1. `폴백 블록 스킬 주소`를 `복사`해 카카오 오픈빌더의 스킬 서버 URL로 등록합니다.
2. `웰컴 블록 스킬 주소`를 `복사`해 오픈빌더의 웰컴 블록에 설정합니다. 고객이 처음 들어왔을 때 시작 시나리오가 나가게 하는 주소입니다.
3. `카카오 오픈빌더 Bot ID`에 Bot ID를 입력하고 `저장`을 누릅니다.

**상담톡 봇으로 연결할 때**는 목록에서 상담톡 채널을 고릅니다. 목록이 비어 있으면 `채널 등록하러 가기`를 눌러 조직의 채널 설정에서 상담톡 채널을 먼저 연결하세요. 진행 중인 챗봇 상담이 있는 상태에서 방식을 바꾸면 저장할 때 그 상담이 종료된다는 경고가 표시됩니다.

### 채널을 추가한 고객만 이용하게 하기

`채널 옵션`의 `채널 추가시에만 챗봇 사용 가능`을 켜면 카카오톡 채널을 추가(친구추가)한 사용자만 챗봇을 이용할 수 있습니다. 이 옵션을 켜면 두 가지를 더 설정할 수 있습니다.

- `친구추가 시나리오로 이동`: 고객이 채널을 추가했을 때 보낼 메시지를 [`시나리오` 탭](../scenarios)에서 편집합니다.
- `상담원 연결 유도 이벤트`: 발송 채널과 `오픈빌더 이벤트 이름`을 등록하고, `메시지 편집하기`로 유도 메시지 내용을 편집합니다. 발송 채널에 REST API 키가 등록되어 있어야 하며, 등록 방법은 화면의 `사전 설정 가이드`를 참고하세요.

`AI 응답 안내 문구`에는 AI가 답변을 만드는 동안 고객에게 보일 메시지(예: "잠시만 기다려주세요. AI가 답변을 준비중입니다.")를 적습니다.

## 네이버 톡톡, Instagram, LINE, WhatsApp 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 네이버 톡톡 (`Instagram`, `LINE`, `WhatsApp` 카드도 같은 방식입니다)

- **네이버 톡톡:** 연결할 채널을 고르고 `연결하기`를 누릅니다. 연결된 뒤에는 `연결됨`으로 표시되고 `연결 해제`로 끊을 수 있습니다.
- **Instagram, LINE, WhatsApp:** 각 카드의 `연동 채널`에서 이 챗봇이 응답할 Instagram 비즈니스 계정, LINE 채널, WhatsApp 번호를 고릅니다. 연결되면 `배정된 채널`이 표시됩니다.

목록에 원하는 계정이 없다면 아직 조직에 연동되지 않은 것입니다. 새 Instagram 계정 연동(Facebook 로그인), LINE 채널 액세스 토큰 등록, WhatsApp 번호 연동은 설정(조직 설정)의 `채널 설정`에서 진행합니다. 이미 다른 챗봇에 연결된 채널은 그 챗봇 이름과 함께 표시됩니다.

## 챗봇 없이 바로 상담원에게 연결하기

**위치:** 챗봇 > 설정 > 채널 설정 > 상담원 바로 연결

특정 채널은 챗봇을 거치지 않고 처음부터 사람이 받게 하고 싶다면 `상담원 바로 연결`에서 그 채널을 켭니다.

| 채널 | 켜면 이렇게 동작합니다 |
| --- | --- |
| `웹채팅` | 첫 진입 시 홈 시나리오 대신 상담 대기로 시작합니다 |
| `카카오톡` | 카카오 스킬 요청이 오면 상담원 연결 안내를 응답합니다 |
| `네이버 톡톡` | 고객이 톡톡을 시작하거나 메시지를 보내면 챗봇 없이 상담 대기로 시작합니다 |

상담원이 응대할 수 없는 시간에도 상담 대기로 들어오므로, 켜기 전에 상담 가능 시간과 [상담원 연결 정책](../../../../products/ai-chatbot/handoff-policy)을 먼저 정해 두세요.

## 연결한 뒤에는

채널을 연결했다고 끝이 아닙니다. 고객에게 공개하기 전에 채널마다 가상 질문으로 정상 답변, 답변 거절, 상담원 연결, 업무시간 외 안내를 확인하세요. 점검 항목은 [출시 체크리스트](../../../launch-checklist)에 있습니다. 연결 상태는 [챗봇 목록](../list#챗봇-카드-읽는-법)의 카드에서도 한눈에 볼 수 있습니다.
