# 플로우 탭 - 버튼으로 이어지는 안내 만들기

플로우는 여러 시나리오를 버튼으로 이어 붙인 **단계형 안내**입니다. "예약 문의 → 지점 선택 → 예약 방법 안내"처럼 고객이 버튼을 누르며 따라오는 흐름이 필요할 때 만듭니다. 왼쪽 `플로우` 목록에서 플로우를 고르면 가운데에 흐름도가 열리고, 여기서 시나리오를 추가하고 선으로 연결합니다. 바꾼 내용은 왼쪽 아래 `저장`을 눌러야 적용됩니다.

**위치:** 챗봇 > (챗봇 선택) > 플로우

## 이럴 때 플로우를 만드세요

| 상황 | 플로우가 하는 일 |
| --- | --- |
| 고객이 고를 선택지가 정해져 있습니다 (지점, 진료 과목, 문의 유형) | 버튼으로 선택지를 보여 주고 고른 쪽으로 안내를 이어 갑니다 |
| 안내 순서가 중요합니다 (예약 절차, 준비물 안내) | 시나리오를 순서대로 연결해 빠짐없이 안내합니다 |
| AI가 답하더라도 정확한 고정 안내로 이어 주고 싶습니다 | `AI 참조`를 켜 두면 AI가 관련 질문에서 이 플로우를 참조합니다 |

한두 문장으로 끝나는 질문은 플로우보다 [AI 학습자료](./settings/training-materials)에 넣는 편이 관리하기 쉽습니다.

## 새 플로우 만들기

**위치:** 챗봇 > 플로우 > 새 플로우 만들기

1. 왼쪽 `플로우` 제목 옆의 더하기(+) 버튼을 누릅니다.
2. `새 플로우 만들기` 창에서 `플로우 이름`(필수), `설명`, `태그`를 입력하고 확인합니다.
3. 목록에 생긴 플로우를 누르면 가운데에 빈 흐름도가 열립니다.

## 시나리오를 추가하고 연결하기

**위치:** 챗봇 > 플로우 > (플로우 선택) > 시나리오 추가

1. 흐름도 위쪽의 `시나리오 추가`를 누르고 `새 시나리오 추가` 창에서 `시나리오 이름`을 입력합니다.
2. 흐름도에 생긴 시나리오를 누르면 편집 패널이 열립니다. 메시지 블럭과 버튼은 [시나리오 탭](./scenarios#첫-인사-메시지-바꾸기)과 같은 방식으로 만듭니다.
3. 시나리오의 버튼에서 다음 시나리오로 선을 끌어 연결합니다. 고객이 그 버튼을 누르면 연결된 시나리오로 넘어갑니다.
4. **시작점에서 첫 시나리오로 선을 끌어 연결합니다.** 이렇게 연결된 시나리오가 이 플로우의 `시작 시나리오`가 됩니다. 플로우의 `시작 시나리오`는 고객이 이 플로우에 들어왔을 때 처음 보는 시나리오입니다. [시나리오 탭](./scenarios)의 `시작 시나리오` 태그(챗봇 첫 인사)와는 다른 것입니다. 시작점을 연결하지 않고 저장했을 때 플로우가 어떻게 동작하는지는 확인되지 않았으므로, 저장 전에 시작점 연결을 확인하세요.
5. 연결을 지우려면 연결선을 누르고 `연결 삭제`를 고릅니다.
6. 왼쪽 아래 `저장`을 누릅니다.

흐름이 복잡해지면 `메모 추가 (M)`로 설명을 남기고 `프레임 추가 (F)`로 관련 시나리오를 묶어 두세요. 프레임 안의 시나리오는 프레임을 옮길 때 함께 움직입니다. 시나리오가 많아 찾기 어려우면 `시나리오 찾기`로 검색하고, 화면에서 벗어났다면 `화면 맞춤`을 누릅니다. 편집 패널 위쪽의 눈 모양 아이콘을 누르면 `미리보기` 창에서 고객에게 보일 모습을 확인할 수 있습니다.

:::tip[마우스와 단축키]
시나리오를 우클릭하면 `복사`, `클립보드로 복사`, `삭제` 메뉴가, 빈 곳을 우클릭하면 `새 시나리오 추가`, `메모 추가`, `프레임 추가`, `붙여넣기` 메뉴가 나옵니다. 흐름도 위쪽의 `단축키`를 누르면 `단축키 안내`가 열립니다. 자주 쓰는 것은 `Shift+클릭`(여러 개 선택), `Ctrl+D`(선택한 시나리오 복사), `Ctrl+C`와 `Ctrl+V`(다른 플로우로 복사해 붙여넣기), `Delete`(삭제)입니다. 마우스 휠 버튼이나 우클릭 드래그로 화면을 옮깁니다.
:::

## 플로우를 켜고 끄기, 이름 바꾸기

**위치:** 챗봇 > 플로우 > 플로우 설정

목록에서 플로우 옆의 톱니 아이콘(`플로우 설정`)을 누르면 `플로우 설정 - (플로우 이름)` 창이 열립니다.

- `기본 정보`: `플로우 이름`, `설명`을 바꾸고 `활성화 상태`로 플로우를 켜거나 끕니다. 목록에는 `활성` 또는 `비활성`으로 표시됩니다.
- `태그 관리`: 플로우를 구분하는 태그를 추가합니다. 한 개에 10자까지, Enter로 추가합니다.

만들고 있는 플로우는 `비활성`으로 두었다가 시험이 끝난 뒤 켜는 것이 안전합니다.

## AI가 플로우를 참조하게 하기

**위치:** 챗봇 > 플로우 > 플로우 설정 > AI 참조 활성화

고객이 버튼을 누르지 않고 자유롭게 질문했을 때도 AI가 관련 플로우로 이어 주게 하려면 `AI 참조`를 켭니다.

1. `플로우 설정` 창의 `기본 정보`에서 `AI 참조 활성화`를 켭니다. 목록의 플로우에 `AI 참조` 표시가 붙습니다.
2. `AI 참조 토픽 관리`에 이 플로우가 다루는 주제를 키워드로 추가합니다(예: 진료시간, 주차안내). 최대 10개까지 넣을 수 있습니다. 이 토픽은 같은 창의 `태그 관리`에 넣는 구분용 태그와 다른 항목입니다.

같은 태그를 가진 플로우가 여러 개면 고객에게 어느 것을 볼지 묻는 안내가 나갑니다. 이 문구는 [`AI 설정`의 `플로우 선택 안내 메시지`](./settings/ai-settings#ai-응답-제목과-안내-문구-바꾸기)에서 바꿉니다.

## 플로우 복사와 삭제

**위치:** 챗봇 > 플로우

목록에서 플로우 옆의 `플로우 복사`로 같은 구성을 하나 더 만들 수 있습니다. 비슷한 안내를 지점별로 만들 때 유용합니다.

:::caution[삭제는 되돌릴 수 없습니다]
`플로우와 하위 시나리오 모두 삭제`를 누르면 그 플로우 안의 시나리오 설정, 블럭, 응답이 모두 영구 삭제됩니다. 삭제는 `저장`을 누르지 않아도 즉시 적용되며 복구할 수 없습니다.
:::
