# 개인정보 및 보안

병원 서비스에서는 고객과 환자의 정보가 다뤄질 수 있습니다. 업무에 필요한 최소 범위만 사용하고, 공개 문서·교육 자료·테스트 데이터·지원 요청에 실제 개인정보를 복사하지 마세요. 이 문서는 안전한 이용을 돕는 일반 안내이며, 법적 기준과 세부 처리 사항은 아래의 최신 공식 정책을 기준으로 확인해야 합니다.

## 최소한으로 다루기

- 목적을 달성하는 데 필요하지 않은 개인정보는 입력하거나 내려받지 않습니다.
- 실제 고객·환자·직원의 이름, 연락처, 이메일, 생년월일, 주소와 진료·시술 관련 정보가 공개 자료에 포함되지 않게 합니다.
- 테스트와 예시에는 특정인을 떠올릴 수 없는 완전한 가상 데이터를 사용합니다.
- 로그인 정보, 비밀번호, 인증 코드, 토큰 또는 키를 문서·메신저·문의 내용에 적지 않습니다.
- 개인정보가 포함된 자료를 개인 저장 공간이나 승인되지 않은 서비스로 옮기지 않습니다.
- 의심스러운 접근이나 정보 노출을 발견하면 추가 공유를 멈추고 즉시 조직의 담당자에게 알립니다.

## 안전한 계정과 접속

본인에게 발급된 계정만 사용하고 로그인 정보를 공유하지 마세요. Hospital은 [공식 Hospital 로그인](https://hospital.certi.life/signin), Studio는 [공식 Studio 로그인](https://studio.certi.life)을 이용합니다. 주소 표시줄의 도메인을 확인한 후 정보를 입력하고, 공식 주소와 다른 페이지가 로그인이나 설치를 요구하면 진행하지 마세요. 다운로드가 필요하다면 [공식 다운로드 페이지](https://certi.life/download)를 이용합니다.

공용 기기나 화면 공유 중에는 로그인 상태와 개인정보 노출에 특히 주의하세요. 사용하지 않는 화면은 닫고, 주변 사람이나 회의 참석자에게 고객·환자 정보가 보이지 않는지 확인합니다. 계정 관련 이상이 의심되면 비밀번호나 인증 코드를 문의 메시지에 보내지 말고 조직의 담당 경로를 통해 알리세요.

## 공유·문의 전 개인정보 제거 체크리스트

문서, 화면 캡처, 녹화, 파일을 다른 사람에게 보내기 전에 아래 항목을 모두 확인하세요.

- [ ] 고객·환자의 이름, 연락처, 이메일, 생년월일, 주소를 삭제하거나 복원할 수 없게 가렸습니다.
- [ ] 진료·시술 정보, 이미지, 인증서 내용처럼 개인을 식별할 수 있는 정보를 제거했습니다.
- [ ] 직원 이름, 개인 연락처, 개인 이메일 등 불필요한 직원 정보를 제거했습니다.
- [ ] 비밀번호, 인증 코드, 로그인 링크의 개인 식별 값, 토큰과 키가 보이지 않습니다.
- [ ] 브라우저 탭, 주소 표시줄, 알림, 북마크, 배경 화면에 식별 정보가 남아 있지 않습니다.
- [ ] 파일명과 문서 속성에 이름·연락처 등 개인정보가 들어 있지 않습니다.
- [ ] 이미지에서 일부만 흐리게 처리한 정보가 확대하거나 복사했을 때 읽히지 않습니다.
- [ ] 문제와 관계없는 화면 영역을 잘라냈고, 가능한 경우 개인정보 없는 오류 문구를 텍스트로 전달합니다.
- [ ] 받는 사람과 공유 목적이 맞는지 다시 확인했습니다.
- [ ] 원본 자료를 불필요하게 함께 첨부하지 않았습니다.

:::warning[가리기만 하면 충분하지 않을 수 있습니다]
반투명 도형, 얇은 선 또는 단순한 흐림 효과는 원래 내용을 알아볼 수 있게 남길 수 있습니다. 필요한 영역만 잘라내거나 정보를 완전히 제거한 사본을 만들고, 전송할 최종 파일을 다시 열어 확인하세요.
:::

## AI 상담 이용 시 경계

AI 상담은 일반 안내와 반복 문의 대응을 지원하지만 의료진의 진단, 의학적 판단 또는 치료 결정을 대신하지 않습니다. 답변 범위에 의학적 판단이 필요한 내용이 섞이지 않았는지 담당자가 확인하고, 고객·환자 개인정보를 공개 예시나 테스트 질문에 사용하지 마세요.

## 노출이 의심될 때

1. 해당 자료의 추가 전송, 화면 공유 또는 게시를 즉시 중단합니다.
2. 자료를 임의로 더 복제하지 말고 어떤 정보가 어디에 노출되었는지 최소 범위로 파악합니다.
3. 조직의 CertiLife 담당자와 조직이 정한 개인정보·보안 보고 경로에 즉시 알립니다.
4. 외부 지원이 필요하면 [도입 및 서비스 문의](https://certi.life/contact)를 이용하되, 문의 자체에 노출된 개인정보나 로그인 정보를 다시 첨부하지 않습니다.
