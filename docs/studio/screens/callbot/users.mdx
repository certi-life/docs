# 사용자 관리 - 상담사 번호 등록하고 계정과 그룹에 연결하기

콜봇이 통화를 사람에게 넘기려면 **넘겨받을 전화번호**가 있어야 합니다. `사용자 관리`에서는 세 가지를 합니다. 상담사 번호를 등록하고, 그 번호를 Studio 계정에 연결하고, 여러 번호를 그룹으로 묶습니다. 계정 자체는 여기에서 만들지 않으며 Studio 계정을 그대로 씁니다.

**위치:** 콜봇 > 사용자 관리

이 메뉴는 조직의 이용 범위에 따라 보이지 않을 수 있습니다. 화면에 "사용자 관리 저장 기능이 아직 준비되지 않았습니다."가 표시되면 아직 저장할 수 없는 상태입니다.

## 이럴 때 사용하세요

| 하려는 일 | 가는 곳 |
| --- | --- |
| 콜봇이 넘겨줄 상담사 전화번호 등록하기 | [상담사 번호 등록하기](#상담사-번호-등록하기) |
| 전화상담에서 "내 계정에 연결된 상담사 번호가 없습니다"가 나올 때 | [계정에 번호 연결하기](#계정에-번호-연결하기) |
| 여러 상담사에게 골고루 연결하기 | [번호 그룹 만들기](#번호-그룹-만들기) |

## 상담사 번호 등록하기

**위치:** 콜봇 > 사용자 관리 > 상담사 번호 > 상담사 번호 추가하기

1. `상담사 번호` 탭에서 `상담사 번호 추가하기`를 누릅니다.
2. `번호 이름`과 `상담사 번호`를 입력합니다. 번호는 숫자만 입력합니다.
3. 번호 유형을 고릅니다. 아래 표를 참고하세요.
4. `추가`를 누릅니다.

### 번호 유형 고르기

| 유형 | 켜는 옵션 | 전환 전에 확인하는 것 | 쓰는 경우 |
| --- | --- | --- | --- |
| 일반 전화번호 | 없음 | 운영시간과 상담사 상태 | 상담사 개인에게 연결할 때 |
| `내선` | `내선번호 사용` | 운영시간과 상담사 상태 | 병원 교환기(PBX)의 내선번호로 연결할 때. 1로 시작하는 숫자 4자리입니다 |
| `링그룹` | `링그룹 번호` | 운영시간만 | 여러 전화기가 함께 울리는 번호로 연결할 때 |
| `착신전환` | `착신전환용 번호` | 확인하지 않고 바로 전환 | 언제든 받아야 하는 번호로 연결할 때 |

`착신전환용 번호`와 `링그룹 번호`는 함께 켤 수 없습니다. 착신전환용 번호는 번호 그룹에 넣을 수 없습니다.

:::caution
`착신전환` 번호는 상담 시간이 아니어도, 상담사가 통화 중이어도 전환됩니다. 밤이나 휴일에 받을 사람이 없는 번호에는 쓰지 마세요.
:::

## 계정에 번호 연결하기

**위치:** 콜봇 > 사용자 관리 > 계정 연결

[전화상담](../phone-counsel)에서 전화를 받거나 걸려면 내 Studio 계정에 상담사 번호가 연결되어 있어야 합니다. 이 작업은 `콜봇` 메뉴와 `사용자 관리`가 보이는 계정에서 합니다. 상담사 본인 계정에 이 메뉴가 없거나 "사용자 관리 저장 기능이 아직 준비되지 않았습니다."가 표시되면, 조직 관리자에게 내 Studio 계정 이름과 상담사 번호를 알려 연결을 요청하세요. 어느 권한이 이 메뉴를 보는지는 확인되지 않았습니다.

1. `계정 연결` 탭을 엽니다.
2. 계정 행에서 `번호 연결`을 누릅니다.
3. 연결할 번호를 고르고 `연결`을 누릅니다.

번호 하나는 한 계정에만 연결할 수 있습니다. 다른 계정에 연결된 번호는 그 계정에서 먼저 `연결 해제`를 해야 합니다. 담당자가 바뀌면 이전 담당자의 연결을 해제하세요.

## 번호 그룹 만들기

**위치:** 콜봇 > 사용자 관리 > 번호 그룹 > 그룹 추가

그룹으로 묶으면 콜봇이 그룹 안의 상담사 중 한 명에게 연결합니다.

1. `번호 그룹` 탭에서 `그룹 추가`를 누릅니다.
2. `그룹 이름`을 입력하고 `배정 전략`을 고릅니다.
3. 만든 그룹을 고르고, `추가 가능한 상담사 번호`에서 `그룹에 추가`를 누릅니다. 빼려면 `그룹에서 제외`를 누릅니다.

| `배정 전략` | 연결 순서 |
| --- | --- |
| `순차 배정` | 그룹에서 정한 번호 순서대로 연결을 시도합니다. 기본값입니다 |
| `최소 상담시간` | 당일 통화시간 합이 가장 적은 상담사부터 연결합니다 |
| `최대 대기시간` | 마지막 통화가 끝난 뒤 가장 오래 기다린 상담사부터 연결합니다 |
| `랜덤 배정` | 무작위 순서로 연결을 시도합니다 |

번호 순서는 `순차 배정`에서만 의미가 있습니다. `기본 그룹(전체)`에는 상담사가 지정된 번호가 자동으로 모두 들어가며, 착신전환용 번호는 제외됩니다.

## 등록한 번호를 쓰는 곳

- 에이전트의 [통화 전환 도구](./tools#상담사에게-전화를-넘기게-하기)에서 넘길 대상으로 고릅니다.
- [DTMF 메뉴](./dtmf-menus#키마다-할-일-정하기)의 `상담원 전환`에서 `전환 대상`으로 고릅니다.
- [전화상담](../phone-counsel)에서 상담사가 전화를 받고 겁니다.
