# 전화상담 - 콜봇과 상담사의 통화 응대하기

`전화상담`은 전화 응대를 위한 작업 화면입니다. [콜봇](./callbot/overview)이 받고 있는 전화, 상담사 연결을 기다리는 전화, 내가 통화 중인 전화가 실시간으로 보입니다. 상담사의 일은 세 가지입니다. **기다리는 콜을 받고, 통화 내용을 확인하고, 끝나면 기록을 남깁니다.** 메뉴 이름은 화면에 `전화상담`으로 붙여 표시됩니다.

**위치:** 전화상담 > 상담하기

:::info[조직의 이용 범위에 따라 다르게 보입니다]
`전화상담` 메뉴는 콜봇을 이용하는 조직에 표시됩니다. 이용 범위에 따라 이 메뉴가 `상담하기` 화면 대신 [상담 내역](./conversation-history#전화-통화-기록-보기)의 전화 상담 내역으로 연결될 수 있습니다. 또 일부 기능은 화면에 "아직 준비되지 않았습니다"로 표시될 수 있으며, 그 경우 해당 기능은 아직 쓸 수 없습니다.
:::

## 화면 구성

화면은 세 열입니다. 왼쪽에서 통화를 고르고, 가운데에서 내용을 보고 기록하고, 오른쪽에서 고객을 확인합니다.

| 영역 | 탭 | 내용 |
| --- | --- | --- |
| 왼쪽 목록 | `콜봇` | 지금 콜봇이 응대 중인 콜 (실시간) |
| | `대기` | 지금 상담원 연결을 기다리는 콜 (실시간) |
| | `응대` | 지금 내가 통화 중인 콜 (실시간) |
| | `콜백` | 내게 배정된 미완료 콜백 예약 |
| | `전체콜` | 오늘 조직으로 들어온 콜 전부 (콜봇 응대 종료 포함) |
| 가운데 | `상담 정보`, `콜백 예약` | 대화록, 녹음, `AI 분석`, 콜백 예약, 아래쪽 `상담 기록` |
| 오른쪽 | `고객 정보`, `고객 메모`, `콜백` | 고객 분류와 메모, 이 고객의 콜백, `상담이력` |

목록의 각 콜에는 고객 번호와 단계가 표시됩니다. 단계는 `연결 대기`, `통화 중`, `연결 전 종료`, `응대 완료`이고, 기다리는 콜에는 대기 시간이 함께 보입니다. 화면 위쪽에 `실시간`이 표시되면 목록이 실시간으로 갱신되는 상태입니다. `전체콜`은 오늘 통화만 보여 주며 고객 이름이나 전화번호로 검색할 수 있습니다. 지난 통화는 상담 내역에서 찾습니다.

## 이럴 때 사용하세요

| 하고 싶은 일 | 섹션 |
| --- | --- |
| 연결을 기다리는 고객의 전화를 받고 싶어요 | [기다리는 콜 받기](#기다리는-콜-받기) |
| 콜봇이 응대 중인 통화를 내가 넘겨받고 싶어요 | [통화 넘기고 끝내기](#통화-넘기고-끝내기) |
| 통화 내용을 확인하고 기록을 남기고 싶어요 | [통화 내용 확인하고 기록 남기기](#통화-내용-확인하고-기록-남기기) |
| 나중에 다시 전화하기로 했어요 | [콜백 예약하기](#콜백-예약하기) |
| 고객에게 전화를 걸고 싶어요 | [고객에게 전화 걸기](#고객에게-전화-걸기) |
| 자리를 비워 전화를 받을 수 없어요 | [내 상태 바꾸기](#내-상태-바꾸기) |

## 기다리는 콜 받기

**위치:** 전화상담 > 상담하기 > 대기

1. `대기` 탭에서 연결을 기다리는 콜을 확인합니다. 오래 기다린 콜부터 받으세요.
2. 콜의 `당겨받기`를 누릅니다. 내 상담사 번호가 여러 개면 `당겨받을 번호 선택`에서 고릅니다.
3. "당겨받기 요청됨 — 내 전화로 연결 중입니다. 벨이 울리면 받아주세요."가 표시되고, 내 전화기의 벨이 울리면 받습니다.

"내 계정에 연결된 상담사 번호가 없습니다"가 나오면 콜봇의 `사용자 관리`에서 상담사 번호에 내 계정을 연결해야 합니다. "이미 연결된 통화입니다"는 다른 상담사가 먼저 받은 경우입니다.

## 통화 넘기고 끝내기

**위치:** 전화상담 > 상담하기 > (통화 선택)

이름이 비슷한 두 버튼이 있으니 구분하세요. 통화 단계에 따라 둘 중 하나만 보입니다.

| 버튼 | 언제 | 동작 |
| --- | --- | --- |
| `상담사 전환` | 콜봇이 응대 중인 통화 | 콜봇에서 사람 상담사로 통화를 넘깁니다. `전환 대상 선택`에서 대상을 고릅니다 |
| `전달하기` | 내가 통화 중인 통화 | 다른 상담사에게 통화를 넘깁니다. `전달 대상 선택`에서 대상을 고르면 연결을 기다립니다 |

전달이 성공하면 내 통화는 자동으로 종료됩니다. 상대가 받지 않거나 통화 중이면 "전달 실패 — 고객과의 통화는 그대로 유지 중입니다."가 표시되고 고객과의 통화는 끊기지 않습니다. 콜 목록의 `전환 요청됨` 표시는 전환을 요청했다는 뜻이며 아직 연결된 것은 아닙니다.

통화를 끝내려면 `통화 종료`를 누르고 확인 창에서 다시 `통화 종료`를 누릅니다. 종료하면 되돌릴 수 없고, 이어서 상담 기록(후처리) 작성으로 넘어갑니다. 이 화면에는 보류나 음소거 버튼이 없으므로 그런 조작은 전화기에서 합니다.

## 통화 내용 확인하고 기록 남기기

**위치:** 전화상담 > 상담하기 > (통화 선택) > 상담 정보

1. 왼쪽 목록에서 통화를 누릅니다.
2. `대화록`을 확인합니다. 진행 중인 통화는 `실시간`으로 발화가 표시됩니다. 화자를 `전체`, `콜봇·상담사`, `고객`으로 거르거나 검색할 수 있고, 글자 크기를 바꿀 수 있습니다. 발화를 누르면 그 시점부터 녹음이 재생됩니다.
3. 통화가 끝나면 `AI 분석`에 요약, 키워드, 고객 감정, 종료 사유가 자동으로 채워집니다. `요약을 메모로 복사`를 누르면 요약을 상담 메모로 가져옵니다.
4. 아래쪽 `상담 기록`에서 분류 항목을 고르고 `메모`를 적은 뒤 `저장`합니다. 메모는 조직이 정한 양식으로 미리 채워져 있습니다.
5. 후속 처리까지 끝났다면 `후처리 완료`를 누릅니다. 기록이 저장되고 내 상태가 통화대기로 돌아가 다음 전화를 받을 수 있게 됩니다.

녹음은 `콜봇 구간`과 `상담사 구간`으로 나뉘며, 재생 속도를 바꾸거나 파일로 내려받을 수 있습니다. 상담 기록의 항목은 관리자가 [상담 기록 설정](./org-settings/counsel-record)에서 정합니다. `AI 통화 결과`에 `자동 적용됨`이 표시되면 조직 설정에 따라 AI가 기록을 자동으로 채운 것이니 내용이 맞는지 확인하세요. `참고용`이면 자동으로 채워지지 않으므로 직접 고릅니다.

:::tip[대화록은 참고용입니다]
대화록은 음성 인식 결과라 일부 부정확할 수 있습니다. 이름, 숫자, 날짜처럼 중요한 내용은 녹음을 들어 확인하세요. 민감정보 저장 거부가 설정된 통화는 대화록과 녹음이 보관되지 않습니다.
:::

## 콜백 예약하기

**위치:** 전화상담 > 상담하기 > (통화 선택) > 콜백 예약

1. 가운데 `콜백 예약` 탭을 엽니다.
2. `예약 일시`와 `담당자 번호`를 고르고 `콜백 예약 노트`에 무엇 때문에 다시 전화하는지 적습니다. 고객 전화번호는 자동으로 채워집니다.
3. `콜백 예약`을 누릅니다.

예약한 콜백은 담당 상담사의 `콜백` 탭에 나타납니다. 시간이 되면 콜백의 `시도`를 눌러 전화걸기를 엽니다. 필요 없어진 예약은 `취소`로 삭제하며 되돌릴 수 없습니다. 콜백 상태는 `예약 대기`, `완료`, `실패`, `수동 완료`로 표시됩니다. 웹 통화는 고객 번호가 없어 콜백을 예약할 수 없습니다.

## 고객에게 전화 걸기

**위치:** 전화상담 > 상담하기 > 전화걸기

1. `전화걸기`를 누릅니다.
2. `상담사 번호`와 `발신번호`를 고르고 고객 전화번호를 입력합니다.
3. 콜봇이 먼저 안내하게 하려면 `아웃콜 멘트 사용`을 켜고 `에이전트`를 고릅니다.
4. `통화 걸기`를 누릅니다.

발신에는 통화 요금이 발생합니다. 상담사 번호가 없으면 콜봇의 `사용자 관리`에서, 발신할 번호가 없으면 [번호 관리](./callbot/phone-numbers)에서 먼저 준비해야 합니다.

## 통화 뒤 알림톡 보내기

**위치:** 전화상담 > 상담하기 > (통화 선택) > 알림톡

통화에서 안내한 내용을 글로 남겨 주려면 위쪽의 `알림톡`을 누릅니다. `알림톡 보내기` 창에서 `발송 채널`과 `알림톡 템플릿`을 고르고 `보내기`를 누르면 이 통화의 고객 번호로 발송됩니다. 승인된 템플릿이 없으면 CRM에서 [템플릿](./crm/templates)을 먼저 준비해야 합니다. 자주 보내는 안내는 관리자가 [상황별 콜백](./org-settings/callback-situations)으로 묶어 둘 수 있습니다.

## 내 상태 바꾸기

**위치:** 전화상담 > 상담하기 > 상담사 상태

화면 위쪽의 내 상태에서 지금 상태를 고릅니다. 콜봇은 **`통화대기` 상태인 상담사에게만** 전화를 넘깁니다.

| 그룹 | 상태 |
| --- | --- |
| `상담` | `통화대기`, `수신 안함`, `후처리` |
| `업무` | `작업`, `교육`, `회의` |
| `휴게` | `식사`, `휴식`, `자리비움` |

자리를 비울 때 상태를 바꿔 두지 않으면 받을 수 없는 전화가 넘어옵니다. 통화가 끝나면 자동으로 `후처리`가 되고, `후처리 완료`를 누르면 `통화대기`로 돌아갑니다. `상담사 상태`를 누르면 다른 상담사들의 상태도 볼 수 있습니다. `착신전환`으로 표시된 번호는 상태와 관계없이 바로 전환됩니다.

## 고객 정보와 메모 남기기

**위치:** 전화상담 > 상담하기 > 고객 정보

오른쪽 `고객 정보`에는 고객 번호, 응대한 에이전트, 유입 경로, 과거 통화가 표시됩니다. 연필 아이콘을 눌러 `고객 분류`와 `차단 표식`을 기록하고, `고객 메모`에 다음 통화에서 참고할 내용을 남깁니다. 고객 메모는 통화가 아니라 고객(번호)에 붙는 메모라 다음에 같은 번호로 전화가 오면 다시 보입니다.

`차단 표식`은 표시만 할 뿐 실제로 전화 수신을 차단하지는 않습니다. 웹 통화는 고객 번호가 없어 고객 정보와 메모를 저장할 수 없습니다.
