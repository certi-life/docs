# 알림 설정 - 상담이 들어오면 누구에게 알릴지 정하기

상담이 들어왔는데 아무도 모르면 고객은 기다리다 떠납니다. 알림 설정은 **언제, 누구에게** 알릴지를 정합니다. 대상은 둘입니다. 관리자에게는 알림톡으로, 상담사에게는 Studio 안의 알림으로 알립니다. 두 화면 모두 고르는 즉시 적용되며(5초 이내) 저장 버튼이 없습니다.

**위치:** 설정 > 운영 설정 > 관리자 알림, 상담사 알림

:::info[콜봇 지표 알림은 이 화면에 없습니다]
통화량이 갑자기 늘었을 때처럼 콜봇 지표가 기준을 넘으면 알리는 규칙은 이 화면이 아니라 콜봇 영역의 `알림` 화면에서 관리합니다. 그 화면에는 `규칙`, `인시던트` 탭과 `새 알림 규칙` 버튼이 있습니다. 다만 콜봇의 왼쪽 메뉴에는 `알림`이 없어 메뉴로는 열 수 없습니다. 콜봇 지표 알림을 만들거나 끄려면 조직의 CertiLife 담당자에게 문의하세요.
:::

## 관리자에게 알림톡으로 알리기

**위치:** 설정 > 운영 설정 > 관리자 알림 > 상담 인입 알림톡 발송 정책

상담이 들어왔을 때 관리자에게 알림톡을 보낼 기준을 정합니다. 조직의 모든 채널에 공통으로 적용됩니다.

| 선택지 | 알림이 가는 때 | 이런 조직에 |
| --- | --- | --- |
| `상담원 연결 요청시 발송` | 고객이 상담원 연결을 요청했을 때 | 챗봇이 1차로 응대하고 사람은 필요할 때만 받는 조직. 알림이 적습니다 |
| `챗봇 상담 시작시 발송` | 고객이 챗봇과 상담을 시작했을 때 | 모든 문의를 빠짐없이 지켜보고 싶은 조직. 알림이 많습니다 |

지금 적용된 쪽에 `적용 중`이 표시됩니다. 문의량이 많은 조직에서 `챗봇 상담 시작시 발송`을 고르면 알림이 지나치게 많아질 수 있으니, 먼저 `상담원 연결 요청시 발송`으로 시작해 보세요.

[자동메시지](./auto-messages#상담-전에-고객-정보-받기)에서 `정보 수집 완료 알림`을 켜 두었다면, 고객이 정보를 입력한 뒤에 상담 인입 알림이 갑니다.

## 상담사에게 알리기

**위치:** 설정 > 운영 설정 > 상담사 알림 > 상담사 알림 정책

| 항목 | 선택지 | 뜻 |
| --- | --- | --- |
| `상담사 알림 정책` | `전체 상담사` | 모든 상담사에게 알립니다. 누구든 먼저 받는 방식일 때 |
| | `배정 상담사 + 참조자` | 그 상담에 배정된 상담사와 참조자에게만 알립니다. 담당이 정해져 있을 때 |
| `챗봇 진행 중 알림` | `알림 받음` | 챗봇이 응대하는 동안에도 알림을 받습니다 |
| | `알림 안 함` | 챗봇이 응대하는 동안에는 알리지 않습니다 |

상담사가 여러 명인데 `전체 상담사`로 두면 같은 알림이 모두에게 가서 "누가 받겠지" 하고 놓치기 쉽습니다. 담당 구분이 있다면 `배정 상담사 + 참조자`가 맞습니다.

## 알림을 놓치지 않으려면

- 알림만으로는 부족합니다. 상담 가능 시간에는 [상담](../counsel/inbox) 화면의 `대기` 탭을 주기적으로 확인하는 담당자를 정해 두세요.
- 상담 시간 외에 들어온 문의는 [자동메시지](./auto-messages)의 `운영 시간 외` 문구로 언제 답을 받을 수 있는지 안내합니다.
- 화가 난 고객을 챗봇이 감지해 알리게 하려면 챗봇에 [`컴플레인 대응` 도구](../chatbot/settings/tools#화난-고객을-상담사에게-바로-알리기)를 추가합니다.
- 어떤 문의를 사람에게 넘길지는 [상담원 연결 정책](../../../products/ai-chatbot/handoff-policy)에서 기준을 세우세요.
