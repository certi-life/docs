# 블럭과 버튼 - 챗봇 메시지를 카드와 버튼으로 꾸미기

챗봇이 보내는 메시지 한 덩어리를 **블럭**이라고 합니다. 글만 보낼 수도 있고, 이미지가 있는 카드나 옆으로 넘기는 카드 묶음을 보낼 수도 있습니다. 블럭에는 **버튼**을 달 수 있고, 메시지 아래에는 **퀵 리플라이**를 달 수 있습니다. 시나리오와 플로우 어디에서나 같은 `블럭 디자이너`로 만듭니다.

**위치:** 챗봇 > (챗봇 선택) > 시나리오 > (시나리오 선택) > 블럭 디자이너

## 이럴 때 사용하세요

| 하려는 일 | 가는 곳 |
| --- | --- |
| 어떤 블럭을 써야 할지 모를 때 | [블럭 고르기](#블럭-고르기) |
| 이미지가 올라가지 않을 때 | [이미지 넣기](#이미지-넣기) |
| 버튼을 누르면 홈페이지나 전화로 연결하기 | [버튼 동작 정하기](#버튼-동작-정하기) |
| 고객이 자주 고르는 선택지를 메시지 아래에 달기 | [퀵 리플라이 달기](#퀵-리플라이-달기) |
| 상담 전에 이름과 연락처 받기 | [고객 정보 수집 블럭](#고객-정보-수집-블럭) |

## 블럭 고르기

**위치:** 블럭 디자이너 > 블럭 추가

`블럭 추가`를 누르면 블럭 종류가 나옵니다. 위쪽의 숫자는 지금 블럭 수와 넣을 수 있는 최대 수입니다.

| 블럭 | 쓰는 경우 | 제한 |
| --- | --- | --- |
| `텍스트` | 글만 보낼 때 | 1,000자 |
| `텍스트 카드` | 글에 버튼을 달 때 | 제목 50자(선택), 제목과 설명을 합쳐 400자 |
| `기본 카드(2:1)`, `기본 카드(1:1)` | 이미지 한 장과 글, 버튼을 보낼 때 | 이미지 필수, 제목 50자, 설명 230자 |
| `캐러셀` | 여러 장의 카드를 옆으로 넘겨 보게 할 때 | 카드 최대 10개 |
| `리스트 카드` | 메뉴처럼 항목을 세로로 나열할 때 | 아이템 2~5개, 아이템 제목 35자, 설명 16자 |
| `상품 카드` | 가격이 있는 상품을 보여 줄 때 | 상품명 30자, 상품 설명 40자 |
| `고객 정보 수집` | 상담 전에 고객 정보를 받을 때 | 시나리오당 1개 |

- **`캐러셀`:** `캐러셀 타입`을 `텍스트 카드`, `이미지 카드`, `상품 카드` 중에서 고릅니다. 이미지 카드는 `이미지 비율`을 하나로 정해야 하며, 모든 카드가 같은 비율을 씁니다.
- **`리스트 카드`:** 아이템마다 `클릭 액션`을 `메시지 전송`, `시작 시나리오`, `플로우 이동` 중에서 고릅니다.
- **`상품 카드`:** `정가`는 필수입니다. `할인가`와 `할인율 (%)`은 둘 중 하나만 입력합니다. 둘 다 입력하면 할인가가 우선 적용됩니다.

블럭마다 `위로 이동`, `아래로 이동`, `블럭 복사`, `블럭 삭제`를 쓸 수 있습니다. 복사한 블럭은 다른 시나리오에서 `블럭 붙여넣기`로 넣을 수 있습니다.

## 이미지 넣기

**위치:** 블럭 디자이너 > (카드 블럭) > 이미지 업로드

`이미지 업로드`를 누르고 파일을 고르면 자르기 창이 열립니다. 블럭에 맞는 비율로 잘라서 올립니다.

| 블럭 | 권장 크기 |
| --- | --- |
| `기본 카드(1:1)`, 상품 카드 | 800x800px |
| `기본 카드(2:1)` | 800x400px |
| 리스트 카드 아이템 | 400x400px |

이미지 파일만 올릴 수 있고, 5MB 이하여야 하며, 가로가 500px 이상이어야 합니다. 삭제한 이미지는 복구할 수 없습니다.

## 버튼 동작 정하기

**위치:** 블럭 디자이너 > (카드 블럭) > 버튼 추가

카드 하나에 버튼을 최대 3개까지 달 수 있습니다. 버튼명은 14자까지입니다. 버튼을 펼쳐 동작을 고릅니다.

| 동작 | 버튼을 누르면 | 함께 입력하는 것 |
| --- | --- | --- |
| `메시지 전송` | 고객이 그 문장을 입력한 것처럼 전송됩니다 | `전송할 메시지` |
| `플로우 이동` | 다른 [플로우](./flows)로 넘어갑니다 | `이동할 플로우 선택` |
| `시작 시나리오` | 시작 시나리오로 이동합니다 | 없음 |
| `내부 이동` | 같은 플로우 안의 다른 시나리오로 넘어갑니다 | `이동할 내부 시나리오 선택` |
| `웹 링크` | 웹 페이지가 열립니다 | URL |
| `전화 걸기` | 입력해 둔 번호로 전화를 걸 수 있습니다 | 전화번호(숫자만) |
| `채널 추가` | 카카오톡 채널 추가로 이어집니다 | 없음 |
| `상담사 연결` | 사람 상담사에게 연결합니다 | 없음 |
| `카카오싱크 가입` | 카카오 로그인으로 추가 정보를 받습니다 | `연동 완료 후 이동`할 곳 |

고를 수 있는 동작은 블럭을 쓰는 위치에 따라 다릅니다. `내부 이동`은 플로우 안에서만 나옵니다. 필요한 값을 넣지 않은 버튼에는 "URL 미설정", "전화번호 미설정", "플로우 미선택" 같은 경고가 표시됩니다. 저장하기 전에 경고가 남은 버튼이 없는지 확인하세요.

:::info[콜봇의 상담사 연결과는 다릅니다]
여기의 `상담사 연결`은 채팅 상담을 사람에게 넘기는 버튼입니다. 전화를 상담사에게 넘기는 설정은 콜봇의 [도구](../callbot/tools)에 있습니다.
:::

## 퀵 리플라이 달기

**위치:** 블럭 디자이너 > 퀵 리플라이 > 추가

퀵 리플라이는 메시지 아래에 가로로 나오는 선택지입니다. 최대 10개까지 달 수 있습니다. 동작은 `메시지 전송`과 `플로우 이동`이 기본이고, 플로우 안에서는 `내부 이동`과 `시작 시나리오`도 고를 수 있습니다.

"예약하기", "위치 보기"처럼 고객이 바로 고를 짧은 선택지는 퀵 리플라이가 어울리고, 홈페이지 열기나 전화 걸기처럼 카드 내용에 딸린 동작은 버튼이 어울립니다.

## 고객 정보 수집 블럭

**위치:** 블럭 디자이너 > 블럭 추가 > 고객 정보 수집

이 블럭은 고객에게 이름, 연락처 같은 정보를 입력하는 폼을 보여 줍니다. 블럭 안에서는 내용을 고칠 수 없고, `설정에서 편집`을 눌러 [자동 메시지의 고객 정보 수집](../org-settings/auto-messages#상담-전에-고객-정보-받기)에서 고칩니다.

- 이미 정보가 있는 고객에게는 이 블럭이 표시되지 않습니다.
- 설정에서 꺼져 있으면 블럭에 `비활성`이 표시되고 고객에게 나가지 않습니다.
- 수집 항목은 `이름`, `연락처`, `이메일`, `생년월일` 중 최소 1개이며, 직접 만든 항목을 3개까지 더할 수 있습니다.

## 카카오 상담톡으로 보낼 때

**위치:** 블럭 디자이너 > 상담톡 안내

상담톡 채널은 일부 블럭 구성을 지원하지 않습니다. 지원하지 않는 구성은 발송할 때 자동으로 빠지고 나머지만 전송됩니다. 예를 들어 캐러셀의 바로가기와 최소 크기에 못 미치는 이미지가 빠집니다. 상담톡을 쓰는 챗봇은 실제 카카오톡에서 메시지가 어떻게 보이는지 확인하세요.
