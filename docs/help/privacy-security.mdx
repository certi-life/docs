# 개인정보 및 보안

병원 서비스에서는 고객과 환자의 정보가 다뤄질 수 있습니다. 업무에 필요한 최소 범위만 사용하고, 공개 문서나 테스트 환경에 실제 정보를 복사하지 마세요.

## 공개 가이드에서 지키는 원칙

- 실제 고객·환자·직원의 이름, 연락처, 이메일을 노출하지 않습니다.
- 화면 예시는 완전한 가상 데이터로 작성합니다.
- 내부 주소, 계정, 권한 구조, 토큰과 키를 게시하지 않습니다.
- 미출시 기능과 내부 운영 정보는 공개하지 않습니다.
- 공개 전 이미지와 문서의 식별 정보를 다시 확인합니다.

## 사용자가 확인할 사항

1. 로그인 정보는 다른 사람과 공유하지 마세요.
2. 필요하지 않은 개인정보를 입력하거나 내려받지 마세요.
3. 화면을 공유할 때 고객 정보가 보이지 않는지 확인하세요.
4. 의심스러운 접근이나 정보 노출을 발견하면 즉시 조직의 담당자에게 알리세요.
