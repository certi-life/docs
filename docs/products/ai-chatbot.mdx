# AI 상담

CertiLife AI 상담은 **반복되는 채팅 상담을 돕고 중요한 업무에 집중할 수 있도록 지원**합니다.

## 기대할 수 있는 변화

- 자주 반복되는 문의 대응 부담을 줄입니다.
- 고객이 필요한 정보를 더 빠르게 찾도록 돕습니다.
- 사람이 직접 확인해야 하는 상담에 집중할 여유를 만듭니다.

## 운영 전에 확인할 점

- 고객에게 안내할 정보가 최신 상태인지 확인하세요.
- AI가 답하지 않아야 하는 범위와 사람에게 연결할 조건을 정하세요.
- 공개 가능한 정보만 상담 지식으로 사용하세요.

:::caution[의료 정보 안내]
AI 상담은 의료진의 진단이나 의학적 판단을 대신하지 않습니다. 의료적 판단이 필요한 문의는 병원 담당자에게 연결될 수 있도록 운영 기준을 마련하세요.
:::
