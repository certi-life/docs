# 더 신뢰받는 병원 경험을 만듭니다

CertiLife는 **메디컬 인증서를 기반으로 병원과 고객의 관계를 이어주는 고객관리 플랫폼**입니다. 인증서 발행, AI 상담, CRM 메시징과 이벤트 마케팅을 하나의 흐름으로 연결합니다.

## 무엇을 할 수 있나요?

| 서비스 | 해결하는 일 |
| --- | --- |
| **인증서** | 시술과 제품 정보를 고객에게 안전하고 간편하게 전달합니다. |
| **AI 상담** | 반복되는 채팅 상담을 줄이고 중요한 상담에 집중하도록 돕습니다. |
| **CRM 메시징** | 고객에게 필요한 메시지를 적절한 시점에 전달합니다. |
| **이벤트 마케팅** | 고객 경험과 병원 브랜드의 접점을 넓힙니다. |

## 역할에 맞게 시작하세요

- **병원 사용자**라면 [Hospital 가이드](./hospital/overview)에서 시작하세요.
- **Studio 사용자**라면 [Studio 가이드](./studio/overview)를 확인하세요.
- 서비스 구성이 궁금하다면 [빠른 둘러보기](./getting-started/quick-tour)를 먼저 읽어보세요.

:::tip[가장 빠른 시작]
처음 방문했다면 **빠른 둘러보기 → 역할별 가이드 → 첫 작업** 순서로 확인하는 것을 권장합니다.
:::
