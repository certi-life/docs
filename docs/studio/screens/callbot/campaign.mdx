# 캠페인 - 콜봇으로 여러 고객에게 전화 걸기

캠페인은 콜봇이 **대상 목록의 번호로 전화를 걸어** 정기검진 안내, 예약 확인 같은 용건을 전하는 기능입니다. 통화가 연결되면 지정한 에이전트가 응대합니다. 준비물은 세 가지입니다. 걸 대상이 담긴 **대상 목록**, 응대할 **에이전트**, 그리고 **발신번호**입니다.

**위치:** 콜봇 > 캠페인

:::caution[실제 전화가 걸리고 요금이 청구됩니다]
캠페인을 시작하면 목록의 번호로 실제 통화가 발생하고 통화 요금이 건별로 청구됩니다. 시작하면 되돌릴 수 없고, 취소해도 이미 나간 통화는 청구됩니다. 화면에 캠페인 기능이 아직 준비되지 않았다는 안내가 보이면 조직의 CertiLife 담당자에게 문의하세요.
:::

## 시작하기 전에 준비할 것

| 준비물 | 어디서 |
| --- | --- |
| 캠페인용 에이전트 | [에이전트 만들기](./agents)에서 통화 방향을 `캠페인`으로 만듭니다 |
| 발신번호 | [번호 관리](./phone-numbers)의 보유 번호 |
| 표기번호 (선택) | 번호 관리에서 승인받은 [발신표기번호](./phone-numbers#고객-화면에-보일-번호-등록하기) |
| 대상 목록 | 아래 [대상 목록 만들기](#대상-목록-만들기) |

상담사 전환(아웃바운드) 방향으로 만든 에이전트는 캠페인 통화에서 상담사 전환이 동작하지 않는다는 경고가 나옵니다. 캠페인에는 `캠페인` 방향으로 만든 에이전트를 쓰세요.

## 대상 목록 만들기

**위치:** 콜봇 > 캠페인 > 대상 목록 > 목록 만들기

1. `대상 목록` 탭에서 목록 만들기를 시작합니다.
2. **`1 · 데이터 넣기`:** CSV 파일을 올리거나 엑셀에서 복사해 붙여 넣습니다. 한 줄에 한 명씩이며, `샘플 CSV 내려받기`로 형식을 확인할 수 있습니다. CSV는 5MB 이하여야 합니다.
3. **`2 · 열 지정`:** 열마다 `전화번호`, `변수`, `사용 안 함` 중 하나를 고릅니다. 이름이나 예약일 같은 열을 `변수`로 지정하면 에이전트가 통화에서 그 값을 쓸 수 있습니다.
4. 집계에서 `유효`, `중복 제거`, `형식 오류` 건수를 확인합니다. 하이픈과 공백은 자동으로 제거되고 같은 번호는 한 번만 담깁니다.
5. 목록 이름을 적고 `목록 저장`을 누릅니다. 저장만 할 뿐 발신하지는 않습니다.

목록 하나에는 최대 10,000건까지 담을 수 있습니다. 형식 오류로 표시된 건은 목록에 담기지 않으니, 필요하면 원본을 고쳐 다시 넣으세요. 한 목록으로 캠페인을 여러 번 만들 수 있습니다.

:::caution[전화를 걸어도 되는 고객인지 확인하세요]
광고성 안내 전화는 수신에 동의한 고객에게만 걸어야 합니다. 목록을 만들기 전에 동의 여부를 확인하고, 수신 거부를 요청한 고객은 목록에서 빼세요.
:::

## 캠페인 만들고 시작하기

**위치:** 콜봇 > 캠페인 > 캠페인 만들기

`캠페인 만들기`를 누르면 세 단계로 진행됩니다.

1. **`에이전트 · 발신번호`:** `캠페인 이름`, `발신번호`, `표기번호`, `에이전트`를 고릅니다. `최대 동시 발신 수`는 1~10(기본 5)이며 높을수록 빨리 끝나지만 회선 부하가 커집니다. `시작`을 비워 두면 시작 버튼을 누르는 즉시 발신되고, 일시를 넣으면 그때 시작합니다.
2. **`대상`:** 저장된 대상 목록을 고르거나 `새 목록 만들기`로 바로 만듭니다. 이미 캠페인에 쓴 목록이면 "같은 사람에게 다시 걸립니다"라는 경고가 나옵니다.
3. **`확인 · 시작`:** 요약을 확인하고 `통화 허용 시간대`를 정합니다. 시간대를 벗어나면 자동으로 일시정지되고 다시 들어오면 자동으로 재개됩니다.

마지막으로 발신 건수가 적힌 시작 버튼을 누르고, `캠페인 시작` 확인 창에서 한 번 더 확인합니다.

:::caution[발신번호는 만든 뒤에 바꿀 수 없습니다]
캠페인에는 편집 기능이 없어, 만든 뒤에는 `발신번호`와 `표기번호`를 바꿀 수 없습니다. 어느 번호로 거는지는 캠페인 목록과 상세 화면에서 `발신`(발신번호)과 `표기`(표기번호) 뒤에 적힌 번호로 확인합니다. 다른 번호로 걸어야 한다면 아직 발신되지 않은 캠페인을 `취소`하고 같은 대상 목록으로 캠페인을 새로 만듭니다.
:::

:::caution[통화 허용 시간대를 끄지 마세요]
`제한 없음 — 24시간 발신`을 고르면 야간에도 전화가 나갑니다. 화면에도 "민원 소지가 있으니 의도한 경우에만 끄세요"라고 안내됩니다. 특별한 이유가 없다면 업무 시간대로 제한하세요.
:::

## 진행 상황 보고 멈추기

**위치:** 콜봇 > 캠페인 > (캠페인 선택)

캠페인 상태는 `예약 대기`, `실행 대기`, `진행 중`, `일시정지`, `완료`, `실패`, `취소됨`으로 표시됩니다. 캠페인을 누르면 `전체`, `성공`, `실패`, `남음`, `동시` 집계와 수신 번호별 상태(`대기`, `통화중`, `완료`, `실패`, `취소`)를 볼 수 있습니다.

| 버튼 | 동작 |
| --- | --- |
| `일시정지` / `재개` | 잠시 멈췄다가 이어서 겁니다 |
| `취소` | 아직 발신되지 않은 통화를 모두 중단합니다. 되돌릴 수 없고 이미 발신된 통화 요금은 청구됩니다 |
| `실패분으로 목록 만들기` | 연결되지 않은 번호만 모아 새 대상 목록을 만듭니다. 다른 시간대에 다시 걸 때 씁니다 |
| `보관` | 목록에서 숨깁니다. 통화 기록과 집계는 그대로 남고 `보관함 보기`에서 다시 볼 수 있습니다 |

## 문제가 생기면

### `발신 가능한 보유 번호가 없습니다. 번호 관리에서 번호를 먼저 구매하세요.`

`캠페인 만들기`의 `발신번호`에서 고를 번호가 없다는 뜻입니다.

1. [번호 관리](./phone-numbers)에서 번호를 구매하거나 연동합니다. 번호 구매가 막혀 있으면 먼저 [조직 인증](./verification)을 받습니다.
2. `캠페인 만들기`를 다시 열어 `발신번호`를 고릅니다.

### `승인된 표기번호가 없습니다. 번호 관리 › 발신표기번호에서 등록·승인을 받으면 여기서 고를 수 있습니다.`

고객 화면에 보일 `표기번호`로 승인된 번호가 없다는 뜻입니다. `표기번호`는 선택 항목이라 비워 두고 캠페인을 만들 수 있습니다. 다른 번호를 보이게 하려면 [번호 관리의 발신표기번호](./phone-numbers#고객-화면에-보일-번호-등록하기)에서 등록과 승인을 먼저 받습니다.

### `서버에 연결하지 못했습니다. 네트워크 상태를 확인하고 잠시 후 다시 시도해주세요.`

캠페인 화면이 콜봇 서버에 연결하지 못했다는 뜻입니다. 번호 목록 옆에 이 문구가 보이면 옆의 `다시 시도`를 누릅니다. 연결 문구별 뜻과 할 일은 [콜봇 시작하기의 문제 해결](./overview#문제가-생기면)에 있습니다.

## 권장 운영법

- 처음에는 내 번호와 동료 번호 몇 개로 만든 목록으로 시험 캠페인을 돌려 멘트와 흐름을 확인합니다.
- 첫 인사에서 어디서 왜 전화했는지, AI 상담원이라는 점을 밝히게 하세요.
- 통화 결과는 [전화상담](../phone-counsel)과 [통계](../stats)에서 확인하고, 연결률이 낮으면 시간대를 바꿔 실패분으로 다시 겁니다.
