# 인증서 - Studio에서 병원 관리 화면 열기

`인증서` 메뉴는 새로운 기능이 아니라 **병원 관리 화면(Hospital)으로 가는 창**입니다. 상담을 하다가 인증서 업무를 보려고 Hospital에 따로 로그인할 필요 없이, Studio 안에서 병원 관리 화면을 그대로 열어 줍니다. 그래서 이 메뉴 안의 화면 구성과 버튼은 Hospital과 같습니다.

**위치:** 인증서

## 누구에게 보이나요?

`인증서` 메뉴는 **병원 계정으로 Studio에 직접 로그인했을 때만** 보입니다. 제조사 계정이거나, 다른 조직의 업무를 대신 보는 상태에서는 보이지 않습니다. 메뉴가 없는 계정이 주소로 직접 들어오면 [챗봇](./chatbot/overview) 화면으로 이동합니다.

## 인증서 업무 보기

**위치:** 인증서 > 병원 관리 화면

1. 왼쪽 메뉴에서 `인증서`를 누릅니다.
2. "병원 화면에 연결하고 있습니다."가 잠깐 보인 뒤 병원 관리 화면이 열립니다.
3. 열린 화면의 왼쪽 메뉴에서 업무를 고릅니다. 화면별 사용법은 아래 표의 Hospital 안내를 참고하세요.

인증서를 발행하는 순서는 진료과 이름이 붙은 `인증서 발행` 메뉴(예: `치과 인증서 발행`)에서 환자와 시술 정보를 넣고, `전송 방식 선택`이 보이면 전송 방식을 고른 뒤 `발행하기`를 누르는 것입니다. 단계별 설명은 [인증서 발행](../../hospital/screens/issue-certificate)에 있습니다.

| 하려는 일 | Hospital 화면 안내 |
| --- | --- |
| 어떤 메뉴가 있는지 보기 | [Hospital 메뉴 한눈에 보기](../../hospital/screens/overview) |
| 환자에게 인증서 발행하기 | [인증서 발행](../../hospital/screens/issue-certificate) |
| 주의사항과 보증사항 미리 넣어 두기 | [인증서 설정](../../hospital/screens/certificate-settings) |
| 알림 다시 보내기, 잘못 보낸 인증서 회수하기 | [발행 내역과 환자 관리](../../hospital/screens/history) |
| 병원 정보와 직원 계정 관리하기 | [병원 정보 관리](../../hospital/screens/hospital-info), [계정 관리](../../hospital/screens/accounts) |

인증서를 준비하고 전달하는 전체 절차는 [인증서 발행·전달 가이드](../../hospital/certificate-workflow)와 [인증서 전달 전 체크리스트](../../products/certificate/delivery-checklist)에 있습니다.

:::caution[작성 중에 다른 메뉴로 이동하면]
병원 관리 화면에서 무언가 작성하던 중에 Studio의 다른 메뉴를 누르면 "병원 화면에서 작성 중인 내용이 사라질 수 있습니다. 다른 메뉴로 이동하시겠습니까?"라는 확인 창이 뜹니다. 저장하지 않은 내용이 있다면 먼저 저장한 뒤 이동하세요.
:::

## Studio 안에서 열면 달라지는 점

**위치:** 인증서 > 병원 관리 화면

메뉴와 기능은 Hospital에 직접 접속했을 때와 같습니다. 다음 네 가지만 다릅니다.

- **로그인:** Studio의 로그인을 그대로 씁니다. Hospital의 로그인 화면과 회원가입 화면은 열리지 않습니다.
- **로그아웃:** 병원 관리 화면의 `로그아웃`을 누르면 Studio에서 로그아웃됩니다.
- **새 창:** Hospital에서는 새 창으로 열리던 환자 상세와 발행 내역 상세가 같은 화면 안에서 열립니다.
- **좁은 화면:** 화면이 좁으면 병원 관리 화면의 왼쪽 메뉴가 숨겨지고 `병원 메뉴` 버튼이 생깁니다. 버튼을 눌러 메뉴를 열고, `병원 메뉴 닫기`나 바깥쪽을 눌러 닫습니다.

## 화면이 열리지 않을 때

**위치:** 인증서 > 다시 연결

| 화면의 안내 | 원인 | 해결 |
| --- | --- | --- |
| "병원 화면의 로그인 연결이 종료되었습니다. Studio에 다시 로그인해주세요." | 로그인 연결이 만료되었습니다 | `다시 로그인`을 누릅니다 |
| "병원 화면에 연결할 수 없습니다. 잠시 후 다시 연결해주세요." | 일시적인 연결 문제입니다 | 잠시 뒤 `다시 연결`을 누릅니다 |
| "병원 화면을 불러올 수 없습니다. 다시 연결해주세요." | 화면을 불러오지 못했습니다 | `다시 연결`을 누릅니다 |

병원 관리 화면 안쪽에 "Studio에서 다시 로그인해주세요." 또는 "Studio에서 인증서 메뉴를 다시 열어주세요."처럼 Studio를 가리키는 문구만 보일 때도 있습니다. 로그인 연결이 끊긴 것이므로 문구대로 `인증서` 메뉴를 다시 열거나 Studio에 다시 로그인합니다. "병원 계정이 일치하지 않습니다."가 나오면 Studio에 로그인한 계정과 병원 계정이 다른 것이므로, 로그아웃한 뒤 맞는 병원 계정으로 로그인합니다.

여러 번 시도해도 열리지 않으면 [Hospital 공식 로그인 화면](https://hospital.certi.life/signin)에서 직접 접속해 업무를 보고, 조직의 CertiLife 담당자에게 알려 주세요. 문의할 때 고객 정보가 보이는 화면을 그대로 캡처해 보내지 않도록 주의합니다.
