# 업데이트

CertiLife 공개 가이드의 주요 변경 사항을 기록합니다.

## 2026년 7월

- 공개 문서 사이트의 기본 구조를 만들었습니다.
- 서비스 소개, Hospital, Studio, 도움말 영역을 구성했습니다.
- 공개 정보와 내부 정보를 구분하기 위한 작성 원칙을 반영했습니다.

새로운 사용 가이드는 실제 제품에서 재현하고 공개 범위를 검토한 뒤 추가합니다.
