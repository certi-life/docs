# 도구 화면

> Studio 챗봇 설정의 도구 화면과 챗봇 메뉴의 도구 목록에서 대화 정보 추출, 병원 진료시간 활용, 컴플레인 대응, 알림톡 보내기, 브랜드메시지 보내기, API 도구를 추가하고 설정하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/tools)

`도구`는 챗봇이 답변할 때 함께 사용하는 기능을 챗봇별로 추가하거나 제거하는 화면입니다. 메뉴에 `v2 beta`로 표시되는 베타 기능으로, 응답 버전이 v2인 챗봇에서만 사용할 수 있고 동작과 문구가 바뀔 수 있습니다. 도구의 추가와 제거, 도구별 설정은 바꾸는 즉시 저장되므로 왼쪽 아래 `저장` 버튼을 누르지 않습니다.

## 도구

- **위치:** 챗봇 > 설정 > 도구
- **이 화면에서 할 수 있는 일:** 이 챗봇이 사용할 도구를 추가하거나 제거하고, 왼쪽 목록에서 도구를 골라 이 챗봇에서의 설정을 확인합니다.
- **주요 항목:** `기본 제공` 도구는 `대화 정보 추출`, `병원 진료시간 활용`, `컴플레인 대응`, `알림톡 보내기`, `브랜드메시지 보내기`입니다. 조직에서 정의한 API 도구도 함께 추가할 수 있습니다.
- **주요 버튼:** `추가`, `이 챗봇에서 제거`, `도구 관리 (회사 공통, 챗봇 > 도구)`, `챗봇 > 도구에서 정의 편집`
- **팁:** 응답 버전이 v1이면 "v2에서 사용할 수 있습니다. AI 설정 상단에서 응답 버전을 변경해주세요."라는 안내가 표시됩니다. 기본 제공 도구는 챗봇별 설정을 가지고, API 도구는 `챗봇` > `도구`에서 정의한 대로 동작합니다. 목록에 `삭제됨`으로 표시되는 도구는 도구 목록에서 삭제된 것이므로 제거합니다.
- **관련 가이드:** [AI 설정 화면](https://docs.certi.life/guide/studio/screens/ai-settings#응답-버전), [매뉴얼 화면](https://docs.certi.life/guide/studio/screens/manuals)

## 대화 정보 추출

- **위치:** 챗봇 > 설정 > 도구 > 대화 정보 추출
- **이 화면에서 할 수 있는 일:** 챗봇과의 대화에서 확인할 정보(예: 이름, 관심 시술)를 필드로 등록합니다.
- **주요 항목:** `추출할 정보 추가` 창의 `필드 이름`, `추출 가이드`.
- **주요 버튼:** `필드 추가`, `저장`, `취소`, `다시 불러오기`
- **팁:** 필드는 20개까지 등록할 수 있습니다. 저장하면 새 대화부터 적용되며, 필요한 정보는 대화 중 자연스럽게 질문하고 고객이 거절하면 다시 묻지 않습니다. 필드를 삭제해도 이미 수집된 정보는 삭제되지 않습니다. `추출 가이드`에는 어떤 정보를 확인할지 구체적으로 적습니다.
- **관련 가이드:** [상담 기록 필드 설정](https://docs.certi.life/guide/studio/consultation-records), [개인정보 및 보안](https://docs.certi.life/guide/help/privacy-security)

## 병원 진료시간 활용

- **위치:** 챗봇 > 설정 > 도구 > 병원 진료시간 활용
- **이 화면에서 할 수 있는 일:** 조직의 운영 설정에 등록한 병원 진료시간(요일별 진료시간, 임시 휴진일, 정기 휴무 예외일)을 이 챗봇의 답변에 사용합니다.
- **팁:** 학습자료에 적힌 진료시간과 운영 설정 값이 다르면 운영 설정 값을 우선 안내합니다. 제거하면 학습자료의 진료시간만 사용합니다. 진료시간은 `조직 설정` > `운영 설정` > `병원 진료시간`에서 바꿉니다.

## 컴플레인 대응

- **위치:** 챗봇 > 설정 > 도구 > 컴플레인 대응
- **이 화면에서 할 수 있는 일:** 고객의 감정이 '매우 부정'으로 판단되거나 고객이 명시적으로 항의할 때 챗봇이 상담사 연결을 안내하고 상담사 화면에 알림을 띄우도록 합니다.
- **팁:** 상담사 화면에는 "컴플레인이 감지되었어요" 알림이 뜹니다. 상담 대기열 등록이나 상담원 배정은 하지 않으므로 상담사가 알림을 보고 직접 방을 엽니다. 제3자나 과거 경험에 대한 불만, 단순 실망은 해당하지 않습니다. 판단 결과는 상담 내역의 챗봇 답변 위에 "고객 감정" 태그로 남습니다.
- **관련 가이드:** [상담원 연결 정책](https://docs.certi.life/guide/products/ai-chatbot/handoff-policy), [상담 내역 조회와 화면 설정](https://docs.certi.life/guide/studio/conversation-history)

## 알림톡 보내기

- **위치:** 챗봇 > 설정 > 도구 > 알림톡 보내기
- **이 화면에서 할 수 있는 일:** 챗봇이 대화 중 특정 상황에서 병원 담당자에게 알림톡을 보내도록 발송 슬롯을 만듭니다.
- **화면에 보이는 다른 이름:** `브랜드메시지 보내기`도 같은 구성의 화면이며, 템플릿 종류만 다릅니다.
- **주요 항목:** `이름`, `언제 보낼지 (챗봇에게 설명)`, `담당자 수신 번호`, `실행 전 고객에게 동의 받기`, `발송 채널`, `템플릿`, `템플릿 변수`, `발송 예시`.
- **주요 버튼:** `슬롯 추가`, `편집`, `삭제`, `저장`, `취소`
- **팁:** 수신 번호는 고객 번호가 아니라 알림을 받을 병원 담당자 번호이며, 적어 둔 번호로만 발송합니다. 슬롯은 챗봇당 10개까지 만들 수 있고, 같은 대화에서는 슬롯당 한 번만 보냅니다. 템플릿 변수는 `챗봇이 대화에서 파악`과 `고정 값` 중에서 고릅니다. 담당자 알림이면 `실행 전 고객에게 동의 받기`를 끄고, 고객에게 가는 안내면 켭니다.
- **관련 가이드:** [CRM 메시지 발송 전 체크리스트](https://docs.certi.life/guide/products/crm-messaging/message-checklist)

## 도구 목록

- **위치:** 챗봇 > 도구
- **이 화면에서 할 수 있는 일:** 챗봇이 답변 중 호출할 API 도구를 조직 공통으로 정의합니다. 챗봇별 사용 여부는 각 챗봇의 `설정` > `도구`에서 정합니다.
- **주요 항목:** `기본 정보`(`도구 이름`, `도구 설명`), `엔드포인트`, `파라미터`, `API 인증`, `커스텀 헤더`, `응답 처리`(`결과 기다리기` 또는 `보내고 바로 진행`), `고정 필드`, `실행 전 확인`(`실행 전 고객 동의 받기`).
- **주요 버튼:** `새 API 도구`, `예시 넣기`, `헤더 추가`, `필드 추가`, `저장`, `삭제`, `취소`
- **팁:** 챗봇 목록 화면 위쪽의 `도구` 탭(`v2 beta`)에서 엽니다. `도구 이름`에는 영숫자, 하이픈, 언더스코어만 쓸 수 있습니다. 결과가 답변에 필요한 조회 도구는 `결과 기다리기`를, 완료 여부만 보내면 되는 발송 도구는 `보내고 바로 진행`을 고릅니다. 발송·예약·변경처럼 되돌리기 어려운 도구는 `실행 전 고객 동의 받기`를 켭니다. `기본 제공`과 `시스템 제공` 도구는 이 화면에서 수정하거나 삭제할 수 없습니다.
- **관련 가이드:** [챗봇 목록 화면](https://docs.certi.life/guide/studio/screens/chatbot-list)
