# 기본 정보 - 챗봇 이름·이미지 변경과 다른 계정으로 복사

`기본 정보`에서는 고객과 운영자에게 보이는 챗봇의 "얼굴"을 정합니다. 챗봇 이름과 프로필 이미지, 설명을 여기서 바꾸고, 잘 만든 챗봇을 다른 계정으로 복사할 때 쓰는 내보내기 코드도 여기서 만듭니다.

**위치:** 챗봇 > (챗봇 선택) > 설정 > 기본 정보

## 프로필 이미지 바꾸기

**위치:** 챗봇 > 설정 > 기본 정보 > 챗봇 프로필 이미지

프로필 이미지는 웹채팅에서 챗봇 메시지 옆에 표시됩니다.

1. `이미지 업로드`를 눌러 파일을 고릅니다. 병원 계정은 `병원 이미지 가져오기`, 제조사 계정은 `제조사 이미지 가져오기`로 조직에 등록된 이미지를 바로 불러올 수도 있습니다.
2. 이미지가 미리보기에 나타나면 왼쪽 아래 `저장`을 누릅니다.

권장 크기는 200x200px이고, 최대 5MB의 PNG, JPG, GIF, WebP 파일을 올릴 수 있습니다. 이미지를 없애려면 `삭제`를 누른 뒤 `저장`합니다.

:::tip[저장을 잊지 마세요]
이미지를 올리거나 지우면 "저장 버튼을 눌러 적용하세요"라는 안내가 뜹니다. `저장`을 누르기 전에는 실제 채팅창에 반영되지 않습니다.
:::

## 챗봇 이름과 설명 바꾸기

**위치:** 챗봇 > 설정 > 기본 정보 > 챗봇 이름

`챗봇 이름`과 `설명`을 고친 뒤 `저장`을 누릅니다. 이름은 챗봇 목록과 상세 화면 위쪽에 표시되므로, 챗봇이 여러 개라면 "본점 상담 챗봇", "이벤트 안내 챗봇"처럼 용도가 드러나게 짓는 것이 좋습니다. 웹채팅 창 위쪽에 고객에게 보이는 제목은 여기가 아니라 [`채팅창 설정`](./chat-window-settings#채팅창-색과-제목-바꾸기)에서 따로 정합니다.

## 챗봇을 다른 계정으로 복사하기

**위치:** 챗봇 > 설정 > 기본 정보 > 챗봇 내보내기

잘 만든 챗봇을 다른 계정(또는 같은 계정)에 그대로 하나 더 만들고 싶을 때 내보내기 코드를 씁니다.

1. `챗봇 내보내기`를 누르고, 주의사항을 확인한 뒤 코드를 만듭니다.
2. 화면에 표시된 내보내기 코드를 `복사`합니다. 남은 유효 시간이 함께 표시됩니다.
3. 복사받을 계정의 [챗봇 목록](../list#다른-챗봇을-복제하기)에서 `새 챗봇 만들기` > `챗봇 가져오기`에 코드를 입력합니다.

:::caution[내보내기 코드 사용 조건]
코드는 60분간 유효하고 1회만 사용할 수 있습니다. 채팅 기록과 통계는 복사되지 않습니다. 코드를 가진 사람은 챗봇 구성을 복사할 수 있으므로 필요한 사람에게만 전달하고, 잘못 만들었다면 `코드 삭제`로 바로 없애세요.
:::
