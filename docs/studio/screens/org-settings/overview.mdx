# 설정(조직 설정) - 조직 공통 설정 한눈에 보기

챗봇 하나에만 해당하는 설정은 [챗봇의 `설정` 탭](../chatbot/settings/menu)에 있고, **조직 전체에 공통으로 적용되는 설정**은 여기에 있습니다. 상담 가능 시간, 상담이 들어왔을 때의 알림, 번역, 메신저 채널 계정 연동, 고객에게 자동으로 나가는 메시지가 대표적입니다. 화면 위쪽에는 `설정`, 왼쪽에는 `설정 메뉴`라고 표시되며, 다른 화면의 안내 문구에서는 이곳을 "조직 설정"이라고 부릅니다.

**위치:** 왼쪽 아래 톱니 아이콘 > 설정 메뉴

:::info[PC에서 설정하세요]
설정은 모바일 환경에서 지원하지 않습니다. 화면에 `읽기 전용 모드`가 표시되면 내용을 볼 수만 있고, 변경은 PC에서 해야 합니다.
:::

| `회원 관리` | 채널별 회원과 인증회원 확인 | [고객 표시와 회원 관리](./customer-info) |

## 상담 운영 기준 정하기

**위치:** 설정 > 운영 설정

`운영 설정`은 여섯 개 탭입니다(`상담 시간`, `관리자 알림`, `상담사 알림`, `상황별 콜백`, `번역`, `자주 사용하는 답변`). 처음 도입할 때는 이 순서대로 정하는 것을 권장합니다.

1. [`상담 시간`](./hours): 상담원이 응대할 수 있는 시간을 정합니다. 이 시간이 아래 알림과 자동메시지의 기준이 됩니다.
2. [`관리자 알림`과 `상담사 알림`](./alerts): 상담이 들어왔을 때 누구에게 알릴지 정합니다.
3. [`번역`](./translation): 외국어 상담이 있다면 채팅 번역을 켭니다.
4. [`상황별 콜백`](./callback-situations): 상담사가 자주 보내는 알림톡을 묶음으로 만들어 둡니다.
5. [`자주 사용하는 답변`](#상담-채팅에서-쓸-답변-미리-만들기): 상담원이 채팅에서 `/`로 불러 쓸 답변을 만들어 둡니다.

## 상담 채팅에서 쓸 답변 미리 만들기

**위치:** 설정 > 운영 설정 > 자주 사용하는 답변

인사말, 예약 안내처럼 상담원이 자주 보내는 답변을 미리 만들어 두면, 상담원은 채팅 입력창에서 `/`를 입력해 [자주 쓰는 답변](../counsel/reply-tools#자주-쓰는-답변-빠르게-넣기)으로 바로 불러 씁니다. 그룹은 목록을 묶어 보여 주는 용도이고, 즐겨찾기(★)는 상담사마다 따로 저장됩니다.

1. `+ 새 답변`을 누릅니다. `새 답변` 창이 열립니다.
2. `제목`을 적습니다. 필수 항목입니다.
3. 필요하면 `명령어 (선택)`에 `/` 뒤에 칠 짧은 말(예: 예약안내)을 적습니다. 명령어는 회사 안에서 겹칠 수 없습니다. `그룹`도 고릅니다. 고르지 않으면 `미분류`에 들어갑니다.
4. `말풍선 추가`에서 `+ 텍스트`, `+ 이미지`, `+ 기본 카드`, `+ 텍스트 카드`, `+ 캐러셀` 중 필요한 것을 눌러 내용을 씁니다. 답변 하나에 말풍선은 최대 10개입니다. 고객 이름처럼 달라지는 값은 `변수 넣기`로 넣습니다.
5. 창 안의 `채널별 미리보기`에서 채널마다 어떻게 보이는지 확인합니다.
6. 창 아래의 `저장`을 누릅니다. "답변을 추가했습니다."가 나오면 끝입니다.

처음이라면 `기본 템플릿 불러오기`로 준비된 답변을 가져와 고쳐 써도 됩니다. 답변 옆의 스위치를 끄면 삭제하지 않고 채팅에서만 숨깁니다.

`새 답변` 창은 창 안의 `저장`을 눌러야 저장됩니다. 저장하지 않고 닫으려 하면 "편집을 취소할까요?" 창이 뜨고, `버리기`를 누르면 작성 중인 내용이 사라집니다. 목록에서 하는 그룹 추가, 순서 변경, 켜기·끄기, 즐겨찾기, 삭제는 누르는 즉시 반영되며 아래쪽 저장 바를 쓰지 않습니다.

## 메신저 채널 계정 연동하기

**위치:** 설정 > 채널 설정

카카오톡이나 Instagram 같은 메신저를 쓰려면 **두 단계**가 필요합니다. 먼저 여기서 조직에 계정을 연동하고, 그다음 [챗봇의 `채널 설정`](../chatbot/settings/channel-settings)에서 어느 챗봇이 그 채널에 응답할지 고릅니다. 채널별 연동 절차는 [채널 연동](./channels)에 있습니다.

## 저장은 이렇게 됩니다

**위치:** 설정 > 설정 메뉴

화면마다 저장 방식이 다르므로 바꾼 뒤 적용됐는지 꼭 확인하세요.

| 저장 방식 | 해당 화면 |
| --- | --- |
| 화면 아래 "변경사항이 있습니다" 저장 바의 `저장` | `상담 시간`의 `병원 진료시간`·`채팅 상담`, `자동메시지`(AI 전화 콜백 탭 제외) |
| 고르는 즉시 적용 (5초 이내) | `관리자 알림`, `상담사 알림`, `번역` |
| 목록 조작은 즉시 반영, 답변 내용은 `새 답변` 창의 `저장` | `자주 사용하는 답변` |
| 카드나 화면 안의 자체 `저장` 버튼 | `AI 챗봇` 작동시간, `헤더 고객 정보`, `상황별 콜백`, `AI 전화 콜백` |
| 조작 즉시 반영 | `상담 기록 설정` |

저장하지 않고 다른 메뉴로 이동하려 하면 "변경사항이 저장되지 않았습니다" 확인 창이 나옵니다.

## 알아 둘 점

- 이 화면의 설정은 조직의 모든 상담원과 모든 채널에 영향을 줍니다. 바꾸기 전에 책임자와 상의하세요.
- `고객 태그`는 이 화면에서 볼 수만 있고, 추가와 수정은 [백과사전](../encyclopedia)에서 합니다.
- 상담 시간과 알림 기준은 [상담원 연결 정책](../../../products/ai-chatbot/handoff-policy)과 함께 정하는 것이 좋습니다.

## 문제가 생기면

### `제목을 입력해주세요.`

`새 답변` 창에서 `제목`을 비운 채 `저장`을 눌렀다는 뜻입니다. `제목`을 적고 `저장`을 다시 누릅니다. 명령어가 30자를 넘으면 "명령어는 30자를 넘을 수 없습니다."가 나오니 줄여서 다시 저장합니다.

### `저장에 실패했습니다. 잠시 후 다시 시도해주세요.`

`새 답변` 창에서 답변을 저장하지 못했다는 뜻입니다. 창은 열린 채로 남아 있으므로 작성한 내용은 그대로 있습니다.

1. 잠시 뒤 `저장`을 다시 누릅니다.
2. 명령어가 다른 답변과 겹친다는 안내가 창 안에 나오면 `명령어 (선택)`를 바꿉니다.
3. "불러오지 못한 이미지가 있습니다. 이미지를 다시 선택해주세요."가 나오면 이미지 말풍선의 이미지를 다시 고릅니다.

그래도 안 되면 답변 제목과 발생 시각을 적어 조직의 CertiLife 담당자에게 알립니다.

### `자주 사용하는 답변을 불러오지 못했습니다.`

답변 목록을 읽지 못했다는 뜻입니다. 답변이 지워진 것은 아닙니다. 문구 옆의 `다시 시도`를 누르고, 그래도 같으면 브라우저를 새로고침합니다.

### `채널 적합성 판정을 불러오지 못했습니다 — 답변별 채널 표시는 판정 불가 상태입니다.`

답변이 채널마다 어떻게 바뀌는지 판단하는 정보를 받지 못했다는 뜻입니다. 답변 목록과 저장은 그대로 쓸 수 있고, 답변 옆 채널 표시만 `채널 판정 불가`로 보입니다. 잠시 뒤 화면을 다시 열어 봅니다.

### `조건에 맞는 답변이 없습니다.`

검색어나 `★ 즐겨찾기` 보기 때문에 보이는 답변이 없다는 뜻입니다. 옆의 `필터 해제`를 누르면 전체 답변이 다시 보입니다.
