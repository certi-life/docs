# Studio 안내

Studio 사용자를 위한 공개 안내입니다.

## 사용 가이드 안내

Studio의 화면별 사용 가이드는 준비 중입니다. 현재 이용 중 도움이 필요하다면 조직의 CertiLife 담당자 또는 [도입 문의](https://certi.life/contact)를 통해 지원을 요청해 주세요.

## 안전한 운영을 위한 기본 원칙

- 고객에게 공개해도 되는 정보만 사용합니다.
- 의료진의 판단이 필요한 질문과 일반 안내의 경계를 정합니다.
- 테스트 데이터에는 실제 고객이나 환자 정보를 넣지 않습니다.
- 공개 전 담당자가 답변 범위와 연결 조건을 확인합니다.
