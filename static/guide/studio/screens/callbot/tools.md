# 콜봇 도구 - 통화 중에 할 수 있는 일 늘리기

> Studio 콜봇에서 통화 종료·통화 전환·에이전트 전환·DTMF 전송 기본 도구를 에이전트에 넣는 방법과, 도구 화면에서 우리 시스템을 호출하는 API 도구를 만들고 실행 중 안내 멘트를 정하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/studio/screens/callbot/tools)

콜봇은 도구가 있어야 말하는 것 이상의 일을 합니다. 도구는 두 종류입니다. **통화를 끝내거나 상담사에게 넘기는 기본 도구**는 에이전트 설정 화면에서 바로 넣고, **예약 조회처럼 우리 시스템을 호출하는 API 도구**는 `도구` 화면에서 만든 뒤 에이전트에 연결합니다.

**위치:** 콜봇 > 도구

> **도구가 없으면 통화를 그냥 끝냅니다**
>
> 도구가 하나도 없는 콜봇은 모르는 질문을 받았을 때 통화를 그냥 끝냅니다. 최소한 통화 종료와, 사람 연결이 필요한 업무라면 통화 전환은 꼭 넣으세요.

## 어떤 도구가 있나요?

| 도구            | 하는 일                              | 넣는 곳                            |
| ------------- | --------------------------------- | ------------------------------- |
| `통화 종료`       | 고객이 통화 종료를 요청하는 경우 등에 통화를 끝냅니다    | 에이전트 설정 > `도구`                  |
| `통화 전환`       | 고객이 사람 상담사와 통화를 원하는 경우 상담사에게 넘깁니다 | 에이전트 설정 > `도구`                  |
| `에이전트 전환`     | 다른 에이전트에게 통화를 넘깁니다                | 에이전트 설정 > `도구`                  |
| `DTMF 전송`     | ARS 메뉴에서 버튼 톤을 전송합니다              | 에이전트 설정 > `도구`                  |
| 알림톡·브랜드메시지 도구 | 통화 중이나 통화 뒤에 고객에게 메시지를 보냅니다       | 에이전트 설정 > `알림톡 도구`, `브랜드메시지 도구` |
| API 도구        | 우리 시스템의 API를 호출합니다                | `도구` 화면에서 만들고 에이전트에 연결          |

## 상담사에게 전화를 넘기게 하기

**위치:** 콜봇 > 에이전트 > (에이전트 선택) > 도구

1. 에이전트 설정 화면에서 `도구` 섹션을 펼치고 `추가`를 누릅니다.
2. `통화 전환`을 고릅니다.
3. 언제 넘길지 설명을 적습니다. 예: "고객이 사람 상담사와 통화를 원하는 경우". AI는 이 설명을 보고 전환 시점을 판단합니다.
4. 넘길 대상과 전환 방식을 정합니다. `즉시 전환 (cold)`은 바로 연결하고, `안내 후 전환 (warm)`은 고객에게 안내한 뒤 연결합니다. 안내 멘트는 `고정 문구` 또는 `AI 생성 (동적)` 중에서 고릅니다.
5. 화면 위쪽의 `배포`를 눌러 실제 통화에 반영합니다.

상담사가 통화를 받을 수 없는 시간에 전환되지 않도록 [전화상담의 `상담사 상태`](https://docs.certi.life/guide/studio/screens/phone-counsel#내-상태-바꾸기)와 조직의 상담 시간을 함께 맞춰 두세요.

## 우리 시스템을 호출하는 API 도구 만들기

**위치:** 콜봇 > 도구 > 새 API 도구

1. `도구` 화면에서 더하기(+) 버튼 또는 `새 API 도구`를 누릅니다.
2. `기본 정보`에 `도구 이름`과 `도구 설명`을 적습니다. 이름은 영숫자, 하이픈, 언더스코어로 1\~64자입니다. 설명은 AI가 이 도구를 언제 어떻게 쓸지 판단하는 근거이므로 구체적으로 적습니다.
3. `엔드포인트`에 호출할 API의 주소와 HTTP 메서드, 타임아웃(1\~60초)을 정합니다.
4. `파라미터`에 AI가 전달할 인자를 JSON Schema로 정의합니다. `예시 넣기`로 시작하면 편합니다.
5. 필요하면 `API 인증`과 `커스텀 헤더`를 켭니다. 저장된 자격증명은 다시 보이지 않으며, 바꿀 때만 새 값을 입력합니다.
6. `응답 처리`에서 `결과 기다리기` 또는 `보내고 바로 진행`을 고릅니다. 결과가 답변에 필요한 조회는 기다리고, 완료 여부만 보내면 되는 발송은 바로 진행합니다.
7. `저장`을 누릅니다.

만든 도구는 에이전트 설정의 `도구` 섹션에서 `추가`로 연결해야 쓰입니다. 목록에 `미연결`로 표시된 도구는 어떤 에이전트에도 연결되지 않은 것입니다. 개발 담당자와 함께 진행하는 것을 권장합니다.

### 조회하는 동안 어색한 침묵 없애기

**위치:** 콜봇 > 도구 > (도구 선택) > 실행 중 안내

전화에서는 API 응답을 기다리는 몇 초의 침묵도 고객에게 길게 느껴집니다. `실행 중 안내`에서 `실행 전 말하기`를 켜고 "잠시만요, 확인해 보겠습니다" 같은 멘트를 `메시지 추가`로 넣어 두세요. `도구 실행 중 끼어들기 허용`을 끄면 도구 실행이 끝날 때까지 고객의 끼어들기가 차단됩니다.

## 알아 둘 점

- 도구를 삭제하기 전에 `사용 중인 에이전트`를 확인하세요. 연결된 에이전트가 있다면 그 에이전트의 통화에 영향을 줍니다.
- 저장하지 않고 다른 도구로 이동하려 하면 "저장하지 않은 변경사항이 있어요" 확인 창이 나옵니다.
- 챗봇의 [도구](https://docs.certi.life/guide/studio/screens/chatbot/settings/tools)와 개념은 같지만 목록은 따로 관리됩니다.
- 특정 상황에서만 도구를 쓰게 하려면 [매뉴얼](https://docs.certi.life/guide/studio/screens/callbot/manuals)에 그 절차를 적습니다.
