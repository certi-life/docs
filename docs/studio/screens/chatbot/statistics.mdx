# 통계 탭 - 답하지 못한 질문 찾아 보강하기

`통계` 탭은 챗봇이 **제대로 답하지 못한 질문을 찾아서 고치는 곳**입니다. 숫자를 보는 화면이기도 하지만, 핵심은 "실패한 질문 확인 → 올바른 답 입력 → 학습자료에 자동 반영"으로 이어지는 개선 작업입니다. 정기적으로 들여다보고 보강할수록 챗봇이 답할 수 있는 질문이 늘어납니다.

**위치:** 챗봇 > (챗봇 선택) > 통계

왼쪽 `통계 메뉴`에는 세 화면이 있습니다.

| 화면 | 이럴 때 보세요 |
| --- | --- |
| `통계 개요` | 챗봇이 얼마나 잘 답하고 있는지, 어떤 주제에서 자주 막히는지 한눈에 보고 싶을 때 |
| `실패 발화` | 답하지 못한 질문을 하나씩 확인하고 올바른 답을 넣고 싶을 때 |
| `Q&A 보강` | 보강한 내용을 돌아보거나, 새 질문과 답을 직접 등록하고 시험하고 싶을 때 |

이 탭은 작업이 바로 반영되므로 다른 탭과 달리 왼쪽 아래 `저장` 버튼이 없습니다.

## 챗봇이 얼마나 잘 답하는지 확인하기

**위치:** 챗봇 > 통계 > 통계 개요

화면 위쪽에 선택한 기간의 `AI 발화`, `실패`, `해결`, `미해결` 건수가 차례로 보이고, 실패율과 해결률이 함께 표시됩니다. 실패는 세 가지 유형으로 나뉩니다.

| 유형 | 뜻 | 대응 |
| --- | --- | --- |
| `답변 부적절/비응답` | 답을 하긴 했지만 질문에 맞지 않거나 답을 피한 경우. AI 판정 기반 추정치입니다 | `실패 발화`에서 보강 답변을 넣습니다 |
| `시스템 오류` | 기술적인 문제로 답을 만들지 못한 경우 | 반복되면 CertiLife 담당자에게 문의합니다 |
| `학습자료 미연결` | 챗봇에 학습자료가 없어 답하지 못한 경우 | [`AI 학습자료 설정`](./settings/training-materials)에서 자료를 연결합니다 |

유형 카드를 누르면 그 유형만 걸러진 `실패 발화` 목록으로 바로 이동합니다.

아래쪽 `실패 토픽 분석`에서 `분석 실행`을 누르면 현재 기간의 실패 질문을 주제별로 묶어 보여 줍니다. 분석에는 수십 초가 걸릴 수 있습니다. `자주 실패한 발화`에는 같은 질문이 몇 번 실패했는지 나오므로, 횟수가 많은 것부터 보강하면 효과가 큽니다.

## 답하지 못한 질문에 올바른 답 넣기

**위치:** 챗봇 > 통계 > 실패 발화 (화면 제목은 `실패 발화 목록`)

1. 위쪽 상태 필터에서 `미해결`을 고릅니다. 필요하면 기간, `발화 내용 검색`, 유형 필터로 좁힙니다.
2. 질문을 눌러 펼치면 고객의 `발화`와 당시 `챗봇 답변`이 보입니다.
3. 아래 입력란에 올바른 답을 적습니다. 최대 5,000자입니다.
4. `저장 → 학습자료 반영`을 누릅니다. 이 답은 학습자료에 자동으로 추가되고, 같은 질문 그룹이 함께 `해결됨`으로 바뀝니다.
5. 답할 필요가 없는 질문(장난, 범위 밖 질문)은 `무시`를 눌러 `무시됨`으로 정리합니다.

질문의 앞뒤 맥락이 궁금하면 `상담방 보기`로 실제 대화를 열어 보세요. `상세보기`에서는 `AI 판정`의 신뢰도와 판정 근거, 문의가 들어온 `채널`을 확인할 수 있습니다.

:::caution[보강 답변을 쓸 때]
보강 답변은 이후 비슷한 질문에 그대로 쓰입니다. 특정 고객에게만 해당하는 내용이나 개인정보를 넣지 말고, 누구에게나 안내해도 되는 공개 정보로 작성하세요. 의료진의 판단이 필요한 질문은 답을 넣기보다 상담원 연결로 안내하는 편이 안전합니다.
:::

실패 발화는 이 기능이 켜진 이후의 대화부터 수집됩니다. 목록이 비어 있다면 아직 수집된 실패가 없는 것입니다.

## 질문과 답을 직접 등록하고 시험하기

**위치:** 챗봇 > 통계 > Q&A 보강

실패를 기다리지 않고 예상 질문을 미리 넣어 둘 수도 있습니다.

1. `새 Q&A 직접 등록`에서 `질문`(최대 500자)과 `답변`(최대 5,000자)을 입력합니다.
2. `Q&A 등록`을 누르면 학습자료에 바로 추가됩니다.
3. `챗봇에 테스트 질문`에 같은 질문을 넣고 `전송`을 눌러 챗봇이 실제로 그렇게 답하는지 확인합니다. 이 테스트는 통계에 집계되지 않습니다.

`보강 학습 성과`에는 지금까지 보강한 질문과 해결 건수가 쌓이고, `보강 파일 보기`로 보강 내용 전체를 확인할 수 있습니다. 보강 내용은 [`AI 학습자료 설정`](./settings/training-materials)의 파일 목록에 `보강 Q&A · 자동 관리`라는 파일로 나타나며, 그 화면에서는 직접 삭제할 수 없고 이 화면에서 관리합니다.

## 권장 운영법

- 주 1회 `통계 개요`에서 실패율을 확인하고, `자주 실패한 발화`의 상위 질문부터 보강합니다.
- 같은 주제의 실패가 계속 쌓이면 Q&A를 하나씩 넣기보다 [학습자료](./settings/training-materials) 자체를 보완합니다.
- 운영시간이나 가격처럼 자주 바뀌는 정보는 보강 답변보다 원본 자료를 고치는 편이 관리하기 쉽습니다. 자료 관리 기준은 [상담 지식 관리](../../knowledge-management)를 참고하세요.
