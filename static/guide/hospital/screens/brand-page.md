# 병원 소개 페이지 - 고객에게 보이는 병원 정보 꾸미기

> Hospital 브랜드관의 병원 설정(병원 소개 페이지 설정)에서 병원 연락처, 공식 채널, 진료시간과 휴진일, 진료 정보와 가격, 병원소개 글과 이미지, 검색 태그, 웹챗봇을 설정하고 링크를 복사해 공유하는 방법을 안내합니다.

[사람이 읽는 원문](https://docs.certi.life/guide/hospital/screens/brand-page)

`브랜드관`의 `병원 설정`은 **고객이 보는 병원 소개 페이지**를 만드는 곳입니다. 연락처, 진료시간, 진료 정보, 병원 사진을 넣어 두면 고객이 링크 하나로 병원 정보를 확인할 수 있습니다. 왼쪽 메뉴 이름은 `병원 설정`이고, 열린 화면의 제목은 `병원 소개 페이지 설정`입니다.

**위치:** 브랜드관 > 병원 설정

## 소개 페이지 만들기

**위치:** 브랜드관 > 병원 설정 > 병원 소개 페이지 설정

아래 섹션을 채운 뒤 화면 위쪽의 `저장하기`를 누릅니다.

| 섹션                          | 넣는 내용                          |
| --------------------------- | ------------------------------ |
| `기본 설정`                     | 병원 연락처, 카카오톡 채널                |
| `공식 채널`                     | 홈페이지, 인스타그램, 유튜브, 블로그, 페이스북 주소 |
| `진료시간`                      | 진료일, 진료시간, 점심시간, 휴진일           |
| `임시 휴진일 설정`, `정기 휴무 예외일 설정` | 평소와 다르게 쉬거나 진료하는 날짜            |
| `진료 정보`                     | 진료 항목의 설명, 정상가, 이벤트가           |
| `병원소개`                      | 병원 소개글과 병원 이미지                 |
| `태그관리`                      | 병원 검색 시 노출될 태그                 |
| `웹챗봇 설정`                    | 소개 페이지에 붙일 메인 챗봇 선택            |

가격을 넣을 때는 실제로 받는 금액과 같은지, 이벤트 기간이 지나지 않았는지 확인하세요. 의료 광고에 해당할 수 있는 표현은 병원의 검토 절차를 거친 뒤 올리는 것이 안전합니다.

## 링크 공유하기

**위치:** 브랜드관 > 병원 설정 > 링크 복사

저장한 뒤 `링크 복사`를 누르면 소개 페이지 주소가 복사됩니다. 홈페이지, 메신저 프로필, 안내 문자에 붙여 넣어 공유합니다.

## 어디에서 많이 들어오는지 보기

**위치:** 브랜드관 > 병원 설정 > 링크 관리

같은 소개 페이지라도 **공유하는 곳마다 링크를 따로 만들면** 어느 곳에서 방문과 예약이 많이 생기는지 알 수 있습니다. `링크 관리`를 누르면 `공유 링크 관리` 화면이 열립니다.

1. `새 링크 생성`을 누르고 링크명을 입력합니다. 카카오 공유용, 블로그용처럼 공유할 곳의 이름을 붙입니다.
2. 목록에서 `복사`를 눌러 그 링크를 해당 채널에 올립니다.
3. 목록의 `클릭`, `고유클릭`, `예약`에서 결과를 봅니다. `통계`를 누르면 `총 클릭`, `고유 방문자`, `예약 전환`, `전환율`과 `일별 클릭 추이`, `기기 분포`, `시간대별 방문 패턴`을 볼 수 있습니다.

링크의 상태는 `활성`, `일시중지`, `종료`입니다. `더보기`에서 `일시중지`, `재개`, `종료`를 고릅니다. `삭제`한 링크는 복구할 수 없고, 그 링크를 받은 고객은 더 이상 들어올 수 없습니다. 이미 인쇄물이나 게시물에 쓴 링크는 지우지 마세요.

## 챗봇 붙이기

**위치:** 브랜드관 > 병원 설정 > 웹챗봇 설정

Studio에서 만든 챗봇이 있다면 `웹챗봇 설정`에서 메인 챗봇을 골라 소개 페이지에서 바로 상담을 받을 수 있습니다. 챗봇을 만드는 방법은 [챗봇 메뉴 시작하기](https://docs.certi.life/guide/studio/screens/chatbot/overview)를 참고하세요.

## 알아 둘 점

- 이 화면의 진료시간은 소개 페이지에 보이는 값입니다. 병원의 기준 운영시간은 [병원 정보 관리](https://docs.certi.life/guide/hospital/screens/hospital-info#진료시간과-휴진일-관리하기)에 있으니 서로 다르지 않게 맞춰 주세요.
- 병원 이미지에 환자 얼굴이나 차트, 모니터 화면이 찍혀 있지 않은지 올리기 전에 확인하세요.
- 직원용 서브계정은 [계정 관리](https://docs.certi.life/guide/hospital/screens/accounts)의 `권한 설정`에서 `병원 설정` 메뉴의 권한을 받아야 이 메뉴가 보입니다. 이 권한이 다섯 그룹 중 어디에 있는지는 화면에서 확인되지 않았습니다.
