# 콜봇 매뉴얼 - 특정 상황의 통화 절차 정해 주기

환불 요청, 예약 변경처럼 **정해진 순서로 응대해야 하는 상황**이 있습니다. 이런 절차를 프롬프트에 모두 넣으면 프롬프트가 길어지고 에이전트가 헷갈립니다. 매뉴얼로 떼어 두면 통화 중 그 상황이 왔을 때만 에이전트가 본문을 불러와 따릅니다.

**위치:** 콜봇 > 매뉴얼

매뉴얼을 쓰는 순서는 "매뉴얼 만들기 → 에이전트에 연결하기 → 배포"입니다. 매뉴얼은 프롬프트 타입 에이전트에만 연결할 수 있습니다.

## 매뉴얼 만들기

**위치:** 콜봇 > 매뉴얼 > 매뉴얼 만들기

만드는 방법은 두 가지입니다. 더하기(+) 버튼의 `매뉴얼 만들기`에서 고릅니다.

| 방법 | 이럴 때 |
| --- | --- |
| `새 매뉴얼` | 우리 절차를 처음부터 직접 적을 때 |
| `템플릿에서 시작` | 흔한 상황의 틀을 가져와 다듬을 때. 템플릿을 고르면 내용이 채워진 폼이 열리고, `저장`을 눌러야 매뉴얼이 만들어집니다 |

1. `이름`을 적습니다. 목록에서 알아보기 위한 이름이며 통화에는 전달되지 않습니다. 예: "환불·교환 요청 응대"
2. `트리거`에 이 매뉴얼을 불러올 상황을 적습니다. 예: "고객이 주문한 상품의 환불이나 교환을 요청할 때"
3. `본문`에 절차를 순서대로 적습니다. 예: "1. 주문번호를 물어봅니다. 2. …" 본문은 8,096자까지입니다.
4. 필요하면 `실행 대기음`을 고릅니다. 매뉴얼을 불러온 직후 재생해 통화의 무음 구간을 채웁니다. `사용 안 함`, `타이핑`, `대기 음악` 중에서 고릅니다.
5. `저장`을 누릅니다.

:::tip[트리거는 상황이 드러나게]
"환불"처럼 단어만 적으면 상관없는 통화에서도 매뉴얼을 불러올 수 있습니다. "누가 무엇을 요청할 때"가 드러나는 문장으로 적으세요.
:::

## 에이전트에 연결하기

**위치:** 콜봇 > 에이전트 > (에이전트 선택) > 매뉴얼

[에이전트 설정](./agent-settings#회사-정보로-답하게-하기) 화면의 `매뉴얼` 섹션에서 연결할 매뉴얼을 고른 뒤 `배포`를 누릅니다.

:::caution[무엇이 언제 반영되나요?]
**연결을 바꾼 것은 배포해야** 반영됩니다. 반면 **매뉴얼 본문을 고친 것은 배포 없이 즉시**, 이 매뉴얼을 연결한 모든 에이전트의 통화에 반영됩니다. 운영 중인 매뉴얼의 본문을 고칠 때는 저장 버튼을 누르는 순간 실제 통화가 바뀐다는 점을 기억하세요.
:::

## 권장 운영법

- 매뉴얼 하나에는 상황 하나만 담습니다.
- 본문에 "확인되지 않으면 상담사에게 전환한다"처럼 막혔을 때의 출구를 적어 둡니다. 전환하려면 에이전트에 [통화 전환 도구](./tools#상담사에게-전화를-넘기게-하기)가 있어야 합니다.
- 의료진의 판단이 필요한 상황은 콜봇이 판단하지 않고 사람에게 넘기는 절차로 작성합니다. 기준은 [상담원 연결 정책](../../../products/ai-chatbot/handoff-policy)을 참고하세요.
- 저장한 뒤에는 에이전트 설정의 테스트 패널에서 트리거 상황을 직접 말해 보며 확인합니다.
- 챗봇의 [매뉴얼](../chatbot/settings/manuals)과 개념은 같지만 목록은 따로 관리됩니다.
