# 설정 탭 - 챗봇 설정 항목 찾기

챗봇 하나에 대한 모든 설정은 `설정` 탭에 모여 있습니다. 왼쪽 `설정 메뉴`에서 항목을 고르면 오른쪽에 그 설정이 열립니다. 항목이 아홉 개라 처음에는 어디로 가야 할지 헷갈릴 수 있는데, 아래 표에서 바꾸려는 내용을 찾으면 됩니다.

**위치:** 챗봇 > (챗봇 선택) > 설정

## 바꾸려는 내용으로 찾기

| 이런 걸 바꾸고 싶어요 | 설정 메뉴 |
| --- | --- |
| 챗봇 이름, 프로필 이미지, 설명 / 챗봇을 다른 계정으로 복사 | [`기본 정보`](./basic-info) |
| 말투와 역할(페르소나), 직접 쓴 프롬프트, 답변 범위, 응답 버전, 언어 | [`AI 설정`](./ai-settings) |
| 대화 중 고객 정보 챙기기, 진료시간 안내, 컴플레인 감지, 담당자 알림톡 | [`도구`](./tools) (`v2 beta`) |
| 특정 상황에서 정해진 절차대로 응대 | [`매뉴얼`](./manuals) (`v2 beta`) |
| 챗봇이 쉬는 시간과 공휴일 | [`작동시간`](./operating-hours) |
| 챗봇이 답변 근거로 쓰는 자료 | [`AI 학습자료 설정`](./training-materials) |
| 웹사이트·카카오톡·네이버 톡톡·Instagram·LINE·WhatsApp 연결 | [`채널 설정`](./channel-settings) |
| 웹채팅 창과 채팅 버튼의 색, 크기, 문구 | [`채팅창 설정`](./chat-window-settings) |
| 챗봇 삭제 | [`챗봇 삭제`](./delete-chatbot) |

## 저장은 이렇게 됩니다

**위치:** 챗봇 > 설정 > 설정 메뉴

설정 항목은 저장 방식이 두 가지로 나뉩니다. 헷갈리기 쉬우니 한 번 확인해 두세요.

- **`저장`을 눌러야 적용되는 항목:** `기본 정보`, `AI 설정`, `작동시간`, `채널 설정`, `채팅창 설정`. 내용을 바꾼 뒤 왼쪽 아래 `저장`을 누릅니다.
- **바꾸는 즉시 적용되는 항목:** `도구`, `매뉴얼`, `AI 학습자료 설정`, `챗봇 삭제`. 이 화면들에서는 `저장` 버튼이 비활성화되어 있습니다.

`AI 설정` 안에서도 `응답 버전`은 예외로, 선택하는 즉시 적용됩니다.

저장하지 않은 채 다른 항목이나 다른 탭으로 이동하려 하면 `저장하지 않은 변경사항이 있습니다` 창이 뜹니다. 버튼은 `취소`와 `이동`입니다. `이동`을 누르면 바꾼 내용이 사라지니, 남기려면 `취소`를 누르고 먼저 저장하세요. 챗봇 상세 화면을 아예 떠나려 할 때는 버튼이 `취소`와 `나가기`인 창이 뜹니다. 창마다 다른 문구는 아래 [문제가 생기면](#문제가-생기면)에 정리했습니다.

:::tip[v2 beta 표시]
`도구`와 `매뉴얼`은 메뉴에 `v2 beta`로 표시됩니다. 응답 버전이 v2인 챗봇에서 쓸 수 있는 베타 기능이며, 동작과 문구가 바뀔 수 있습니다.
:::

## 문제가 생기면

### `저장하지 않은 변경사항이 있습니다`

`저장`을 누르지 않은 설정이 있는 채로 다른 곳으로 가려 했다는 뜻입니다. 창의 제목은 모두 같습니다. 어디로 가려 했는지에 따라 안내 문구와 버튼이 다릅니다.

| 하려던 일 | 창의 안내 문구 | 버튼 |
| --- | --- | --- |
| 왼쪽 `설정 메뉴`에서 다른 항목을 누름 | "현재 설정의 변경사항이 저장되지 않았습니다. 다른 설정으로 이동하시겠습니까?" | `취소`, `이동` |
| 위쪽의 `시나리오`, `플로우`, `통계` 탭을 누름 | "설정 탭의 변경사항이 저장되지 않았습니다. 다른 메뉴로 이동하시겠습니까?" | `취소`, `이동` |
| `AI 답변 시나리오로 이동`, `미작동 시나리오로 이동`처럼 시나리오로 가는 버튼을 누름 | "설정의 변경사항이 저장되지 않았습니다. 시나리오 탭으로 이동하시겠습니까?" | `취소`, `이동` |
| Studio 왼쪽 메뉴를 누르는 등 챗봇 상세 화면을 떠남 | "설정 탭의 변경사항이 저장되지 않았습니다. 페이지를 떠나시겠습니까?" | `취소`, `나가기` |

1. 바꾼 내용을 남기려면 `취소`를 누릅니다. 창이 닫히고 지금 화면에 그대로 머뭅니다.
2. 왼쪽 아래 `저장`을 누릅니다.
3. 가려던 곳으로 다시 이동합니다.

`이동`이나 `나가기`를 누르면 바꾼 내용이 사라지고, 설정은 마지막으로 저장한 상태로 돌아갑니다. 새로고침하거나 브라우저 탭을 닫을 때는 이 창 대신 브라우저가 직접 떠날지 묻습니다. 그 창의 문구와 버튼은 브라우저가 정하므로 브라우저마다 다릅니다.
